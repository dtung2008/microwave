## 第一小時 — 原理 I：寬頻匹配（0:00–0:50）

### 1.1 客戶的信 — 以及為什麼一節 λ/4 撐不住（0:00–0:08）

投影片提示：那封信。「12.5 Ω 接上 50 Ω 的世界 — 回波損耗（return loss）20 dB，
2 到 4 GHz，整整一個八度頻程（octave）。時程很趕。」

開場先講工作，不講理論。這是真實的規格長相：功率放大器輸出 12.5 Ω（是系統 50 Ω
的 4:1 降階），要在一個八度頻程內匹配到 20 dB 回波損耗 — 2 至 4 GHz 處處
|Γ| ≤ 0.1。第 2 講給了我們四分之一波長轉換器，第 3 講警告過它是一個諧振；今天
算清楚那個警告的代價，以及用什麼買回來。

先寫單節答案，數字上黑板。Z₁ = √(Z₀Z_L) = √(50·12.5) = 25 Ω，在頻帶中心
f₀ = 3 GHz 是四分之一波長。在 f₀ 完美，出於構造。偏離 f₀，該節不再是 90°，匹配
就衰敗：在頻帶邊緣（2 與 4 GHz），精確的輸入反射是 |Γ| = 0.351 — **9.09 dB**，
對上 20 dB 的規格。這個設計的 20-dB 頻寬，第 3 小時量出來：**17.1% 分數頻寬** —
客戶要 **66.7%**。一節窄了四倍。今天的三個主張，寫在黑板上留到下課：

1. **頻寬用「節」買。** 把一大步阻抗跳變拆成 N 小步，匹配就變寬；把「怎麼拆」
   選聰明（切比雪夫，Chebyshev），每一節約買到 11.4 dB 的帶內回波損耗。
2. **天花板存在，而且是定理。** Bode–Fano（波德–法諾準則）只憑負載儲存的能量，
   就為「任何網路、任意元件數」在一個頻帶上能做到的最佳匹配標了價。先判可行性，
   再動手設計。
3. **諧振器量到的 Q 不是它的 Q。** 掃頻諧振的 3-dB 寬度給的是負載品質因數
   （loaded Q）；諧振器自己的 Q 躲在耦合（coupling）後面，本週的修正係數高達
   25 倍。

先擋掉看課表的同學正在形成的問題：「轉換器和諧振器為什麼是同一講？」因為它們是
同一套數學面朝相反的方向。匹配網路是你想**拉寬**的諧振；諧振器是你想**珍藏**的
諧振。Q 決定兩者的頻寬 — 第 3 講埋的種子，第 8 講收割（濾波器就是耦合諧振器），
今天的上下兩半就是那兩個方向。

### 1.2 小反射理論 — 推導兩次（0:08–0:20）

讓多節設計變得可算的工具。黑板上架設：N 節，每節在 f₀ 是四分之一波長，阻抗
Z₀ → Z₁ → Z₂ → … → Z_N → Z_L。每個接面 k 有一個**部分反射係數**（partial
reflection coefficient）：

> Γ_k = (Z_{k+1} − Z_k)/(Z_{k+1} + Z_k)，每節 θ = βℓ = (π/2)(f/f₀)

**第一層 — 相量和（快版）。** 假裝每道入射波只反射一次就結束：在接面 k 反射的
波，比在最前面反射的多走了 2k 節。把首次反彈加總：

> Γ(θ) ≈ Γ₀ + Γ₁e^{−2jθ} + Γ₂e^{−4jθ} + … + Γ_N e^{−2jNθ}

一個偽裝的傅立葉餘弦級數 — 對我們要造的對稱設計（Γ_k = Γ_{N−k}）收攏成
Γ(θ) = 2e^{−jNθ}[Γ₀cos Nθ + Γ₁cos(N−2)θ + …]，偶數 N 的中間項只算一次。
**整個小時的設計自由度，就是 Γ_k 的選法。**

**第二層 — 多重反彈級數（第一性原理），當作第一層的解釋。** 老老實實做兩接面
問題：一節的總反射是幾何級數 Γ = Γ₀ + Γ₁e^{−2jθ}(1−Γ₀²)·Σ(−Γ₀Γ₁e^{−2jθ})^n —
首次反彈那對之後的每一項都帶著部分反射的**乘積**。第一層正是把所有乘積丟掉的
這個級數。所以這套理論是對步階大小的一階微擾，誤差是二階的：Γ_iΓ_j 這類乘積。
警告現在講，1.4 節兌現：那些乘積由**總**阻抗比決定，而 Z_L/Z₀ = 4 的總量並不小。
這套理論會替我們**設計**轉換器，然後對它的漣波（ripple）撒謊 — 而且量得出來。

先擋掉必問題：「負載又不對稱，為什麼 Γ_k 要對稱？」因為實阻抗負載的 |Γ(θ)| 必須
對 θ = π/2 偶對稱 — 餘弦收攏的數學**要求**對稱，而每個經典設計（二項式、
切比雪夫）都有它。不對稱住在絕對阻抗水平裡，不住在反射的樣式裡。

### 1.3 二項式：最平坦的拆法（0:20–0:30）

第一個設計：讓 Γ(θ) 在 f₀ 儘可能平。把相量多項式的零點全部放在 θ = π/2：

> Γ(θ) = A(1 + e^{−2jθ})^N，|Γ| = 2^N|A||cos θ|^N，A = 2^{−(N+1)}ln(Z_L/Z₀)

（A 用 ln 形式 — 大比值時比裸 Γ 準，遞迴也乾淨）。把二項式展開和相量和逐項
對上，得設計法則 — 每一步分到總對數阻抗比的一份二項式係數：

> ln(Z_{k+1}/Z_k) = 2^{−N}·C^N_k·ln(Z_L/Z₀)

把我們的工作在黑板上算，N=2：步階比 1:2:1，Z₁ = 50·(1/4)^{1/4} = **35.36 Ω**、
Z₂ = **17.68 Ω**。理論帶緣回波損耗 2^N|A|cos^N(60°)：**15.22 dB** — 不及格。
N=3：Z = **[42.04, 25.00, 14.87] Ω**，理論帶緣 **21.25 dB** — 帳面過關；精確
掃頻（第 3 小時的機械，備課時先跑過）量得帶內最差 **20.42 dB** — 以 0.42 dB
低空飛過，20-dB 頻寬 67.9%，對上要求的 66.7%。零餘裕的及格，而且請注意這個
已經出現的模式：精確值比理論**差**。先記著。

二項式的性格：中心奢華，帶緣揮霍。它把多項式零點全疊在 f₀ — 我們只需要其中
一個。規格說「帶內**處處** 20 dB」，獎勵的不是中心的平坦，是最差點的守住。
那是等漣波（equal-ripple）的工作。

### 1.4 切比雪夫：等漣波，以及遞迴（0:30–0:42）

主菜。讓漣波多次碰到規格上限，不在中心浪費餘裕 — 在 ±1 內震盪得愈久、出界後
爆炸得愈兇的多項式，就是切比雪夫的：

> T_N(cos φ) = cos Nφ（界內）；T_N(x) = cosh(N·arccosh x)（界外）。

設計陳述：代入 x = sec θ_m·cos θ。帶內（θ 介於 θ_m 與 π − θ_m）引數留在
[−1, 1]，|T_N| 以 ≤ 1 起伏；帶外爆炸。於是設

> Γ(θ) = Γ_m e^{−jNθ} T_N(sec θ_m cos θ)，Γ_m·T_N(sec θ_m) = ½|ln(Z_L/Z₀)|

其中 θ_m 是帶緣電氣長度。我們的八度頻程：θ_m = (π/2)(f₁/f₀) = 60°，所以
**sec θ_m = 2** — 乾淨得可愛的數字，整份作業都跑在它上面。設計交換一行講完：
給定 N，漣波 Γ_m = ½|ln(Z_L/Z₀)|/T_N(2)。表格在黑板上邊唸邊建（T_N(2) 用遞迴
T_{N+1} = 4T_N − T_{N−1}：2、7、26、97）：

| N | T_N(2) | Γ_m | 理論 RL |
|---|---|---|---|
| 1 | 2 | 0.3466 | 9.20 dB |
| 2 | 7 | 0.0990 | **20.09 dB** |
| 3 | 26 | 0.0267 | 31.48 dB |
| 4 | 97 | 0.0071 | 42.92 dB |

兩種讀法。第一：**理論說 N=2 過客戶的 20 dB — 過 0.09 dB。** 第二：
T_N(2) = cosh(N·arccosh 2) ≈ ½e^{1.317N}，每加一節就把漣波往下乘 e^{1.317} —
**每節 11.44 dB**（漸近值）。對照二項式 N=3：理論 21.25 dB 對切比雪夫的
31.48 — 同樣的硬體，等漣波紅利約 10 dB。（作業的第一題預測就住在這張表裡；
不要當場講破。）

接著是把 Γ_m 變成銅的遞迴。把 T_N(sec θ_m·cos θ) 展開成餘弦倍頻，和
2[Γ₀cos Nθ + Γ₁cos(N−2)θ + …] 逐項對上。N=2：T₂(sec θ_m cos θ) =
sec²θ_m(1 + cos 2θ) − 1，所以 2Γ₀ = Γ_m sec²θ_m、Γ₁ = Γ_m(sec²θ_m − 1) —
中間項一次，不是兩次。然後把阻抗踏出去：ln(Z_{k+1}/Z_k) = 2Γ_k，我們的下降
負載**取負號**。算：Γ_m = 0.0990、sec² = 4 → Γ₀ = 0.198、Γ₁ = 0.297，
Z₁ = 50e^{−0.396} = **33.65 Ω**、Z₂ = **18.57 Ω**（端點檢查：18.57·e^{−0.396}
= 12.50 ✓）。任何代數失手都逃不掉的自我檢查：2ΣΓ_k = ln(Z_L/Z₀) = −1.386，
分毫不差。

**現在兌現 1.2 的警告。** 這個 N=2 設計的精確 ABCD 掃頻 — 串接是第 4 講的
教材，數字是第 3 小時的 — 量得帶內最差回波損耗 **18.98 dB**。設計它的理論
承諾 20.09。規格**差了整整一個 dB**，這位客戶誠實的最小值是 **N=3**：各節
[40.40, 25.00, 15.47] Ω，精確帶內最差 **29.44 dB**，餘裕紮實。承諾與量測的
差距隨 N 增長 — N = 1…4 依序 +0.11、+1.10、+2.04、+3.70 dB — 而為什麼每一步
變小、差距反而變大，是作業 Q4。下面的戰場故事，是同一堂課的量產版。

戰場故事，60 秒：某寬頻天線饋線的 16:1 八度轉換器，各節阻抗直接抄教科書表格，
機械加工漂亮，量出來比表格的漣波差 3 dB。一星期都在怪技工和接頭。加工沒問題；
**表格**才是小反射近似，而 16:1 不是小反射。理論是設計者，不是判決。判決是
掃頻 — 這也是為什麼課程讓你早兩講先把串接機械蓋好，才把一套需要稽核的設計
理論交到你手上。

### 1.5 漸變線一張圖，本小時回顧（0:42–0:50）

投影片提示：漸變圖 — 樓梯溶成斜坡。

固定總長讓 N → ∞，樓梯變成**漸變線**（tapered line）：Z(z) 連續，處處反射，
用同一套小反射邏輯積分（總和變成 ∫e^{−2jβz}·d(ln Z)/dz·dz — 漸變剖面的傅立葉
轉換；每種漸變的 |Γ(f)| 就是其阻抗斜率的頻譜）。三種剖面看到要認得：**指數**
（d(lnZ)/dz 恆定 — 簡單，旁瓣高）、**三角**（端點更平滑，第一旁瓣較低，主瓣
較寬）、**Klopfenstein**（切比雪夫極限 — 截止之上等漣波，給定漣波下最短；業界
預設）。漸變的美德不是魔法頻寬 — 是截止頻率以上**永不**失效：高通式的匹配，
多節則是帶通式。代價：長度。做我們這件 20 dB 工作的 Klopfenstein 需要約最低
頻率處的半波長再多一點；三節 3 GHz 的 λ/4 比它短。交換就這麼多，一張投影片
夠了 — 數學在 Pozar §5.8，指定閱讀，不上課。

回顧，三句話：一節 λ/4 是拿 17% 的元件做 67% 的工作；小反射理論把「選節」變成
「選多項式」— 二項式在中心囤積餘裕，切比雪夫平均花掉、每節買 11.4 dB；設計
轉換器的那套理論在大比值時少報漣波，所以在資料表上簽名的是掃頻，不是公式。
第二小時：這一切頭上的天花板，然後是反向的交易 — 我們想留住的諧振。

## 第二小時 — 原理 II：Bode–Fano 天花板，與諧振器（1:00–1:50）

### 2.1 Bode–Fano — 任何匹配的物理天花板（1:00–1:16）

把第一小時的遊戲重新框起來：節買到了頻寬，但還沒有人說買到哪裡停 — 或停不停。
會停。對儲存能量的負載，Fano（1950，承 Bode）證明了一條硬積分界。對典型的
並聯 R-C 負載：

> ∫₀^∞ ln(1/|Γ(ω)|) dω ≤ π/(RC)

推導講輪廓，並誠實標明是輪廓（完整版在 Pozar §5.9 / Fano 的論文）：被動反射的
ln(1/|Γ|) 受解析性約束 — |Γ(s)| 在整條 jω 軸上的行為由右半平面的零點決定，而
負載的 RC 透過電容必須儲存的能量固定了 Γ 的高頻漸近。於是「匹配品質對**全**
頻率的積分」只由負載封頂：**一份由負載簽發的預算，隨處可花，總額 π/RC。**

用工程師的方式讀，上黑板。你要 |Γ| = Γ_m 平鋪在 Δω 上，其他地方不管（帶外
一毛不花 — |Γ| = 1）。界變成：

> Δω·ln(1/Γ_m) ≤ π/(RC)

客戶那封信的每個字現在都是一個因子：Δω 是八度頻程，Γ_m 是 20 dB，RC 是負載的
誠實度。數字，我們的 12.5 Ω 負載掛上銲墊電容 C（第 3 小時全部印出）：

- C = 2.2 pF（客戶改版後的板子）：2–4 GHz 上可想像的最佳 RL = **78.96 dB**。
  規格物理可行；剩下的問題是我們的。
- C = 10 pF（客戶第一版板子）：可想像的最佳 RL = **17.37 dB**。20 dB 規格不是
  困難。是**不可能** — 沒有網路、沒有 N、沒有天才。
- 讓「八度頻程 20 dB」保持物理可行的最大 C：**8.686 pF**。

職涯技能直說：「老闆的規格違反一條定理」是一句能結束會議的話 — 前提是你算得
出來。談判恰有三個出口，一因子一個：縮 Δω、放寬 Γ_m、或修負載（縮 C）。作業
Q3 要你把那封信連數字寫出來。

兩條細則，先擋掉，因為尖的學生一定會問。第一：「78.96 dB 真的做得到嗎？」
不 — 這條界假設無限多個無損元件和磚牆式 |Γ|；真實有限網路把預算浪費在斜坡裙邊
上。這條界分開的是**不可能**與**可想像**；從不承諾**可達成**。第二：「我們的
轉換器負載是純 12.5 Ω — 它的天花板呢？」C = 0 → π/RC = ∞：沒有天花板，這正是
第一小時能無限用節買頻寬的原因。Bode–Fano 咬的是儲能的負載；電阻不儲。（真實
的 PA 銲墊永遠儲 — 所以客戶有三個負載模型。）

### 2.2 諧振器 — 諧振附近的 RLC，Q 推導兩次（1:16–1:30）

把交易反過來：第一小時和諧振作戰是為了拉寬頻帶；課程接下來**用**諧振蓋東西 —
濾波器（L8–9）是耦合諧振器，振盪器（L12）是帶增益的諧振器，本週作業的客戶
要替他的振盪器驗諧振器。

串聯 RLC 上黑板：Z_in = R + jωL + 1/(jωC)，在 ω₀ = 1/√(LC) 諧振。諧振附近，
ω = ω₀ + Δω：

> Z_in ≈ R + j·2L·Δω = R(1 + j·2Q_u·Δω/ω₀)

並聯 RLC 是嚴格對偶（Y_in ≈ G(1 + j2Q_uΔω/ω₀)）— 一套代數、兩種電路，而
**任何**單模諧振器在諧振附近都是其中之一。這就是作業敢丟給你三個天差地遠的
諧振器、卻只教一種萃取法的原因。

**Q，第一層 — 能量記帳（快版）。**

> Q = ω₀ ·（平均儲存能量）/（耗散功率）

串聯電路：Q_u = ω₀L/R = 1/(ω₀RC)。下標 u — **無載**（unloaded）— 諧振器
自己，只算自己的損耗。

**Q，第二層 — 極點位置（第一性原理），當作第一層的解釋。** 電路的自然響應是
極點對 s = −α ± jω_d，α = R/2L：敲一下諧振器，能量以 e^{−2αt} = e^{−ω₀t/Q_u}
衰減。Q 數的是能量掉到 1/e 之前振了多少弧度 — Q_u = ω₀/2α。把這段衰減震盪做
傅立葉轉換，得到洛倫茲線形（Lorentzian），其**半功率全寬 Δω = ω₀/Q** —
3-dB 法不過是從頻譜上讀出極點的實部。2.4 節的每個量測陷阱，都是弄髒這句
無辜的話的一種方式。

隨身帶的數字（它們就是作業三個資料集的化身）：微帶諧振器住在 Q_u ~ 100–200
（輻射 + 導體 + FR-4 的 tan δ）、同軸約 500–1000、機械加工腔體 10⁴ 起跳。
有人替印刷諧振器報「Q = 20,000」時，一定有人錯了。

### 2.3 傳輸線諧振器 — λ/2 與 λ/4（1:30–1:38）

微波諧振器的實體出身：第 2 講的駐波，現在是故意留下的。開路 λ/2 線在諧振附近
長得像 — 考一下全班：ℓ = λ/2 時開路反射回開路，兩端電流節點，阻抗極大 —
**並聯**型。短路 λ/4 線：基頻附近也是並聯型；短路 λ/2 則是串聯型。每次的對映
法：算 Z_in(ω₀ + Δω)、展開正切、和 R(1 + j2QΔω/ω₀) 模式比對 — 第 2 講的正切
變換來做諧振器班。

值得框起來的結果，從低損短路 λ/2 線的展開（Z_in = Z₀(αℓ + jπΔω/ω₀)）：

> Q_u = β/(2α) — 線的相位常數除以兩倍損耗。

這樣讀：Q 是**儲存的波比上損失的波**，它瞬間為技術標價。FR-4 上的銅微帶在
2.5 GHz：α ≈ 2–3 dB/m，tan δ 主導 → Q ~ 10²。空氣介質同軸：Q ~ 10³。鍍銀
腔體（α 只剩壁電流）：Q ~ 10⁴。這就是作業的資料集 A、B、C — 合成的，但它們
的 Q 是照這些技術鑄的。

先擋掉：「λ/2 都能做，要 λ/4 諧振器幹嘛？」銅省一半，而且短路端是免費的散熱
與機械錨點 — combline 濾波器的主力。λ/2 的美德是不用接地過孔。是技術選擇，
不是物理。

### 2.4 耦合 — Q_u、Q_L、Q_e，以及量測如何說謊（1:38–1:48）

填滿最後十分鐘的不舒服真相：**Q_u 無法直接量**，因為量測就是耦合，而耦合增加
損耗。讓能量進得來的探針、環圈或間隙，也讓能量出得去。

定義，框起來：

> 1/Q_L = 1/Q_u + 1/Q_e — 負載（loaded）、無載（unloaded）、外部（external）。
> 耦合係數 κ = Q_u/Q_e；臨界耦合（critical coupling）κ = 1。

穿透式耦合諧振器的掃頻 |S21| 給你什麼：諧振的 3-dB 寬度給 **Q_L** — 諧振器
**加上**儀器。峰值穿透告訴你儀器占多少：對稱耦合時，

> |S21(f₀)| = 1 − Q_L/Q_u ⇒ Q_u = Q_L/(1 − |S21(f₀)|)，|S21| 用**線性值**。

兩個極限唸出聲。弱耦合：|S21(f₀)| → 0（插入損耗巨大），Q_L → Q_u — 誠實但
吵雜的區域。強耦合：|S21(f₀)| → 1（插入損耗極小），Q_L 崩落到遠低於 Q_u —
諧振看起來**寬**，不是因為諧振器差，是因為你的測試機台焊在它身上。諧振時
插入損耗 0.35 dB 的諧振器，|S21| = 0.96：其無載 Q 是量到的 3-dB Q 的
**25 倍**。那個 25 倍就是作業的資料集 C，也就是這個：

戰場故事，90 秒：某實驗室驗收濾波器腔體 — 規格 Q_u ≥ 8000。技師用兩個健康的
耦合環掃它（軌跡漂亮、插損低、SNR 很棒），讀 3-dB 寬度，算出 Q = 500，整批
判退。供應商來回兩週後，有人問了一句諧振時的插入損耗：0.4 dB。技師**為了
好 SNR** 選的環圈，把腔體加載了 20 倍；Q_u 約 11,000，那批貨是好的。探針是
電路的一部分。量到的每個 Q 都是 Q_L；Q_u 是**推論**出來的，而推論需要
|S21(f₀)| — 所以第 3 小時的蓄意 bug 和作業的陷阱資料集，都吊在同一個被跳過
的修正上。誠實報告的守則：**沒附耦合的 Q，不是量測。**

### 2.5 本小時回顧（1:48–1:50）

Bode–Fano 給每個負載簽發 π/RC 的匹配預算 — 攤在 Δω 上、花在 ln(1/Γ_m) 的
深度；10 pF 的銲墊電容讓客戶的規格成為定理違規（17.37 < 20 dB）；諧振器在
諧振附近全是 RLC，Q = ω₀/2α 是同一個極點實部的三種讀法；而掃出來的每個 Q 都
是 Q_L，要靠 1 − |S21(f₀)| 才能贖回 Q_u — 本週這個修正值 25 倍。第 3 小時
把這一切印出來。

**休息（1:50–2:00）。**

### 3.7 蓄意 bug — 把 Q_L 報成 Q_u（2:42–2:46）

Cell 3.7，第 1–2 小時預告的 bug：拿 3.6 完全正確的 Q_L = 250，**當作諧振器的
Q 報出去**。什麼都沒崩；250 是個合理的 Q。然後修正印出：Q_u = Q_L/(1 −
|S21(f₀)|) = 250/(1 − 0.50) = **500** — 差的恰好是耦合，這裡 ×2，作業的腔體
**×25**。同格第二刺：公式要 |S21| 的**線性值**；餵 dB 進去就是除以
(1 − (−6.02))，發明一個胡說的 Q。習慣：每個 Q 旁邊寫上耦合，每個幅度標明
線性或 dB — 第 1 講的命名紀律，回來收第二次帳。

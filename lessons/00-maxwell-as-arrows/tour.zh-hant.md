## 0.0 主角們 — 四條方程式，一次講清楚

本章（乃至全課程）的一切都是對四行式子的註解。這裡把它們的兩套服裝並列 —
**微分形式**（在一點上成立）與**積分形式**（對你畫的任何迴路或封閉面成立）—
並各附一句白話讀法，其餘各節逐一展開：

| 名稱 | 微分形式 | 積分形式 | 讀作 |
|---|---|---|---|
| 高斯定律（電） | ∇·D = ρ | ∯ D·dA = Q_enc | E/D 的場線自正電荷出發、終止於負電荷 |
| 高斯定律（磁） | ∇·B = 0 | ∯ B·dA = 0 | B 的場線永不終止 — 磁荷不存在（§0.6） |
| 法拉第定律 | ∇×E = −∂B/∂t | ∮ E·dl = −dΦ_B/dt | E 繞著*變化中的*磁通量打轉，方向與變化作對 |
| 安培–馬克士威定律 | ∇×H = J + ∂D/∂t | ∮ H·dl = I_enc + dΦ_D/dt | H 繞著電流打轉 — 傳導的（J）或位移的（∂D/∂t） |

**積分形式的速記怎麼讀。** 兩條高斯定律在**封閉面**上積分（∯ — 一個盒子、
一顆氣球：任何「有裡面」的面），下標 **enc 意為「被包住」（enclosed）**：
Q_enc 是面內的總電荷。兩條旋度定律沿**閉合迴路**（∮）行走，並在以該迴路為
邊緣的任何**開放面**（把迴路當鼓框、面當鼓皮）上積分：

- **Φ_B = ∫ B·dA** — 穿過鼓皮的磁通量（韋伯）；
- **Φ_D = ∫ D·dA** — 穿過鼓皮的電通量（庫侖）；
- **I_enc = ∫ J·dA** — 穿過迴路的傳導電流（安培）— 這裡的「被包住」指
  *刺穿鼓皮*、與迴路互相勾連，像鑰匙圈穿著一枚環。

迴路方向與面法向量由右手定則（right-hand rule）綁定（四指沿迴路，拇指沿
dA）。這些 ∫F·dA 的「通量」積分是什麼意思，§0.2 專節處理；此刻先讀成
「有多少場穿過去」。

**先盤點單位再談相信** — 每個空間導數（∇）都除以一公尺，兩邊必須對帳：

| 方程式 | 場的單位 | 兩邊 |
|---|---|---|
| ∇·D = ρ | D: C/m² | → C/m³ — 體積電荷密度 ✓ |
| ∇·B = 0 | B: Wb/m² | → Wb/m³ = 0 ✓ |
| ∇×H = J + ∂D/∂t | H: A/m | → A/m² = J ✓；∂D/∂t: (C/m²)/s = A/m² ✓ |
| ∇×E = −∂B/∂t | E: V/m | → V/m²；∂B/∂t: (Wb/m²)/s = V/m² ✓ |

盤點本身瑣碎，副產品卻不瑣碎：curl H 帶著 J 的單位，是斯托克斯定理
（Stokes' theorem）的變裝（每面積的環流必須是每面積的安培 — §0.4 把這句話
做成精確）；而 ∂D/∂t 是唯一帶著 J 單位、能在沒有電荷流動之處撐住安培定律的
東西 — 馬克士威的位移電流（displacement current），靠記帳被找出來。

**符號的演員表**，附單位：

| 符號 | 名稱 | 單位 |
|---|---|---|
| E | 電場 | V/m |
| D = εE | 電通量密度 | C/m² |
| H | 磁場 | A/m |
| B = μH | 磁通量密度 | T = Wb/m² |
| J | 電流密度（§0.1–0.2；導體內 J = σE） | A/m² |
| ρ | 電荷密度 | C/m³ |

符號表右側的三條 — **D = εE、B = μH、J = σE** — 是組成關係式
（constitutive relations）：馬克士威方程組刻意對材料視而不見，ε、μ、σ 就是
基板、鐵氧體、銅接上物理的插座。第 5 講住在 ε 裡；其損耗住在 σ 裡；§0.1 的
Drude 模型則是 J = σE 的*出身*。

使用之前，三個觀察，各自長成一節：

1. **兩欄說的是同一件事，只是尺寸不同。** 積分形式在你選的迴路與面上數
   總量；微分形式是把總量縮到一點、除以體積或面積 — 散度是每體積的通量
   （§0.3），旋度是每面積的環流（§0.4）。高斯散度定理與斯托克斯定理是兩欄
   之間的兩部電梯。
2. **右邊是源，左邊是被逼出來的場行為。** 電荷讓場線終止；電流（或變化的
   D）讓場線纏繞；變化的 B 讓 E 反向纏繞；而沒有任何東西能讓 B 的場線終止，
   永遠沒有。§0.5 的箭頭規則，全部內容就是這一句 — 方程式*就是*規則。
3. **有一個空位空得刺眼。** 法拉第定律裡沒有與 J 對稱的磁流項，而高斯（磁）
   的零就是原因。這份對稱能不能用租的 — 是 §0.6 的故事。

*（記號說明：本課程把場寫成 (E, H) 一對、通量密度寫成 (D, B) 一對 — Pozar
的慣例，在材料邊界上自然（切向連續的是 E、H）。物理教科書常偏好 (E, B)；
下文一切不依賴這個選擇。）*

## 0.1 一安培裡的三種速度

讓 1 A 流過 1 mm² 的銅線，問一個天真的問題：*電流跑多快？*誠實的答案是：這
句話裡藏著三種截然不同的速度，混淆它們是電機工程裡最常見的壞掉的直覺。

**速度一 — 漂移（drift）。** 銅每個原子貢獻一顆傳導電子：n = 8.49×10²⁸
顆/m³。電流是 I = n·q·v_d·A，所以撐起這一安培所需的淨載子速度是

> v_d = I / (nqA) = **7.35×10⁻⁵ m/s = 0.0735 mm/s。**

蝸牛都比它快。從牆上插座進線的一顆電子，要走 **3.8 小時**才能穿過一公尺。

**速度二 — 熱攪動。** 單顆電子其實*很快* — 銅的費米速度約 1.57×10⁶ m/s —
但方向隨機、彼此抵銷。漂移是疊在這鍋攪動之上約 10⁻¹⁰ 量級的偏置：一大群
幾乎察覺不到地朝同一方向挪動的人潮，因為人潮天文數字般龐大，每秒仍搬運一
庫侖。

**速度三 — 訊號。** 改變源端，遠端多快知道？在 RG-58 級的傳輸線上
（L′ = 250 nH/m，C′ = 100 pF/m）：

> v = 1/√(L′C′) = **2.00×10⁸ m/s = 0.667 c。**

訊號 5.0 ns 就跨過那一公尺 — 比漂移快 **十二到十三個數量級**（實測比值
2.7×10¹²）。

![三種速度，以及把電流打開的波前](figures/fig01_speeds.png)

**三者如何共存 — 機制分三步：**

1. **導線本來就是滿的。** 電流不需要電子從電源走到負載；它需要*沿線各處*
   的電子海同時開始蠕動。一條已灌滿水的水管，龍頭一開、噴嘴幾乎立刻出水 —
   跑過水管的是壓力波，不是你剛灌進去的水。
2. **跑得快的是場，而且它跑在銅的外面。** 一層薄薄的表面電荷重排沿著導體
   飛奔，在每一點建立起 E；那個「電荷加場」的圖樣是被導體引導、卻活在導體
   *之間的介質裡*的電磁波 — 所以 v 由絕緣材料決定（1/√(L′C′)），與金屬本身
   無關。
3. **本地反應實質上是瞬間的。** 銅的 Drude 弛豫時間 τ = mσ/(nq²) =
   **2.5×10⁻¹⁴ s**；場一到，漂移在 ~5τ ≈ **125 飛秒**內就緒。所以漂移是
   *沿線依序*被打開的，以波速推進、本地延遲可忽略 — 電流以 0.667 c「出現」
   在遠端，而任何帶電的東西從頭到尾不超過慢走的速度。三個命題、三種速度，
   毫無矛盾。

**這些數字會在哪裡回來** — 本節其實是全課程第一個電磁波，只是沒有掛牌：
第三種速度*就是*第 2 講的 v = 1/√(L′C′) = c/√ε_eff，是課程裡每個導波波長、
每段殘段長度、每個電氣長度背後的相速度；而那個飛秒級的 τ，是整套「良導體」
框架的許可證 — 在 10 GHz，一個射頻週期約 4000τ，電子海跟隨場如同無質量，
J = σE 可以用直流的 σ，導體邊界條件（§0.5 規則 5）在每個微波頻率都站得住 —
這筆交易要到 ω 逼近 1/τ 的光學頻段才會失效。至於漂移速度那個數字，之後
再也不出現：它的任務是拆除 — 把「訊號由電子搬運」的模型拆得夠徹底，
另外兩個數字才有人肯信。

*（上面的 τ 出自 Drude 模型 σ = nq²τ/m — 歐姆定律的微觀出身，也是第 5 講
集膚效應的出身。屬於加菜、不是先修：課程只需要結論 — 本地反應是瞬間的，
在路上跑的是波。）*

## 0.2 通量是一個積分，不是一種運動

「通量」（flux，拉丁文 *fluxus*，流動）這個詞暗示有東西在流。把暗示剝掉：
對任何向量場 F，**穿過一個面的通量**是

> Φ = ∫ F·dA

— 「有多少 F 穿過這個面，方向計入」— 而 F 本身就是**通量密度**（每面積的
被積量）。這個詞命名的是*積分的形狀*，不是任何實體運動。磁通量 ∫B·dA 穿過
線圈時，沒有任何磁性物質在移動；安培計上那個平凡的 I，其實一直都是
∫J·dA — 電流密度穿過導線截面的通量。

徒手驗算一次。均勻的 J = 2 A/mm² 穿過半徑 1 mm 的圓盤：

| 圓盤方位 | 通量（實測） |
|---|---|
| 垂直 | I = J·A = **6.2832 A** |
| 傾斜 60° | I = J·A·cos 60° = **3.1416 A**（數值面積分：3.1402） |

同一個場、同一個盤 — 通量變了，因為通量量的是*場穿過面的幾何*。沒有任何
東西動得不一樣。

![通量數的是穿過面的場](figures/fig02_flux.png)

**一個詞為何伺候這麼多主子。** 這個模板你每週都會用：

| 量 | 通量密度（每 m²） | 它的通量（那個積分） |
|---|---|---|
| 電荷輸運 | J (A/m²) | 電流 I |
| 磁場 | B (T = Wb/m²) | 磁通量 Φ — 法拉第定律 |
| 電場 | D (C/m²) | 高斯定律數的包住電荷 |
| 功率 | 坡印廷向量 S (W/m²) | 穿過面的功率 |
| 雷達照射 | P_tG/4πR² (W/m²) | 被雷達截面積 σ 攔截的功率 |

最後一列就是第 1 講的雷達方程式：「目標處的功率密度」是功率通量密度，
「目標攔截其中 σ 的份額」是對等效面積的通量積分。高斯與 Friis，同一套文法。

**先拆除一個命名地雷：** 電磁學另有一個貨真價實的*面電流密度* K（A/m）—
束縛在薄片上的電流，見於集膚效應的理想化與邊界條件。注意單位：每公尺薄片
*寬度*的安培，是*在*面上的電流。J（A/m²）是*穿過*面的電流。兩個不同的
物件 — 這也是沒有人把 J 叫做「表面密度」的原因。

## 0.3 散度是通量密度

§0.2 定義了穿過「你選的面」的通量。把面封起來 — 盒子、氣球、任何有裡面的
外殼 — 問*淨往外*的通量。散度就是這個量縮到一點：

> ∇·F = lim_{V→0} (1/V) ∯ F·dA

— **每單位體積的外流量**：源的偵測器。§0.4 的槳輪問「場在這裡*打轉*嗎？」，
散度問「這裡的小氣球會不會*膨脹* — 這一點有沒有場被生出來？」散度為正：
場線在此誕生（源）。為負：在此消亡（匯）。為零：進多少、出多少。

接著是校準眼睛的示範 — §0.4 渦旋的嚴格對偶。取全物理界*看起來*最發散的
場，點電荷的 E = r̂/r²，對封閉盒子做數值通量積分（`tour_numbers.py 0.3`）：

| 封閉面 | 淨外流通量 |
|---|---|
| 包住電荷的立方體，邊長 1 | **12.5664** = 4π |
| 包住電荷的立方體，邊長 4 | **12.5664** = 4π — *任何*尺寸 |
| 在 (3, 0, 0) 的立方體，電荷在外 | **−0.0000** |
| 在 (2, 0, 0) 的縮小盒：通量/體積 | −3.5×10⁻⁸ → 0 |

![三維幾何，以及「不隨尺寸變」為何是三維的事](figures/fig07_divergence.png)

這張表請讀兩遍。那團箭頭*看起來*處處發散 — 但離開電荷，散度精確為
零：場線幾何上的散開，被場強 1/r² 的減弱一分不差地抵銷。凡是不含電荷的
盒子，進去的每一條線也都出來。全部 4π 的外流集中*在電荷那一點* — 而且包住
它的盒子不論大小形狀，通量都是 4π。你剛剛用數值方法發現了高斯定律：
∯D·dA = Q_enc，也就是 ∇·D = ρ 的積分孿生。

**留意維度 — 這是一句不折不扣的三維陳述。** 上表的盒子是立方體，通量是對
全部六個*面*加總的（`tour_numbers.py` 算的正是這個）；圖的左半就是真實的
三維幾何。抵銷之所以成立，是因為球面的*面積*隨 r² 增長、場隨 1/r² 減弱 —
所以在三維裡，1/r² 是**點**源之外唯一無散度的徑向衰減。換掉源的形狀，
平衡就自行重調：繞著無限長的**線**電荷，包圍面像圓柱側面一樣隨 r 增長，
無散度的場因此是 **1/r** — 正是同軸線兩導體之間的 E（第 2 講，以及 §0.5
的算例）；繞著無限大的帶電**平面**，包圍面積根本不長，場是**常數**。
點 → 1/r²、線 → 1/r、面 → 1/r⁰：一條定律、三種幾何 — 而第一種正是第 1 講
Friis 功率密度隨 1/R² 衰減的原因。（提防扁平的示意圖：在一個真正二維的
世界裡，1/r² 的場*不會*無散度 — 它穿過圓的通量是 2π/R，隨尺寸縮水，
如圖右半所示。）

要背起來的一對，因為 §0.4 馬上補完它：

- **散度** = 每體積的通量 → 場線*終止*之處的源（對 D 而言是電荷）。點電荷
  的場：離源處處無散度，4π 全數集中在源上。
- **旋度** = 每面積的環流 → 場線*繞著轉*的源（對 H 而言是電流）。§0.4 導線
  的場：離軸處處無旋度，2π 全數集中在軸上。

而第二條高斯定律 ∇·B = 0，現在讀起來是物理而非記號：*任何地方、任何大小的
氣球，磁通量永遠收支平衡* — B 的場線沒有出生地，只好自我閉合。這正是
§0.6 那個空位，用散度說了一遍。

## 0.4 旋度是環流密度

∇× 的寫法長得像外積（cross product），會引誘出一個錯誤結論（場必須垂直於
自己的旋度 — 見 §0.5）。旋度真正是什麼，用不依賴座標的話說一次：

> (∇×F)·n̂ = lim_{A→0} (1/A) ∮ F·dl

沿著法向量為 n̂、面積為 A 的小迴路走一圈 F；環流除以面積；縮小。旋度只回答
一個問題：*在這裡放一個無窮小的槳輪（paddle wheel），軸朝哪個方向轉得最快、
每單位面積轉多猛？*向量沿著那根軸（右手定則）；寫法裡的「叉」是場的導數之
反對稱部分的記帳法，不是兩支實體箭頭的幾何外積。

兩個流場，用真的走迴路算出來（`tour_numbers.py 0.4`），比任何公式更能校準
直覺：

**剪切流 v = (2y, 0) — 流線筆直如尺。**

| 迴路半邊長 | 環流 / 面積 |
|---|---|
| 0.40 | −2.0000 |
| 0.10 | −2.0000 |
| 0.01 | −2.0000 |

沒有任何東西轉彎，槳輪卻在轉（上緣的槳被推得比下緣重）：**旋度 = −2，
處處如此。**直的流可以有旋度。

**渦旋流 v = φ̂/r — 萬物肉眼可見地繞圈。**

| 迴路 | 環流 |
|---|---|
| 不含軸，半邊長 0.20 | /面積 = +2.1×10⁻⁸ ≈ 0 |
| 不含軸，半邊長 0.05 | /面積 = +1.3×10⁻⁹ ≈ 0 |
| 包住軸，R = 0.3 | 6.28319 = 2π |
| 包住軸，R = 1.0 | 6.28319 = 2π — *任何* R |

繞圈的路徑，離開中心卻**旋度為零** — 槳輪*沿著*圓圈旅行，卻不繞自己的軸
自轉（內側槳快、外側槳慢，恰好抵銷）。全部的環流 — 不論迴路多大都是 2π —
集中在軸上。

![剪切流會轉，渦旋不會](figures/fig03_curl.png)

把剛算完的東西用電磁的語言再說一次：v = φ̂/r **就是直導線的磁場**
（H = I/2πr φ̂）。除了軸上處處無旋度 — *而電流就在軸上*。那個「每包住一次
軸就是 2π」的常數，就是安培定律 ∮H·dl = I_enc，被數值方法發現。旋度偵測的
是*局部自轉*，而導線的場只在導線內部、只在 J 所在之處局部自轉。

## 0.5 箭頭上工 — 以及它們需要監督的那一天

把閱讀規則收攏，每一條都是一句被定性閱讀的馬克士威方程式：

| # | 規則 | 出處 |
|---|---|---|
| 1 | E/D 場線自 + 出發、終於 −，絕不自行成圈 | ∇·D = ρ |
| 2 | B/H 場線永不終止 — 自我閉合 | ∇·B = 0 |
| 3 | H 纏繞 J（與 ∂D/∂t），右手定則 | ∇×H = J + ∂D/∂t |
| 4 | E 纏繞 −∂B/∂t，方向與變化作對（楞次定律） | ∇×E = −∂B/∂t |
| 5 | 良導體表面：E 垂直落地，H 平行奔跑，兩者都死在體內 | 邊界條件 |
| + | 場繼承源的對稱性 | 協變性 |
| + | S = E×H 指向功率去的地方 | 坡印廷向量 |

**招牌示範：三句話用箭頭解掉一條同軸線。** E 必須從導體走到導體（規則 1）
— 徑向。H 必須纏繞中心電流（規則 3）— 環向。S = E×H — 軸向，*順著電纜走*：
功率在介質裡流動；銅只負責引路。接著讓數字替箭頭的宣稱背書
（`tour_numbers.py 0.5`）：空氣同軸線 a = 1 mm、b = 2.301 mm
（Z₀ = 50.000 Ω），V = 10 V、I = 0.2 A：

> 電路理論：P = VI = 2.00000 W
> 場理論：對*介質*截面積分 ∫(E×H)·dA = **2.00000 W**（Δ = 7×10⁻¹² W）

電路交付的每一瓦，都從絕緣層裡通過。箭頭不是卡通，箭頭就是答案。

![用箭頭讀同軸線；坡印廷密度分布](figures/fig04_coax.png)

**傾斜的線圈：箭頭對座標免疫。** 半徑 5 cm、1 A 的電流圈，圓心處
B = μ₀I/2R = 12.57 μT，沿線圈自己的軸（線圈的旋轉對稱不容許任何側向分量 —
繞軸轉動整個裝置，側向的 B 會與一模一樣的源矛盾）。把線圈斜 45°，*分量*
變了，(0, 0, 12.57) → (8.89, 0, 8.89) μT，但箭頭仍釘在線圈軸上，|B| =
12.57 μT 動也不動。分量是記帳；箭頭是物理。若一個計算在你旋轉座標時改變了
場*與源的關係*，錯的是計算。

**以及監督條款 — 理髮店旋轉柱。** 規則 3 說 H 纏繞導線；光桿導線因此
H ⊥ J。現在把導線滑進螺線管（solenoid）的軸心（`tour_numbers.py 0.5`）：

| 螺線管場 H_z | 總場偏離軸的傾角 |
|---|---|
| 0 | 90.0°（純圓環） |
| 31.83 A/m（= 5 mm 處的 H_φ） | 45.0° |
| 95.49 A/m | 18.4° |

總場成了螺旋線 — 繞著導線的理髮店旋轉柱 — 而 J 一動未動、∇×H 一分未變
（螺線管內部的場在此區域無旋度）。**旋度是線性的：加上一個無旋度的場，
會把 H 轉走，卻碰不到它的旋度。**所以「場垂直於自己的旋度」從來不是定理，
只是光桿導線幾何養成的習慣；而讀箭頭這門手藝附帶一條紀律：*先清點所有的源
與邊界，再相信任何方向*（亥姆霍茲：場由它的旋度**加**散度**加**邊界共同
決定 — 不是旋度單獨決定）。

![理髮店旋轉柱：H 轉了，curl H 沒動](figures/fig05_barberpole.png)

**箭頭止步、算術上場之處。** 大小 — 永遠要算，沒有一張草圖畫得出 92.45 dB。
低對稱的疊加 — 草圖的*性格*仍對，精確向量得靠積分。以及一切與相位有關的
事 — 兩支畫得全對的箭頭仍可能相消；第 13 講陣列因子的每一個零點正是如此。
先畫，抓出錯的拓撲；再算，因為客戶買的是分貝，不是箭頭。

## 0.6 空位 — 磁流

把兩條旋度方程式並排，盯著那個不對稱：

> ∇×H = **J** + ∂D/∂t
> ∇×E = **?** − ∂B/∂t

完美的對稱會在空位放一個*磁流密度* M — 磁荷的流動，E 繞著它轉、一如 H 繞著
J 轉，它的荷會讓 B 場線終止（∇·B = ρ_m）。那時方程組將在 E→H、H→−E、
J↔M、ε↔μ 之下完全對偶（duality）。

**自然把空位空著。** 孤立的磁荷從未被觀測到：每塊磁鐵切開都是兩塊更小的
偶極，∇·B = 0 在每一次量測中成立，專門的磁單極（magnetic monopole）搜尋
一無所獲。（狄拉克 1931 年的安慰獎：只要宇宙中存在一顆磁單極，量子力學就
強迫電荷量子化 — 而電荷確實量子化了。）所以在物理裡，∇×E = −∂B/∂t：E 繞
著*變化*打轉，不繞任何電流。

**工程界照樣把空位租下來。** 天線理論的等效原理（equivalence principle）
把口徑面上的場換成虛構的片電流 — 電的 J_s = n̂×H 與**磁的 M_s = −n̂×E** —
外部的場分毫不差。沒有人宣稱磁單極在流動；M 是記帳。回報是整個口徑天線
家族：**槽孔天線**（slot antenna，金屬片上一道細縫、E 橫跨縫口）被當成
沿縫的磁偶極電流來分析，由巴比涅原理（Babinet's principle）與互補的線
偶極對偶 — 真實雷達上波導槽孔陣列就是這樣設計的。一個小電流圈，從遠處看
*就是*一小段磁流元 — 這就是它被叫做磁偶極的原因。

**而自然雖然不擁有磁流，卻真的蓋出了那個「會載磁流」的場。** 要求一個場
處處*平行*於自己的旋度 — ∇×B = αB，**無力場**（force-free / Beltrami
field），對「垂直」直覺的終極反駁。圓柱解是 Lundquist 磁通量繩，
B = (0, J₁(αr), J₀(αr))，貝索函數寫成，可用有限差分驗證
（`tour_numbers.py 0.6`）：取 α = 1，

> max |∇×B − B| = **1.0×10⁻⁴**（網格解析度 — 恆等式本身精確）

| 半徑 r | 場偏離軸的傾角 |
|---|---|
| 0（核心） | 0.0° — 純軸向 |
| 1.0 | 29.9° |
| 2.0 | 68.8° |
| 2.404（繩緣） | 90.0° — 純環向 |

電流全程*沿著*盤旋的場線流（J ∥ B，磁力 J×B = 0 — 故名「無力」）。這不是
珍奇標本：實驗室的湍流電漿會自發弛豫到這個狀態（泰勒弛豫，在球馬克與
反場箍縮裝置中實測），而日冕物質拋射掠過太空船時，磁力計曲線一次又一次
擬合出 Lundquist 繩。

![無力繩：curl B 平行於 B](figures/fig06_lundquist.png)

## 0.7 把運算子練成自己的 — 八個招式

本章該把一句實話說明白：如果你把散度定理與斯托克斯定理的證明「讀過很多遍」、
感覺卻始終沒有來 — 問題不在你，藥方也不是再讀一遍證明。運算子的流利是一種
**技能**，不是一件知識；它來自在具體場上的反覆使用 — 這正是本章每個主張都
落成一個數字的原因。進第 1 講之前要知道三件事：真正需要的工具箱有多小、
兩大定理為何無感（以及治好它的換框），還有怎麼練。

**工具箱只有八個招式 — 本課程用到的向量微積分全部在此：**

| # | 招式 | 在哪裡遇過 |
|---|---|---|
| 1 | 三個極限定義：梯度 = 最陡坡度、散度 = 每體積外流量、旋度 = 每面積環流 | §0.3、§0.4 |
| 2 | 在具體場上求值（直角座標配方；對稱允許時用圓柱／球座標） | §0.3–0.5 |
| 3 | 兩條恆零恆等式 ∇·(∇×A) = 0 與 ∇×(∇φ) = 0 — 各有物理面孔（位勢為何存在；電荷為何守恆） | 連續方程式、§0.5 規則 1 |
| 4 | 旋度的旋度恆等式 ∇×(∇×A) = ∇(∇·A) − ∇²A（推出 Biot–Savart 與波動方程式） | 第 1 講的參考資料 |
| 5 | 散度定理 + 斯托克斯定理，讀成**記帳**（見下） | §0.0 的「兩部電梯」 |
| 6 | 格林函數招式：∇(1/R) = −R̂/R²，以及把 δ 看成縮小的抹開源 | §0.3 的點電荷 |
| 7 | 縮小的藥盒與跨面小迴路（導體邊界條件） | §0.5 規則 5 |
| 8 | 把每個結果讀回箭頭規則 | §0.5 |

Pozar 第一章的每個推導都分解成這八招，再無其他。「先把向量微積分整個學透」
是把範圍畫大了；正確的路是**在電磁學裡面**、按需要，把八招練熟。

**兩幅相消圖像** — 把兩大定理從「令人吃驚的事實」變成「你本來就會猜到的事」
的那次換框。把*極限定義*（招式 1）當成定義，然後：

- **散度定理：**把體積鋪滿小盒子。每個*內部*的面，對一個盒子是出口、對鄰居
  是入口 — 這些通量**成對相消**。沒有搭檔的面只剩最外層的皮。「局部外流量
  之和 = 穿過外皮的外流量」是一條望遠鏡式相消的和，幾乎是同義反覆。
- **斯托克斯定理：**把鼓皮鋪滿小迴路。每條*內部*的邊都被走過兩次、方向相反
  — 相消。只剩鼓框。「局部環流之和 = 沿鼓框的環流」。

如果這兩條定理曾讓你覺得神祕，那是因為座標公式僭越了定義的位子；把它降回
本職 — 求值配方 — 定理就只是記帳。

**練功方法**（就是本章自己的方法，取了名字）：

1. **養一座場動物園。** 均勻場 · r̂/r²（點源）· φ̂/r（導線）· 剪切場
   (ky, 0, 0) · 螺旋線。五個場。每個新運算子、恆等式、主張，都拿全園測一遍
   — 手算容易就手算，不容易就十五行 numpy（`tour_numbers.py` 是園裡第一個
   獸籠，儘管擴建）。
2. **先預測，再驗證。** 計算之前先押注 — 「這裡旋度為零；那裡沿 ŷ 非零；
   靠近導線更大」— 然後跑。押錯並弄清為什麼，感覺就在那裡長出來。（這正是
   本課程作業對學生的預測先行紀律；拿來對自己用。）
3. **每條恆等式配一張物理面孔。** ∇·(∇×) = 0 *就是*電荷守恆；斯托克斯
   *就是*安培迴路定律；藥盒*就是*表面電荷邊界條件。有面孔的恆等式記得住；
   光禿禿的會蒸發。
4. **拆小步不是繞路，就是學習本身。** 把推導拆成很多小步感覺像發散 — 不是，
   因為每一步都出自上面那個有限的招式集，所以每拆一次，下一次就更短
   （組塊化，如同視譜）。全解析度拆五個典型推導就夠：高斯／點電荷（§0.3）、
   迴路上的法拉第、由靜磁兩式反解 Biot–Savart、由旋度的旋度得波動方程式、
   導體邊界條件。做完這五個，任何教科書第一章裡都沒有你沒出過的招。

**本章不夠用時，往哪裡去：**

- [R41] Schey，*Div, Grad, Curl, and All That* — 正是為這個缺口寫的：用靜電學
  教運算子、極限定義優先，約 150 頁、口吻不拘。標準藥方，一個週末讀完。
- [R42] 費曼物理學講義第二卷第 2–3 章（線上免費）—「物理學家如何把這些
  運算子放在腦子裡」，以熱流為貫穿全文的具體場。
- [R43] Purcell & Morin，*Electricity and Magnetism* 第 2 章 — 出版品中圖像
  最豐富的散度／旋度講法。
- [R44] 3Blue1Brown，"Divergence and curl"（影片）— 二十分鐘的流體視覺化；

## 帶進第 1 講的行李

1. **三種速度：**場在傳播（快，由介質決定）、漂移在響應（本地瞬間、速度
   龜爬）— 傳輸線追蹤的是波，電路理論追蹤的是人潮。差異從 λ/10 開始要緊，
   第 1 講會把那條線算出來。
2. **通量 = ∫F·dA**，一個模板從高斯用到雷達方程式。除非場本身是電流，
   否則沒有東西在流。
3. **散度 = 每體積的通量，旋度 = 每面積的環流** — 氣球與槳輪，兩具源偵測
   器：4π 集中在電荷上（高斯）、2π 集中在導線上（安培），都是數值走出來
   的；除此之外處處為零，不管場*看起來*多發散、多會繞圈。（另外：任何場
   方程式先盤點單位 — ∇ 永遠花掉一個 1/m。）
4. **七條箭頭規則**三句話解掉同軸線的功率流，也是第 2–13 講每張模態圖的
   畫法 — 但要守亥姆霍茲紀律：先清點所有源（不守的話，理髮店旋轉柱在
   等你）。
5. **空位：** E 繞的是變化、不是電流；磁流是自然的缺席、天線工程師最好用
   的虛構 — 你會在第 13 講參考文獻的每一道槽孔與口徑上再遇到 M。

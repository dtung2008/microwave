## 第一小時 — 原理 I：規格、方法，與兩種經典形狀（0:00–0:50）

### 1.1 接收機的大門（0:00–0:10）

投影片提示：60 MHz 中頻（IF, intermediate frequency）鏈路和它的鄰居 — 想要的頻帶
兩側，35 MHz 蹲著鏡像頻帶（image band）、85 MHz 蹲著同址的 VHF 發射機。

從客戶開場，不從數學開場。第一講的課程雷達把 10 GHz 的回波混頻到 60 MHz 的中頻 —
為什麼是 60，第 12 講會教；但後果今天就到：中頻鏈路住在治安不好的街區。頻率規劃
把兩個已知的干擾源停在 ±25 MHz 處 — 第二混頻器的鏡像頻帶在 35 MHz、同址 VHF 通訊
鏈路在 85 MHz — 而且兩個都比 4 公里外無人機的回波**強**。在作業一精算過的 1 MHz
偵測頻寬有任何意義之前，得先有東西把鄰居殺掉、又不碰到頻帶本身。那個東西，就是
這一講。

規格語言 — 三個數字，你此生每一次濾波器對話都用它們：

- **通帶漣波（passband ripple）：** 你承諾要放行的頻帶裡，最糟的衰減。我們的規格：
  55–65 MHz 內 ≤ 0.5 dB。（漣波會晃；規格管的是它的天花板。）
- **阻帶抑制（stopband rejection）：** 你承諾要殺掉的頻率上，最少的衰減。我們的
  規格：35 與 85 MHz 處 ≥ 40 dB。
- **群延遲（group delay）：** 每一片頻譜穿過濾波器要多久 — 振幅圖藏起來的相位規格。
  第二小時講雷達為什麼在乎。

今天的三個主張 — 寫在黑板上，留到下課：

1. **所有梯形濾波器都是同一個濾波器。** 你只設計一樣東西 — 截止 1 rad/s、兩端 1 Ω
   的低通原型（lowpass prototype）— 其餘每一種通帶形狀、阻抗、中心頻率、頻寬，
   都靠機械式代換抵達。這套架構就是**插入損耗法**。
2. **漣波是貨幣。** 允許通帶晃到 0.5 dB 的天花板，買到更陡的裙邊 — 今天實測匯率：
   同階數多 11.7 dB 的抑制，或者同規格省下一整節。
3. **帶通的中心是幾何平均 √(f₁f₂)** — 不是算術平均 — 第三小時故意蓋一座錯的，
   讓你看看忘記這件事時，濾波器失敗得多有禮貌。

先擋掉 DSP 背景同學正在成形的問題：「Butterworth 和 Chebyshev 我在訊號課做過 —
這是複習嗎？」多項式是老朋友。新的是：我們的濾波器必須是**電路** — 一座無源、
雙端接載的 LC 梯形網路，元件值從多項式來，源和載是 50 Ω，缺陷是物理的。你今天算
的 g 值，下週是元件值 — 第九講是它們的微帶線後代。

### 1.2 插入損耗法 — 一部機器，四個站（0:10–0:20）

投影片提示：流水線 — 規格 → 原型 → 縮放 → 轉換 → 掃頻。

先定義設計對象。二埠在其端接之間的**功率損耗比**：

> P_LR =（源可用功率）/（送達負載功率）= 1/|S21|² — 而 IL = 10·log₁₀P_LR 就是
> **插入損耗（insertion loss）**（就是第四講的 |S21|，倒過來讀）。

插入損耗**法**，是「先把 P_LR(ω) 當數學來指定、再回頭找電路」這個決定。對物理
二埠，|Γ|² 是 ω 的偶函數，逼出 P_LR = 1 + M(ω²)/N(ω²) — 多項式之比。選多項式，
得響應；抽取電路，得濾波器。對照更老的鏡像參數法 — 串上一堆節、祈禱端接原諒你 —
做得出會動的濾波器，給不出保證的規格。插入損耗法說：先聲明你應得的響應，再合成
一座**可證明**在真實端接之間交付它的網路。

投影片上的四個站，因為它們就是作業的模組地圖：

1. **原型：** 低通梯形，截止 Ω = 1，源與載 ≈ 1 Ω，元件值 g₁…g_N 加負載 g_{N+1}。
   所有形狀決策都發生在這裡。
2. **阻抗縮放**到 50 Ω。3. **頻率轉換**到真實頻率上的低通／高通／帶通／帶阻。
4. **掃頻**你蓋的東西，把規格表從曲線上讀下來 — 人人想跳過、跳過必後悔的一站。

梯形的畫法，現在畫、用兩週：串聯電感 g₁、g₃…與並聯電容 g₂、g₄…交錯（或完全對偶 —
同一組 g 數字，角色互換），g₀ = 1 是源，g_{N+1} 是載。一座梯形，N 個電抗元件，
N 個 g 數字加一個載。

### 1.3 巴特沃斯（Butterworth）— 推導兩次（0:20–0:33）

**第一層 — 最平坦（maximally flat，快版）。** 要求通帶平到不能再平：
P_LR = 1 + Ω^(2N)。Ω = 0 處完美；Ω = 1 處永遠 3.01 dB（這是要背的**定義** —
巴特沃斯的帶緣就是它的 3 dB 點）；再往外，裙邊以每十倍頻 20N dB 下墜。P_LR 在
直流處前 2N−1 階導數全為零 — 所以叫**最平坦**。代價現在就看得見：所有的近似誤差
都囤積在帶緣 — 規格最鬆的地方。

**第二層 — 極點位置（第一性原理版）。** S21(s) 的極點必須坐哪？虛軸上
P_LR = 1 + (−s²)^N，所以 |S21|² 的極點解 (−s²)^N = −1：**單位圓上等間隔的 2N 個
點**，沒有一個在虛軸上。留左半平面的 N 個（穩定性替你選好了），N = 3 直接讀出：
s = −1 和 −½ ± j(√3/2)。這正是 `scipy.signal.buttap` 回傳的東西，第三小時就拿這個
恆等式當裁判。從極點出發，網路合成（1.4 的機器）交出一條值得框起來的閉式：

> g_k = 2·sin[(2k−1)π/2N]，k = 1…N，g_{N+1} = 1 — 永遠對稱，永遠端接 1。

用工程師的方式驗算：N = 1 說 g₁ = 2·sin(π/2) = 2。直接推導：1 Ω 源與 1 Ω 載之間
一顆並聯 C，|S21|² = 1/(1 + (ωC/2)²)；要求 ω = 1 處 3 dB，C = 2 掉出來。公式和
電路在你能手算的最簡單情形上一致 — 記住這個方法，1.4 在更難的條件下重演一次。
作業要用的 N = 4：0.7654、1.8478、1.8478、0.7654。第三小時印表。

### 1.4 切比雪夫（Chebyshev）— 漣波力學與遞迴（0:33–0:47）

投影片提示：N = 3 的巴特沃斯與切比雪夫同軸疊畫；等漣波帶著色。

等漣波的想法一句話講完：規格既然允許你在帶內錯 0.5 dB，那就**處處恰好**錯
0.5 dB — 把平坦囤在沒人要求的直流，是浪費裙邊本可以花掉的預算。工具是切比雪夫
多項式 C_N：在 [−1,1] 上於 ±1 之間振盪、出了區間就爆炸的那個多項式 —
帶內 C_N(Ω) = cos(N·arccos Ω)，帶外 cosh(N·arccosh Ω)，遞迴
C_{N+1} = 2Ω·C_N − C_{N−1}（講出來；DSP 同學會點頭）。於是：

> P_LR = 1 + ε²·C_N²(Ω)，其中 ε² = 10^(漣波/10) − 1。0.5 dB 時 ε = 0.3493。

帶內 P_LR 在 1 與 1+ε² 之間起伏 — N 個漣波極值，帶緣恰在漣波值上（N 為奇數時；
偶數的皺摺一分鐘後見）。帶外 C_N ≈ ½(2Ω)^N，裙邊比同階巴特沃斯高出
(2^(2(N−1))·ε²) 倍 — 差不多 6(N−1) dB。第三小時實測：同樣 0.5 dB 通帶、N = 3、
作業的阻帶頻率上：切比雪夫 40.52 dB，巴特沃斯 28.84 dB。**漣波買到 11.7 dB。**
這就是主張 2，帶著數字。

現在就擋掉那個寫在業界一半白板上的誤解：「允許的漣波愈大 = 濾波器愈爛。」不 —
這是**交易**。漣波愈大，帶內誤差愈大，**且**每一節換到的抑制愈多。設計者不是把
漣波壓到最小；設計者把系統受得了的漣波恰好花完（ADC 驅動也許吃得下 1 dB；通道化
接收機也許只給 0.1 dB），換成省下的節數。等漣波就是穿著 LC 戲服的極小極大
（minimax）逼近。

**g 值 — 先陳述，再掙得。** 遞迴，框起來，因為作業要對任意 N 實作它：

> β = ln[coth(漣波_dB/17.37)]，γ = sinh(β/2N)
> a_k = sin[(2k−1)π/2N]，b_k = γ² + sin²(kπ/N)
> g₁ = 2a₁/γ，g_k = 4a_{k−1}a_k / (b_{k−1}·g_{k−1})，k = 2…N
> g_{N+1} = 1（N 奇）、coth²(β/4)（N 偶）

（那個 17.37 是 40/ln 10 — 把漣波的 dB 換成雙曲函數要的奈培。毫不神祕。）

掙得它，兩次。**快版：** N = 1 的閉環，方法同巴特沃斯。1 Ω 兩端之間一顆並聯 C，
要求 ω = 1 處衰減恰為「漣波」：C = 2ε。遞迴說 g₁ = 2a₁/γ = 2/sinh(β/2)，一場
短短的雙曲恆等式搏鬥（做吧 — 用 e^(β/2) = √coth 兩行搞定）給出
2/sinh(β/2) = 2ε，**恆等**。β/γ 的機器就是 ε 換了衣服。第三小時把兩邊都印出來：
0.698623 = 0.698623。

**第一性原理版：** 一般遞迴從哪來？把 N = 1 的做法對任意 N 做一遍：由
|S11|² = 1 − 1/P_LR 寫出 S11（一次譜分解 — 挑左半平面的因子），組
Z_in = (1+S11)/(1−S11)，再用連分數（continued fraction）長除法一件一件把梯形剝
下來 — 串聯 L、並聯 C、串聯 L…— 就是你對有理函數做過的長除法，只是每一商都有
電路意義。Takahasi 等人把這套代數符號式地推到上面那條閉式遞迴；我們不在黑板上
磨完 — 第三小時改用**數值**執行它：作業的裁判正是用這套 Z_in 長除法，從 scipy
自己的極點抽取 g 值，一條和你的遞迴毫無血緣的路徑，要求 1e-8 以內一致。實測一致
到 1e-12。推導是真的；只是鉛筆讓機器握著。

**偶數 N 的皺摺**，因為檢查器會印給你看：N 為偶數時 C_N(0) = ±1，響應在**直流**
就得低 0.5 dB。但低通 LC 梯形在直流是透明的 — 串聯 L 短路、並聯 C 開路 — 直流
損耗只可能來自電阻性失配。所以 0.5 dB 時 g_{N+1} = coth²(β/4) = 1.9841：偶數階
等漣波濾波器**要求不相等的端接**，而 1.9841 對 1 的失配損耗 — 算算看 — 是
0.4999 dB。恰好等於漣波。濾波器表裡沒有一個數字是任意的。（實務推論：50 Ω 型錄
上滿滿都是奇數階。作業 Q3 要你把這個論證變成自己的。）

### 1.5 本小時回顧（0:47–0:50）

三句話，然後休息：插入損耗法先設計響應（P_LR = 1 + ε²C_N² 或 1 + Ω^(2N)）、再

## 第二小時 — 原理 II：縮放、轉換、階數與延遲（1:00–1:50）

### 2.1 阻抗與頻率縮放（1:00–1:10）

原型活在 1 Ω / 1 rad/s。真實世界是 50 Ω 和百萬赫。兩個代換，各用一行掙得：

**阻抗縮放 R₀：** 把網路裡每個阻抗乘上 R₀，任何比值都不變 —（對新 R₀ 參考的）
S 參數毫髮無傷。電感阻抗 jωL 要縮放，就令 L' = R₀L；電容阻抗 1/jωC，就令
C' = C/R₀。電阻：R' = R₀R。

**頻率縮放 ω_c：** 處處代換 Ω ← ω/ω_c；原本 jΩg 的電抗變成 jωL'，其中
**L' = g/ω_c** — 頻率愈高，元件值愈小（這句留給 2.5 用）。合起來，低通配方：
L' = gR₀/ω_c，C' = g/(R₀ω_c)。

出聲算一個，校準手感：0.5 dB 切比雪夫 N = 3 低通、100 MHz、50 Ω：
L₁ = 1.5963·50/(2π·10⁸) = 127 nH；C₂ = 1.0967/(50·2π·10⁸) = 34.9 pF。買得到的
零件。作業檢查器用 nH 和 pF 印元件值，理由相同 — 合成到你焊不出來的數字為止，
不算完成。

### 2.2 低通 → 帶通 — 完整推演，陷阱附上（1:10–1:28）

板書，本日主菜。頻率轉換就是對 P_LR(Ω) 做頻率代換：

- **高通：** Ω ← −ω_c/ω。電感變電容、電容變電感（投影片有兩行對照表）。
- **帶通：** Ω ← (1/Δ)·(ω/ω₀ − ω₀/ω)。 - **帶阻：** 取其倒數。

帶通的一切都住在那個代換裡，所以慢慢讀。它把 ω = ω₀ 映到 Ω = 0（帶中心 ← 直流），
並把 ω₁、ω₂ 這**對**頻率映到 Ω = ∓1 — 前提是你定義：

> **ω₀ = √(ω₁ω₂)** — 幾何平均（geometric mean）— 且 **Δ = (ω₂−ω₁)/ω₀** —
> 對**這個** ω₀ 量的分數頻寬（fractional bandwidth）。

為什麼是幾何？因為這個映射有一條精確對稱：Ω(ω₀²/ω) = −Ω(ω)。轉換後的濾波器把
ω 和 ω₀²/ω 當同一個頻率。頻率按**比值**配對，不按差值 — 低通響應在對數頻率軸上
對稱，而 √(f₁f₂) 正是對數軸的中點。我們的規格：f₀ = √(55·65) = **59.7913 MHz**，
Δ = 10/59.7913 = **0.1672**。不是 60.0。正確中心和「顯然」中心之間 0.35% 的縫，
是第三小時的蓄意 bug — 而它恰好寬得剛好是一整條漣波帶的錯。

現在把代換推過元件 — 代數在這裡變成硬體：

- **串聯電感** g：電抗 jΩg → j(g/Δ)(ω/ω₀ − ω₀/ω) — 過 ω₀ 時斜率為正地穿零 —
  這是一對**串聯 L-C，於 ω₀ 諧振**：L = gR₀/(Δω₀)，C = Δ/(gR₀ω₀)。
- **並聯電容** g：導納裡同一個故事 — 一對**對地並聯 L-C，於 ω₀ 諧振**：
  C = g/(ΔR₀ω₀)，L = ΔR₀/(gω₀)。

把不變量說出聲，因為它就是作業的逐支路檢查：**帶通梯形的每一條支路都在同一個
f₀ = √(f₁f₂) 諧振** — 第六講的諧振器，一個 g 一座，同一個諧振的拷貝，靠梯形
互相耦合。（Cohn [R23] 把整幅圖重建成「諧振器 + 耦合」，那才是第九講和每本微波
濾波器書實際使用的形式。）

我們濾波器的數字，上黑板 — 第三小時印它們，作業檢查器量它們：

> 串聯支路：**1270.3 nH / 5.578 pF** · 並聯支路：**20.30 nH / 349.09 pF** ·
> 全部諧振於 **59.7913 MHz**。

兩個陷阱，趁數字還在黑板上點名：

1. **元件值離散。** 串聯支路的 L 除以並聯支路的 L 是 1270/20.3 ≈ 63 倍。追蹤
   Δ 的位置：串聯 L ∝ 1/Δ、並聯 L ∝ Δ — 離散按 g₁g₂/Δ² 成長。頻寬窄 3 倍，
   離散漲約 9 倍；Δ 到幾個百分點時，零件出走型錄。這 — 不是品味 — 是窄帶濾波器
   拋棄直接梯形、投奔耦合諧振器（L9）的原因。
2. **中心。** 任何一條支路諧振偏離 √(f₁f₂)，漣波帶就滑走。第三小時把傷害量化。

先擋掉合理的抗議：「我的兩個帶緣 55 和 65 又不是繞著什麼漂亮數字幾何擺放 —
映射還精確嗎？」精確 — f₀ 是從你的帶緣**定義**出來的，兩個帶緣永遠正好落在
Ω = ±1。之後**不**對稱的，是你在乎的其他一切：算術擺放的規格點（±25 MHz！）
映到兩個差很多的 Ω。這是 2.3 的開局，也是作業 Q2 的預測題。

### 2.3 階數估計 — 讓諾模圖退休（1:28–1:36）

老書用諾模圖解「我需要多大的 N」。我們有閉式。先把阻帶頻率映過帶通代換：

> Ω(35 MHz) = (1/0.1672)·(35/59.79 − 59.79/35) = **−6.714**
> Ω(85 MHz) = (1/0.1672)·(85/59.79 − 59.79/85) = **+4.294**

裙邊對 |Ω| 單調，所以 |Ω| **小**的那邊卡規格：85 MHz 決定階數，35 MHz 白拿一份
它沒要求的肥厚裕度。（85 MHz 的幾何鏡像是 59.79²/85 = 42.1 MHz — 規格的 35 在
它下面很遠。）

兩個家族面對同一個衰減裕度比 — 規格濃縮成一個數：

> A = (10^(L_阻/10) − 1)/(10^(L_緣/10) − 1) = (10⁴−1)/(10^0.05−1) = **81,945**

在 Ω_s 處把兩條 P_LR 公式反解（各兩行 — 切比雪夫那條上黑板：
ε²cosh²(N·arccosh Ω_s) ≥ A·ε² 給出）：

> 切比雪夫：N ≥ arccosh(√A)/arccosh(Ω_s) = 6.350/2.137 = **2.972 → N = 3**
> 巴特沃斯：N ≥ log₁₀(A)/(2·log₁₀Ω_s) = 4.914/1.266 = **3.882 → N = 4**

有人的設計照定義就會失格之前，講一句誠實的細節：對巴特沃斯，「帶緣」必須指
**0.5 dB 點** — 我們的通帶承諾 — 不是傳統的 3 dB 點。上面的公式用 L_緣 = 0.5 dB
組出 A，就把它釘對了；等價地，把設計頻寬放寬 ε^(−1/N) 倍，讓 3 dB 點外移、
0.5 dB 點正好落在 55/65（第三小時就這麼做，好蓋一場公平的群延遲對決）。在這裡
沿用 3 dB 慣例，你會得到一座在 65 MHz 低 3 dB 的濾波器 — 合法的巴特沃斯，
失格的規格。

所以：主張 2，用算術定案 — 對這份規格，**3 節切比雪夫做到 4 節巴特沃斯的事**。
作業 Q1 要你在檢查器證實之前預測這個差距；對帳時有趣的部分，是為什麼差距只有一。

### 2.4 群延遲 — 陡濾波器在哪裡付帳（1:36–1:44）

定義上黑板：**τ_g = −dφ/dω**，φ 是 S21 的相位。濾波器要在帶內不失真，τ_g 得在
帶內平坦；延遲隨頻率變，任何頻譜橫跨頻帶的訊號就被抹開。

要內化的形狀：群延遲**在通帶邊緣起峰** — 帶緣的極點離 jω 軸最近，每個極點都像
一座諧振一樣貢獻延遲。振幅愈陡 ⇒ 帶緣極點被推得愈近 ⇒ 延遲峰愈高愈尖。平坦的
振幅從來不是免費的；等漣波濾波器用相位付款。

第三小時實測，兩座濾波器都蓋到同樣的 0.5 dB 帶緣：

> 切比雪夫 N = 3：中心 **68.3 ns**，帶緣 **128.5 / 108.8 ns**。
> 巴特沃斯 N = 4：中心 **63.9 ns**，帶緣 **99.2 / 84.0 ns** — **多一節反而
> 延遲更平**。

接著是雷達的帳，因為這座濾波器伺候第一講的雷達：回波是脈衝；它的頻譜切片以不同
速度穿過濾波器。帶內延遲離散 Δτ ≈ 60 ns 就是 c·Δτ/2 ≈ **9 公尺的距離抹糊** —
第 15 講距離解析度所依賴的脈衝邊沿，在偵測器看到之前就被磨軟了。通道化的通訊
接收機可能不在乎；精密測距系統在乎。所以誠實的設計陳述是：**恰好滿足抑制規格的
最陡濾波器，不自動是對的濾波器** — 振幅規格、延遲規格、節數是同一場談判。當延遲
平坦度當家時，還有第三個家族 — 貝索（Bessel），最平坦延遲 — 今天先點名，等哪次
作業的脈衝被抹糊了再用。

### 2.5 集總元件的極限 — 與回顧（1:44–1:50）

回頭看元件值：60 MHz 處，1270 nH 和 349 pF 是架上零件，自諧振安全地高於頻帶。
現在把同一份三支路配方跑在 2.4 GHz、10% 頻寬（第三小時印出）：串聯 **52.9 nH 配
0.083 pF**，並聯 **0.30 nH 配 14.5 pF**。0.083 pF 的電容比你要焊它的銲墊寄生
還小；0.30 nH 比一顆導通孔（via）的電感還少；而真實的 52.9 nH 線圈自諧振落在
2.4 GHz **以下** — 在那上面它是顆電容。集總梯形到此為止。活下來的是其餘一切：
規格語言、g 值、轉換、階數公式。第九講留下數學、換掉硬體 — Richards 轉換與
Kuroda 恆等式帶來的傳輸線諧振器、Cohn 諧振器-耦合觀點下的耦合線濾波器。同一顆
腦，新的銅。

回顧：用 R₀ 和 ω_c 縮放；帶通 = 每個 g 變成一座 √(f₁f₂) 上的諧振器（幾何！）；
先映**卡規格的**阻帶緣再用閉式拿階數（這裡 85 MHz → Ω 4.294 → 切比雪夫 3、
巴特沃斯 4）；群延遲在帶緣起峰、給陡峭標價（60 ns 離散 ≈ 9 公尺雷達抹糊）。
第三小時把全部蓋出來，然後故意把中心弄壞。

**休息（1:50–2:00）。**

### 3.2 g 值引擎，scipy 當裁判（2:05–2:15）

Cell 3.2：整個遞迴十二行 — 用打的，別用貼的。印表：巴特沃斯 N = 3 給
[1, 2, 1, 1]（叫大家背這一組；它是「我是不是弄壞了什麼」的金絲雀），切比雪夫
0.5 dB N = 3 給經典的 [1.5963, 1.0967, 1.5963, 1]，N = 2 以 1.9841 收尾 — 1.4 的
偶數階負載，上了螢幕。然後兩個檢查：手推的 N = 1 情形（g₁ = 2ε = 0.698623 —
遞迴一致到小數第六位），以及裁判 — 用 ABCD 在原型層級掃 g 梯形，疊上
`scipy.signal.cheb1ap` 的響應：**max |Δ| = 1.4e-14 dB**。把寓意說出口：梯形和
極點集是同一座濾波器，走兩條毫無血緣的程式路徑；一旦不合，就是有人的代數錯了，
而且吵得很大聲。作業的裁判是這個想法的升級版：它用連分數從 scipy 的極點**抽取**
g 值，要求 1e-8 一致。

收尾亮匯率：同階、同 0.5 dB 帶緣、Ω = 4.294 處的抑制：切比雪夫 **40.52 dB**、
巴特沃斯 **28.84 dB**。漣波買到 11.7 dB。作業 Q1 從這裡出發。

### 3.3 縮放、轉換 — 中頻濾波器現身（2:15–2:25）

Cell 3.3：先印 `f0 = sqrt(55 * 65) MHz = 59.7913 MHz (not 60!)` — 伏筆。然後
`bandpass_ladder`：十五行，把三個 g 數字變成六個元件值；印出的每一條支路都諧振
在 59.7913 MHz。用 ABCD 掃頻（第四講的級聯，向量化），把 |S21| 和 |S11| 畫在規格
遮罩上，印規格表：

> 通帶最糟衰減 **0.5000 dB** · 抑制 35 MHz 處 **52.38 dB** · 85 MHz 處
> **40.52 dB**。

指著不對稱 — 規格是對稱的，±25 MHz；濾波器不是。下面白拿十二 dB 裕度，上面只剩
半 dB。85 MHz 那條邊扛下全部工作，和 Ω 映射預測的一模一樣。然後是裁判那一行：
同樣六個元件交給 scikit-rf 的集總元件 media，用 `**` 級聯 —
**max |ΔS21| = 4.2e-14**。兩套實作，一座濾波器。

### 3.4 群延遲 — 代價，畫出來（2:25–2:33）

Cell 3.4：蓋那座公平的巴特沃斯 — N = 4，設計頻帶放寬 ε^(−1/4) 倍，讓 0.5 dB 點
正好落在 55/65（2.3 的細節，現在是三行程式）。它的規格表印出 85 MHz 處
41.49 dB — 同一份規格它也過，用多一節。然後
`-np.gradient(np.unwrap(np.angle(s21)), 2πf)`，延遲圖登場：切比雪夫在 55 MHz
帶緣衝到 128.5 ns、中心才 68.3 ns；巴特沃斯明明更大一座，卻處處更平。印出九公尺
那一行：帶內 60 ns 離散，乘 c/2。讓全班和這筆交易獨處十秒：**更陡的**濾波器和
**更有教養的**濾波器是兩座濾波器，而規格表沒問過雷達就選了一座。

### 3.5 蓄意 bug — 算術平均中心（2:33–2:42）

Cell 3.5，第一小時預告的 bug。複製 `bandpass_ladder`，改一行：
`f0 = (f1 + f2) / 2`。60 而不是 59.79 — 每個疲倦工程師都打過的 0.35% 手滑。
掃它。螢幕上曲線漂亮極了：置中、陡峭、抑制印出 52.66 和 40.33 dB — **兩個都
還過**。然後把兩張規格表並排印出，讓 55 MHz 那一列落地：**承諾 0.5 的地方讀到
0.9726 dB。** 整條漣波帶滑到 55.21–65.21 MHz；下帶緣掉出漣波帶、摔到裙邊上。
把兩課慢慢講。第一：這個 bug 不當機、不難看、阻帶還過 — 只有**規格邊緣的數字**
能定它的罪。永遠不要用圖形給濾波器打分。第二：檢查器的逐支路諧振檢查正是為這種
失敗而生 — 錯的中心表現為每個 L·C 乘積都諧振在 60.00 MHz，儀器立刻讀出 3.5e-3
的相對偏移，眼睛卻什麼都讀不到。

接著 cell 3.6，三十秒，通往下週的門：同一份配方在 2.4 GHz 印出 0.083 pF 和

### 收尾（2:47–2:50）

通帶（reentrant passband）。同一套哲學，在銅裡，在 2.4 GHz。

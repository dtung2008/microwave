## 第一小時 — 原理 I：方程式在此收束，虛警算到精確（0:00–0:50）

### 1.1 課程在此收束（0:00–0:08）

投影片提示：雷達方程式放大寫出，每一項蓋上「出身講次」的印章。

開場把第 1 講的方程式一項一項寫上黑板 — 但這一次，每一項都有課程內部的出處：

> SNR = P_t G² λ² σ / ((4π)³ R⁴ · kT₀B·F · L)

P_t 經過**傳輸線**（L2）與**匹配網路**（L3、L6）沒被反射回來；G 是**第 13 講**的
孔徑，因為單站（monostatic）而用了兩次；B 是你已能親手合成的**濾波器**（L8–9）；
F 是**第 10 講**的雜訊指數（noise figure），幾乎由你在 L11 設計的低雜訊放大器
（LNA）決定；L 是沿途所有配管損耗的總和（L5、L7）；把回波搬下來、讓這個決策
得以發生的混頻器是 L12。把話說白：*第 1 講時，這條方程式是一張來自異國的
明信片。今天，每一項你都住過了。*

其中有一個數字從來沒有掙來過：**SNR_min = 13 dB** — 第 1 講請你先信著的
「偵測門檻」。今天的三個主張，上黑板：

1. **偵測是不確定性下的決策，兩種犯錯方式各有價格。** P_d（偵測機率，detection
   probability）與 P_fa（虛警機率，false-alarm probability）將取代 13 dB 的
   揮手帶過 — 而到第二小時結束，你會發現 13 dB 恰恰**就是**
   (P_d = 0.9, P_fa = 10⁻⁶) 的誠實數字，幾乎分毫不差。
2. **虛警的數學是精確的，你可以徒手反解。** 一條瑞利（Rayleigh）閉式解設定了
   本講的每一個門檻 — 而指數裡一個 2 倍的疏失，會把 10⁻⁶ 悄悄變成 10⁻³。
   第 3 小時會蓄意犯下這個錯。
3. **固定門檻一離開實驗室就會死。** 真實世界會移動它的雜訊底線；CFAR
   （恆虛警率，constant false-alarm rate）— 「在沒有目標的地方估雜訊」— 是雷達
   活下來的方式，它付一筆可量測的稅，也有兩個可量測的盲點。

### 1.2 雷達截面積，老實講（0:08–0:20）

投影片提示：dBsm 階梯，從昆蟲到客機。

第 1 講把 σ 當作給定的數字。現在講誠實版。σ 是**由方程式定義**的：那個「若
全向再輻射所攔截的功率、恰能解釋你收到的回波」的等效面積。它是散射性質，
不是輪廓剪影：一塊正對你的平板回波是 4πA²/λ² — X 頻段一塊 30 cm × 30 cm 的
平板約 **110 m²**，比客機整架的帳面數字還大 — 同一塊板傾斜 30°，鏡面閃光就
不朝你來了。

沿 dBsm（dB re 1 m²）階梯走一遍，班級標準數字加上新住戶：

- 昆蟲：**−40 dBsm**（0.0001 m²）— X 頻段氣象雷達還真的看得到蟲群
- 小型鳥：**−30 dBsm**
- 大型鳥／小型無人機：**−20 dBsm** — 讓無人機偵測變難的那一對
- 人：**≈ 0 dBsm**（步行，X 頻段）
- 戰鬥機，機鼻方向，乾淨構型：**0 dBsm**
- 汽車：**+10 dBsm**；客機（班級數字）：**+16 dBsm**（40 m²）
- 側面的戰鬥機或客機：**+25 到 +30 dBsm** — 光是視角就能擺動 25 dB
- 貨輪：**+30 到 +40 dBsm**

有兩個機制讓 σ 是**隨機變數**而非數字。**視角（aspect）：** 目標是一群散射
中心（發動機進氣道、角落狀的接縫、尾翼的平面）的集合，各自的回波以相量相加；
視角變化零點幾度，相量和就重新洗牌。**頻率：** 同樣的相量和也隨 λ 重新配相，
所以就算幾何固定，寬頻波形掃過時它也會閃爍。量測到的結果 — 繞著平均值的深度
衰落與亮閃 — 就是第二小時 Swerling 模型要誠實平均的東西。第 1 講寫「σ ≈ 40 m²」
時，那個 ≈ 藏著一支 20–30 dB 的舞。

匿蹤（stealth），誠實的一段話（指定深度讀物是 Balanis 的 RCS 縮減章 [R10]）：
槓桿恰好只有兩支。**外形（shaping）**不吸收能量 — 它**改道**：消滅角落型的
逆反射結構，用切面或連續曲率讓鏡面閃光飛向單站接收機不在的方向。這就是匿蹤
機外形的由來，也是雙站（bistatic）雷達成為反匿蹤話題的原因。**吸收
（absorption）**（雷達吸波材料，RAM）把感應電流變成熱 — 有效、偏窄頻、重、
維護昂貴。兩支槓桿買到的都是 σ 的 dB；四次方根再以四分之一的匯率折算成距離：
一個認真計畫買到的 30 dB，只把偵測距離砍成 10^(30/40) ≈ 5.6 分之一，不是一千
分之一。匿蹤划算，但不是魔法 — 第 1 講說過；現在你知道那 30 dB 有多貴。

先擋掉必問題：*「那方程式裡到底該填哪個 σ？」* 答案：一個講明的慣例 — 班級
數字大致是視角上的中位數；認真的設計用起伏模型（第二小時）或量測分布。任何
單一數字都是穿制服的統計摘要。

### 1.3 偵測是一個決策（0:20–0:32）

投影片提示：兩條機率密度曲線與一條垂直線。

把問題剝到骨架。經過接收鏈（L10–12），一個距離單元、一個瞬間、一個數字：
檢波器輸出的包絡（envelope）r。兩個假設：

> H₀：只有雜訊。  H₁：目標回波加雜訊。

你必須輸出一個位元。唯一誠實的程序：選一個門檻 T；r > T 就宣告「有目標」。
於是犯錯的方式恰好兩種，各有名字、價格，以及 — 這是定理形狀的部分 — 一顆
**互相交換的旋鈕**：

> P_fa = P(r > T | H₀) — 螢幕對操作員說謊。
> P_d = P(r > T | H₁) — 有 1 − P_d 的機率，無人機大搖大擺走過。

畫兩條密度：純雜訊堆在零附近，訊號加雜訊往右移，兩者重疊。T 同時切開兩條
尾巴。T 往右推：P_fa 崩落、P_d 下垂。往左推：滿螢幕虛警。**門檻治不了重疊；
只有 SNR 治得了** — 訊號變強，H₁ 的密度整條右移，兩個數字一起變好。這就是
整門課 — L10 省下的每一分 NF、L5–7 省下的每一分損耗、L13 買到的每一分增益 —
最終服務的那張圖。

第一性原理版，三行帶過（然後誠實地揮手）：最優檢定統計量是似然比
p(r|H₁)/p(r|H₀) 對上由代價決定的門檻（Neyman–Pearson：固定 P_fa 下最大化
P_d）。對我們的密度而言，似然比對 r 單調 — 所以「拿包絡比門檻」不是土法，
它**就是**最優偵測器；這也是為什麼本講剩下的內容都在選 T，而不是找更好的
統計量。完整機器（包括包絡比門檻何時**不是**最優）在 Richards 第 6–7 章
[R14]；我們取那三行與結論。

接著把密度講具體。接收機交給你 I 與 Q — 兩路獨立高斯雜訊，各自變異數 σ²，
**總雜訊功率 N = 2σ²**（這個 2 是今天的地雷；插旗）。包絡 r = √(I²+Q²)：

- H₀ 下：**瑞利分布（Rayleigh）**。p(r) = (r/σ²)·exp(−r²/2σ²)。
- H₁ 下（幅度 A 的穩定回波）：**萊斯分布（Rician）** — 瑞利的位移表親，
  訊號強時是繞著 A 的一座鐘形。

擋掉必問題：*「為什麼不直接對 I 做偵測？」* 因為回波相位不可知 — 目標距離
以 λ/2 為模設定它，而 λ/2 是 1.5 公分。包絡丟掉不可知的相位、留下能量；這
正是今天的數學由瑞利（而非高斯）主演的原因。

### 1.4 虛警，算到精確（0:32–0:45）

板書 — 第一小時的主菜。積分瑞利尾巴。它收得起來：

> P_fa = ∫_T^∞ (r/σ²) e^(−r²/2σ²) dr = **exp(−T²/2σ²)**

沒有近似。當場徒手反解：

> T = σ·√(2·ln(1/P_fa)) = √(N·ln(1/P_fa))   （N = 2σ²，即雜訊功率）

作業的正規化數字（N = 1）：P_fa = 10⁻⁶ → ln(1/P_fa) = 13.816 → **T = 3.7169**
— 門檻坐在**平均雜訊功率之上 11.40 dB**，是 rms 包絡的 3.72 倍。把第二種寫法
唸出來：第 1 講的預算以瓦特算出 N = kT₀BF；門檻離它只差一個平方根。

為什麼是 10⁻⁶，不是舒服一點的 10⁻³？數一數決策次數。B = 1 MHz 意味著每秒約
10⁶ 次獨立觀察。P_fa = 10⁻⁶ 就是*每秒一個假光點* — 已經多到真實系統要在上面
疊確認邏輯（跨掃描的 m-of-n）。10⁻³ 是每秒一千個：滿螢幕白光。P_fa 由決策
**速率**設定，而速率由 B 設定 — 第 1 講稱之為雜訊稅的那個 B，現在對你課了
第二次稅。

刀鋒，量化（門檻誤差之所以致命）：P_fa 對 T 的相依是**平方的指數**。門檻移
**半個 dB**，指數就乘上 10^(±0.05)：P_fa = 10⁻⁶ 變成 1.9×10⁻⁷（上移半 dB）或
4.5×10⁻⁶（下移半 dB）— 半個 dB，各方向約 5 倍。這門課裡沒有第二個東西對半個
分貝有這種反應。正因如此，第 3 小時對每一個門檻都用一百萬次蒙地卡羅抽樣去量，
而不是相信任何人的代數（包括我們自己的）— 也正因如此，那個 2 倍指數疏失
（把總雜訊功率 N 填進單通道 σ² 的格子）不是預算裡的 3 dB 小麻煩，而是
*P_fa → √P_fa* 的災難：10⁻⁶ → 10⁻³，無聲無息。第 3 小時重演它；第二小時的
戰場故事給你看它在顯示器上的長相。

### 1.5 本小時回顧（0:45–0:50）

三句話，然後休息：雷達方程式完全是你的了 — 每一項都有出身講次，最後一個
沒掙來的數字（13 dB）下一小時就倒；σ 是會擺動 20–30 dB 的散射性質，匿蹤用
外形與吸收買 dB，四次方根再以四分之一匯率退款；虛警是精確的 —
P_fa = exp(−T²/2σ²)、T = √(N·ln(1/P_fa))、單位雜訊上是 3.72，而半個 dB 的門檻
就讓 P_fa 動 5 倍。第二小時把目標放進雜訊，得到 P_d — 然後教門檻自己設定自己。

**休息（0:50–1:00）。**

## 第二小時 — 原理 II：P_d、Albersheim、積分與 CFAR（1:00–1:50）

### 2.1 P_d，以及 13 dB 門檻的終審（1:00–1:15）

投影片提示：P_fa = 10⁻⁶ 下的 P_d 對 SNR 曲線。

H₁ 下包絡是萊斯分布，而它的尾積分沒有初等函數閉式解 — 它是 **Marcum 的 Q
函數**：P_d = Q₁(√(2·SNR), √(2·ln(1/P_fa)))。scipy 能精確求值（非中心 χ²；
作業工具箱包成 `marcum_pd` — 裁判）。但七十年來白板前的工程師用的是
**Albersheim 近似式**，你也將如此：

> A = ln(0.62/P_fa)，B = ln(P_d/(1−P_d))
> **SNR_dB = −5·log₁₀N + (6.2 + 4.54/√(N+0.44)) · log₁₀(A + 0.12AB + 1.7B)**

像唸規格表一樣唸出它的契約，因為它真的有一份：**約 0.2 dB 精度，適用
10⁻⁷ ≤ P_fa ≤ 10⁻³、0.1 ≤ P_d ≤ 0.9、1 ≤ N ≤ 8096**（N = 非同調積分脈波數；
線性檢波器；**非起伏**目標）。有明示適用範圍的近似式是儀器；沒有的是謠言。
第 3 小時會去量這個範圍 — 包括一個磨損的角落（在 P_d = 0.1、P_fa = 10⁻⁷ 量到
0.75 dB 誤差；範圍是有角落的）。

接著是課程從第一週就欠你的終審。餵進誠實的客戶規格 — P_d = 0.9、
P_fa = 10⁻⁶、N = 1：

> Albersheim：**13.11 dB**。精確（Marcum）：**13.18 dB**。

停在這裡。第 1 講的「13 dB」根本不是揮手 — 它是**這份規格**的壓縮檔，現在你
會解壓縮了。誠實偵測距離移動 ×10^(−0.11/40) = **×0.9934**：客機 32.65 →
32.44 km、戰鬥機 12.98 → 12.90、無人機 4.11 → **4.08 km**。而在恰好 13 dB 處，
實際交付的 P_d 是 **0.8744**。所以揮手到底藏了什麼？不是距離 — 是**意義**。
「可偵測到 4.11 km」從頭到尾的意思都是「每看一眼是一枚 87–90% 的硬幣，代價是
每百萬格一次虛警」。偵測距離不是牆；它是一條陡峭的機率曲線與一個合約數字的
交點。

有多陡？由 P_d 曲線與 R⁴：在 4 km 附近，無人機每公里損失約 3.9 dB 的 SNR
（40·log₁₀(5/4)）；P_d 從 0.9 掉到 0.5 只要 13.18 − 11.24 ≈ 1.9 dB。整座懸崖
只有半公里的天空。這種陡峭是*好*消息 — 它讓 R_max 是個有意義的數字 — 也是
作業 Q1 的對帳內容。

### 2.2 Swerling，誠實的一頁（1:15–1:22）

投影片提示：非起伏與 Swerling-1 的 P_d 曲線對照。

以上全部假設回波幅度 A 穩定。1.2 節已經告訴你它不穩 — σ 隨視角起舞。Swerling
模型是那支舞的標準語彙：case 0/5（非起伏 — 今天的數學）、case 1–2（許多同量級
散射中心 — σ 呈指數分布，即整個*功率*在瑞利衰落；慢起伏／快起伏兩版）、
case 3–4（一個主導散射中心加合唱團）。有一條值得上黑板的公式，因為它是閉式
而且驚人 — Swerling 1，單脈波：

> P_d = P_fa^(1/(1+SNR))   （SNR 為線性值）

在 (0.9, 10⁻⁶) 反解：SNR = ln(P_fa)/ln(P_d) − 1 = 130.1 → **21.1 dB**。起伏
目標要比穩定目標**多 8 dB** 才能達到同樣的 P_d = 0.9 — 因為起伏代表目標有時
*衰落*，而要求九成的成功率，就是逼你為衰落買單。（P_d = 0.5 時差距幾乎消失；
起伏懲罰的是野心。）換算距離：×10^(−8/40) ≈ 0.63 — 若無人機真的瑞利衰落，
誠實距離從 4.08 掉向 **2.6 km**。我們只花一頁，但把寓意帶走：*聽到任何偵測
距離，先問三件事 — 什麼 P_d、什麼 P_fa、哪個 Swerling。* 這三問就是本講的
作戰形式。

### 2.3 積分 — 為什麼 10 個脈波 ≠ 10 倍距離（1:22–1:30）

雷達不是只看一眼；掃描波束用一串脈波刷過目標。把它們加起來。兩種加法：

**同調（coherent）**（在包絡檢波器之前、相位對齊 — L15 的都卜勒處理做的正是
這件事）：N 個脈波以電壓相加、雜訊以功率相加 → SNR 恰好增益 **10·log₁₀N**。
十個脈波 = +10 dB。

**非同調（non-coherent）**（檢波之後、相位已丟）：雜訊的包絡不再往零平均 —
一部分增益花在重新偵測上。精確需求（第 3 小時用 Gamma／非中心 χ² 閉式解算）：
單脈波要 13.18 dB；十個同調脈波每脈波要 3.18 dB；十個非同調要每脈波
**5.27 dB**。非同調稅：N = 10 時 **2.1 dB**（Albersheim 的 N 項對每個 N 都能
標價；大 N 時稅大致隨 √N 長）。

然後是課綱承諾的重點：十個脈波遠遠不是十倍距離。距離騎在四次方根上：同調
+10 dB → 距離 ×10^(10/40) = **1.78 倍**；非同調 → **1.58 倍**。要把無人機的
偵測距離*翻倍*，稅後需要 +12 dB — 16 個同調脈波，或約 25 個非同調。積分是
真實雷達買得起偵測的方式（百萬瓦峰值功率是另一條更糟的路），但 R⁴ 讓每條路
都昂貴。這也是第 15 講的種子：FMCW 雷達*天生*同調積分 — FFT 就是積分器。

### 2.4 CFAR — 自己設定自己的門檻（1:30–1:44）

先講戰場故事，六十秒，因為本節的一切都因這類案場而存在。某海岸監視雷達交付
驗收；門檻在實驗室對熱雜訊設好，P_fa = 10⁻⁶，驗證得漂漂亮亮。到了海邊，海面
雜波（sea clutter）把有效雜訊底線抬高 20 dB。丟進第一小時的閉式解 — 指數除以
100：

> P_fa = (10⁻⁶)^(1/100) = 10^(−0.06) = **0.87**

不是 10⁻⁴。*百分之八十七。* 每秒一百萬次決策，約 87 萬個虛警：螢幕全白，
操作員把增益轉小（等於盲目抬高門檻），雷達從此什麼都偵測不到。沒有人焊錯
任何東西。門檻只是一個*常數*，而世界不是。讓全班體會指數函數的暴力：底線
移了 20 dB，P_fa 動了*五個數量級然後飽和*。

解法是一句話：**在沒有目標的地方估雜訊。** 對每個待測單元（CUT，cell under
test），取兩側各 n_train 個訓練單元（training cells）的功率平均 — 中間跳過
n_guard 個保護單元（guard cells），免得目標自己的能量污染自己的陪審團 — 門檻
設為這個局部估計的某個倍數。這就是單元平均 CFAR（CA-CFAR）：恆虛警率，因為
門檻現在*騎著*底線走。

數學是一段乾淨的推導（平方律域：功率 z = r² 在雜訊下呈指數分布 — 注意換了
統計域，這是今天 2 倍 bug 能藏身的第二個地方）。N 個訓練功率之和是 Gamma
分布；把 CUT 的指數尾巴對估計積分，精確得到：

> P_fa = (1 + α/N)^(−N)  →  **α = N·(P_fa^(−1/N) − 1)**

門檻 = α ×（訓練平均）。檢查極限：N → ∞ 時 α → ln(1/P_fa) — 第一小時已知
雜訊的乘數（功率形式），如數歸位。基準 N = 16、P_fa = 10⁻⁶：**α = 21.94
（13.41 dB）**，對比理想的 13.82（11.40 dB）。這個差距就是 **CFAR 損失**：
10·log₁₀(α_N/ln(1/P_fa)) = N = 16 時 **2.01 dB**、N = 32 時 **0.97 dB**。用
16 個單元*估*底線而非*知道*底線的代價：兩個 dB，永遠、到處 — 約 11% 的偵測
距離。訓練單元愈多愈便宜。那為什麼不用 N = 200？

因為訓練視窗是一注「世界在視窗內均勻」的賭注，而世界有邊緣。兩種故障模式，
都在作業的場景裡：

**雜波邊緣（clutter edge）。** 海陸交界 — 或一段 30 dB 雜波區的起點 — 剛進
雜波的 CUT，陪審團有一半還在投「便宜的淨空側雜訊」：門檻低估，虛警從邊緣
噴出（作業的系集量到：邊緣區約為設計 P_fa 的 13 倍，而且視窗愈長愈糟 — 跨得
愈多）。過了另一側邊緣則是鏡像：淨空側的 CUT 陪審團裡混著雜波 — 門檻高估，
一條盲帶。作業在那裡種了一個 15 dB 的目標，你的偵測器會從它旁邊走過去。

**遮蔽（masking）。** 兩架無人機相隔六格：強的那架坐進弱者的訓練視窗，把它
的雜訊估計抬高約 10 dB，於是那架單獨飛行時輕鬆可偵測的弱無人機 — 消失了。
陪審團被收買了。解法存在（smallest-of、censored、順序統計 OS-CFAR），每一種
都用額外損失或新的邊緣行為換取穩健；作業 Q4 要你挑一種、標出價格。

### 2.5 雜波一頁，本小時回顧（1:44–1:50）

雜波投影片，用課程雷達自己的數字：在無人機的 4.08 km 處，3.6° 的波束（33 dBi
買到的就是這個 — G ≈ 26000/θ²，第 13 講）照出約 257 m 寬的足跡，B = 1 MHz 把
距離切成 150 m 的單元。在無人機自己的單元裡與它競爭的地面斑塊：約 257 × 150 m
≈ 3.9×10⁴ m² — **+46 dBsm 的泥土被照亮**。就算反射率 σ⁰ = −10 dB 這樣客氣的
數字，也剩 +36 dBsm 的雜波對上 −20 dBsm 的無人機：**地面比無人機大約 56 dB —
姑且叫它 60**。功率域裡沒有任何門檻數學撐得過這個比值。誠實的答案是換一條軸：
地面*不會動*。都卜勒／移動目標指示（MTI，moving-target indication）— 第 15 講
— 才是無人機甩開泥土的地方（而第 12 講的相位雜訊裙已經告訴你*那條路*的極限）。

三句話回顧：P_d 來自萊斯統計 — Albersheim 在明示的 0.2 dB 範圍內近似它，而
誠實的 (0.9, 10⁻⁶) 規格要價 13.18 dB，也就是第 1 講那個 13 dB 的真身；起伏與
積分重新標價 — Swerling 1 多要 8 dB、十個同調脈波恰好退 10 dB，四次方根再把
一切以四分之一匯率折成距離；門檻必須*就地估計* — CA-CFAR 以
α = N(P_fa^(−1/N)−1) 收 2 dB 的稅，並在邊緣與鄰居旁邊以可量測的方式失效。
第 3 小時讓每一句都印出來。

**休息（1:50–2:00）。**

## 第三小時 — 工具：NumPy 裡的蒙地卡羅偵測與 CA-CFAR（2:00–2:50）

現場寫程式，與 `lab/hour3_walkthrough.py` 逐格對應。邊打邊講；第 1–2 小時的每個
主張都變成印出來的數字。全部固定種子 — 全班看到的正是下列數字。

### 3.1 環境驗證（2:00–2:03）

跑 cell 3.1：python 3.12.x、numpy 1.26.4、scipy 1.13.x、matplotlib 3.10.x。
本週不需要新東西 — 精確裁判（非中心 χ²、Gamma）就在已安裝的 scipy 裡。

### 3.2 包絡檢波器之後的雜訊（2:03–2:10）

Cell 3.2：一百萬次複數雜訊抽樣，總功率單位化，取包絡。量到平均包絡功率
0.9998（設計值 1）；平均包絡 0.8859，對上瑞利的 √π/2 = 0.8862。直方圖貼著
pdf 2r·e^(−r²) 像手套 — `hw14_rayleigh.png`，P_fa = 10⁻⁶ 的門檻畫在尾巴已經
看不見的地方。指著主體與門檻之間的空隙：*整個偵測這門生意，就住在那最後一絲
看不見的縫裡。*

### 3.3 精確反解 — 然後是不信任它的量測（2:10–2:18）

Cell 3.3：把黑板上的 T = √(ln(1/P_fa)) 打進去。10⁻³：T = 2.628，量到
**1.05×10⁻³**（10⁶ 次中 1051 次跨越 — 在 ±9.5×10⁻⁵ 的 3σ 帶內）。10⁻⁶：
T = 3.717，量到 **2×10⁻⁶** — 兩次跨越，而期望次數是*一*。停下來教後設課：
一百萬次試驗量不了百萬分之一的機率；10⁻³ 那一列驗證的是公式的*形狀*，閉式解
再把信任帶到 10⁻⁶。接著分塊跑 10⁷ 次：8 次跨越，8.0×10⁻⁷ — 「≥ 10/P_fa 次
試驗」的經驗法則，當場示範。（作業 Q3 就是把這段討論寫下來。）

### 3.4 P_d 對 SNR — 蒙地卡羅、Albersheim、精確解（2:18–2:26）

Cell 3.4：種一個穩定目標，SNR 從 6 掃到 16 dB，每點 10⁵ 次試驗，對上精確的
Marcum 曲線與 Albersheim 近似：10 dB 量到 0.2484 對精確 0.2480；12 dB 是
0.6824 對 0.6794；14 dB 是 0.9723 對 0.9721。然後是本講承諾的終審那一行：
**(P_d = 0.9, P_fa = 10⁻⁶) → Albersheim 13.11 dB，精確 13.18 dB。**
`hw14_pd_sweep.png` 是那條曲線；全班該注意到蒙地卡羅的點*落在*精確曲線上，
而 Albersheim 的虛線懸在十分之一個 dB 之外 — 一個完全照著自己規格表演出的
近似式（而在檢查器裡，它在自己標示的角落磨損）。

### 3.5 積分，量出來（2:26–2:32）

Cell 3.5：十脈波非同調積分。純雜訊之和是 Gamma(10) — 門檻 **32.71**，由建構
即精確，不需要蒙地卡羅（種下的真值）。在 Albersheim 建議的每脈波 4.99 dB 上，
量到的 P_d 是 **0.851** 而非 0.9 — 因為精確需求是 **5.27 dB**：Albersheim 在
自己範圍邊緣 0.28 dB 的滑移，*親眼看著發生*。計分板印出：單脈波 13.18 dB；
十同調 3.18；十非同調 5.27（稅：2.1 dB）。距離：**同調 ×1.78、非同調 ×1.58 —
不是 ×10。** 又是 R⁴，永遠是。

### 3.6 CA-CFAR — 三個場景現場跑（2:32–2:40）

Cell 3.6：cfar 函數約 12 行（前綴和、裁切視窗、α = N(P_fa^(−1/N)−1) — 黑板上
的閉式解；先印 α(16, 10⁻⁶) = 21.94、13.41 dB、CFAR 損失 2.01 dB）。跑三個
作業場景，種子與學生拿到的相同：

- **clean**：在第 400 格（20 dB）與第 1400 格（15 dB）命中，零虛警 — 門檻貼著
  底線上方 13.4 dB 走，承諾成立。
- **clutter_edge**：*在* 30 dB 雜波裡面的 20 dB 目標被抓到（門檻跟著雜波爬上了
  牆 — 這正是 CFAR 的全部意義），但邊緣前五格的 15 dB 目標不見了 — 邊緣的
  盲側，就在螢幕上。
- **two_drones**：22 dB 的無人機抓到；六格外 15 dB 的那架不見了 — 圖上兩架
  之上的門檻隆起，清楚顯示誰的功率抬高了誰的門檻。然後是對照組：同一個種子、
  刪掉強者，detected = True。遮蔽，用對照實驗示範完畢。

`hw14_cfar_scenes.png` 留在螢幕上，一路撐到作業簡報。

### 3.7 蓄意 bug — 把功率統計用在幅度統計的地方（2:40–2:44）

Cell 3.7，第一小時插旗的那個疏失：雜訊功率*總共* 1 W，但 I 與 Q 各只揹 ½ —
瑞利的指數要的是單通道 σ²。把那行貌似合理的錯誤打出來：把總功率填進 σ² 的
格子。門檻算出 2.628 而不是 3.717 — 兩個都長得像正經門檻，什麼都沒崩 — 而
剛才量到 2×10⁻⁶ 的同一批一百萬次雜訊抽樣，現在量到 **1.1×10⁻³**。
P_fa^(1/2)：*指數裡*的 2 倍不是 3 dB 的錯，是三個數量級。印出作戰翻譯：
B = 1 MHz 下每秒約 1,051 個虛警而不是約 1 個 — 螢幕變白，在實驗室裡，
彬彬有禮，帶著種子。解法是整門課一直在養的習慣：公式看起來是對的；
**蒙地卡羅抓到了它**。沒量過的門檻，永遠不要出貨。

### 作業簡報（2:44–2:48）

- 模組 1：精確瑞利反解，加上不信任它的蒙地卡羅（10⁶ 次試驗、二項式誤差棒 —

### 收尾（2:48–2:50）

對著三個主張收帳：偵測是兩個錯誤率加一顆旋鈕，而第一週的 13 dB 解壓縮成
(P_d = 0.9, P_fa = 10⁻⁶) = 恰好 13.18 dB；瑞利閉式解設定了今天每一個門檻，
而它指數裡的一個 2 — 當場犯下 — 把 10⁻⁶ 變成 10⁻³，直到一百萬次抽樣抓住它；
CFAR 用 2 dB 的代價守住固定門檻守不住的承諾，除了在邊緣與鄰居旁邊 — 你看著
它蓄意失敗了兩次。預告：功率域裡無人機仍壓在泥土下 56 dB — 下一講，雷達不再
問「多強」，改問「多快」：FMCW、都卜勒，以及懸停無人機被自己的旋翼出賣的
那張圖。

1.2 The snapshot model

One wavefront, sixteen phases

  • ULA (uniform linear array): element n at x = n·d, d = λ/2
  • Path difference to element n: n·d·sin θ (θ from broadside)
  • Narrowband: a 0.1 ns crossing delay is just a phase → element n sees e+j·k·d·n·sin θ, k = 2π/λ
  • Stack the N phases: the steering vector a(θ) — L13's array-factor phase, written as a column

Course array: N = 16 at 77 GHz, d = 1.9467 mm, aperture 29 mm, HPBW (half-power beamwidth) = 6.35°. The whole homework is priced in this beamwidth.

1.2 The snapshot model

x = A s + n — the equation the rest of the day interrogates

x = | |a(θ₁)…a(θ_M)| | s₁⋮s_M + n
  • x: one snapshot — N complex samples across the array (our world: one range-Doppler cell of one chirp; L15 gave the cell, today we keep its wavefront)
  • s: source amplitudes — fluctuating (complex Gaussian per snapshot; L14's Swerling story)
  • n: receiver noise, unit power per element (L10 priced it)

K snapshots → the sample covariance R̂ = XXH/K.  True value R = APAH + σ²I. Every method today is a bet on how well K snapshots estimated it — hour 3 loses that bet on purpose.

1.3 Delay-and-sum, twice

Fast version: steer and sum

y = wHx,   w = a(θ₀)/N
  • Undo each element's phase for direction θ₀, then add.
  • From θ₀: sixteen phasors in a line — full coherent gain (L13's picture).
  • From elsewhere: scrambled phases, mostly cancellation — L13's sidelobes.

This is the phased array, receiving. Steering is a multiply — no gimbals, no inertia, a new direction every snapshot.

1.3 Delay-and-sum, twice

First-principles version: the matched filter in space

Ask instead: which w maximizes SNR (signal-to-noise ratio) for a signal along a(θ₀) in white noise?

SNR ∝ |wHa|² / ‖w‖²  →  (Cauchy–Schwarz)  →  w ∝ a(θ₀)

The matched filter IS the steering vector. SNR gain = N exactly (12 dB at N = 16) — the same N lecture 13 called directivity.

Third appearance of one idea — correlate with the template of what you seek: in time (matched filter, L14), in delay (pulse compression, L15), in space (today). Same theorem, three coordinates.

1.4 Beamscan DOA

Point the beam everywhere, plot the power — L13 closes

Pbs(θ) = a(θ)H R̂ a(θ) / N²
  • Lecture 13's pattern, used backwards → inherits its limits: beamwidth-wide peaks, −13.2 dB sidelobes.
  • Resolution = the beamwidth — separations below ~1 HPBW merge into one lump.

Do not over-apply the rule — the homework's predict-first question: two drones 1.5 beamwidths apart are above the limit. Measured: beamscan shows both, dip +5.7 dB at 18 dB SNR — and keeps them to −15 dB. (Also measured: overlapping skirts pull the peaks together — planted ±4.76°, read ±4.9°.)

1.5 MVDR / Capon

Adaptivity in one Lagrange multiplier

MVDR (minimum-variance distortionless response), Capon 1969: per look direction, minimize total output power, hold the look direction at gain one.

minw wHR̂w  s.t.  wHa(θ) = 1
L = wHR̂w + λ(1 − wHa)  ⟹  R̂w = λa  ⟹  w = R̂⁻¹a / (aHR̂⁻¹a)
Pmvdr(θ) = N / (aHR̂⁻¹a)

Minimizing power at unity look-gain forces the weights to null whatever correlated energy is loudest — without being told where it is. The jammer's bearing is inside R̂; the inverse digs it out.

1.5 MVDR / Capon

What it buys: the jammer case, measured

  • Beamscan at the drone's angle: +24.9 dB — the jammer's sidelobe floor, 15 dB over the drone's own echo
  • Beamscan's two tallest peaks: the jammer (+25°) and the jammer's first sidelobe (+37°). The drone is gone.
  • MVDR at −10°: +20.9 dB — the drone at full array gain, jammer nulled

MVDR also resolves below the beamwidth — superresolution bought with SNR × snapshots. The homework measures where it flips (0.7 BW: at 0 dB SNR).

1.5 The fine print

The sample-covariance caveat

MVDR trusts R̂ completely. K ≥ 2N snapshots: trust earned (K = 4N is comfort). K < N: R̂ is rank-deficient — the minimizer discovers it can "cancel" the strongest thing in the data, the target itself. Hour 3, measured: K = 8 → the target's reading collapses from +27 dB to −114 dB.

The fix: diagonal loading — invert R̂ + εI (hour 3: ε = 10 dB over noise restores +27.7 dB). Cost: nulls get shallower. Adaptivity is a loan against the covariance estimate; K pays it back; loading is collateral.

War story: the sidelobe canceller whose covariance window was shortened "to react faster" — it softly nulled its own low-elevation returns for months. Adaptive systems fail by subtraction; only planted truth (your checker) catches silence.

2.1 Monopulse

Σ and Δ — lecture 7's comparator, now in software

  • Σ (sum) beam: uniform weights — the matched filter
  • Δ (difference) beam: same weights, sign flipped on half the aperture — nulls exactly on boresight (L7's 180° hybrid, in software)
  • Off boresight by δθ: Δ grows linearly, Σ barely moves → Im(Δ/Σ) ≈ km·δθ
  • One division per dwell — mono-pulse: one pulse suffices

Measured (hour 3): slope km = 0.2195/deg; target at +0.90° → read +0.914° — 0.014° against a 6.35° beamwidth. Caveat in numbers: at −2.3° the error is 0.21° — the discriminant is linear only near the null. Beamscan finds the beam; monopulse refines within it.

2.2 MIMO radar

The virtual array: N·M elements from N + M channels

  • MIMO (multiple-input multiple-output): Nt transmitters send orthogonal waveforms (time-staggered chirps); each of Nr receivers separates all Nt echoes
  • Pair (m, n) measures phase k·(xtx,m + xrx,n)·sin θ — positions add
  • Space TX elements Nr·λ/2 apart → the sums fill a ULA of Nt·Nr elements

The standard automotive chip: 3 TX + 4 RX = 7 channels behaving as 12 elements; cascaded chips reach ~1° beams on production trucks [R25][R26]. Everything today applies to the virtual array verbatim.

2.3 The tracking minimum

The α-β filter — below Kalman, above nothing

predict: x̂⁻ = x̂ + v̂·Δt  ·  residual: r = z − x̂⁻  ·  correct: x̂ ← x̂⁻ + α·r,   v̂ ← v̂ + (β/Δt)·r
  • Two gains, one trade: big α, β chase the data (fast, noisy); small α, β trust the model (smooth, laggy under maneuver). Course gains: α = 0.5, β = 0.2.
  • Lineage: the steady-state Kalman filter for constant velocity — graduate to full Kalman when maneuvers matter [R31].
  • Data association (which detection is which track) is given by the toolkit — real trackers spend half their code earning it.

"Why filter — just difference two frames"? Differencing amplifies: 0.1 m of position noise ÷ 0.25 s × √2 ≈ 0.57 m/s of velocity noise per pair, extrapolated over seconds of prediction. The filter is disciplined differencing over many frames.

2.4 CPA & time-to-go

Closest point of approach — four lines of geometry

Track state: position p, velocity v (sensor at origin). Minimize |p + v·t|²:

tCPA = −(p·v)/|v|²    dCPA = |p + v·tCPA|
  • p·v < 0: closing — the close approach is ahead (tCPA > 0)
  • p·v > 0: opening — CPA already happened; relax
  • |v| = 0: hovering — CPA is now, at range |p|

CPA = closest point of approach; TTC = time to collision.

2.4 CPA & time-to-go

Why R/(−R) is not enough — the crossing trap

The naive TTC = R / closing-rate works head-on and fails crossing: as a crossing target nears its CPA, the radial rate R → 0 and R/(−R) → ∞ — "no danger" — regardless of whether the pass is at 60 m or 6 m.

  • Homework witness: drone_b crosses safely at 60 m — naive TTC says "no alert" for the wrong reason, and would say the same at 6 m.
  • Only the angle measurement upgrades R to a velocity vector; only the vector separates coming close from coming slowly.

This is what the array bought. (R, v, θ) per frame → p and v as vectors → CPA in closed form.

2.5 The alert

Lecture 14's Pfa, with a cockpit attached

alert ⟺ 0 < tCPA ≤ 20 s and dCPA < 30 m

Miss: L14's missed detection with the cost made vivid. Homework margin: drone_a violates by 6.3 m; your tracked CPA error is ~0.03–0.94 m. Margins are a design output.

False alert: commands a maneuver that is itself dangerous — and burns trust at compound interest. An alerting system operators ignore is worse than none.

The homework's truth table contains two correct non-alerts (a 60 m crossing; an opening target) — reproducing those is graded as hard as the alerts.

2.5 The industrial instances

TCAS and AEB — the same mathematics, certified

TCAS (traffic collision avoidance system, aviation): transponder ranging → (R, R, θ, altitude) tracks → time-to-go ("tau") logic descended from R/R with crossing protections → RA (resolution advisory): climb / descend.

Überlingen 2002: one crew followed the controller, one followed TCAS — the case study in what an advisory system's credibility is worth.

AEB (automatic emergency braking, automotive): L15's 77 GHz FMCW (frequency-modulated continuous wave) chip → MIMO DOA → tracks → CPA/TTC → the brakes [R25][R26].

Regulators score misses and phantom braking — the two-sided table your homework fills, in production.

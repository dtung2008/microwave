## 第一小時 — 原理 I：那張圖（0:00–0:50）

### 1.1 一張 1939 年的紙上計算器，為什麼還統治整個產業（0:00–0:08）

投影片提示：現代向量網路分析儀（VNA）的螢幕，旁邊放 Smith 1939 年的原圖 —
同樣的圓，相隔八十七年。

開場拿出實物：舉起一張印出來的史密斯圖（Smith chart）。Phillip Smith 在 1939 年
的貝爾實驗室畫出這張圖 [R19]，原因很誠實 — 他受夠了手算複數反正切。今天地球上
每一台網路分析儀開機畫面仍是他的圖 — 不是懷舊，而是因為這張圖是**微波設計得以
被閱讀的座標系**。今天你要學會讀它、在上面走路、用它做設計。

今天的三個主張 — 寫在黑板上，留到下課：

1. **整個被動宇宙裝進一個圓盤。** 映射 Γ = (z−1)/(z+1) 把每一個 R ≥ 0 的阻抗 —
   整個右半平面，一路到無窮遠 — 收進半徑為一的圓裡。合法的點永遠不會離開
   圓盤。這種壓縮不是戲法，它就是「反射」的物理本身，你上週整週都在算它。
2. **在這張圖上，電路動作就是幾何動作。** 一段線讓你**旋轉**；串聯電抗沿一族圓
   滑動；並聯電納沿另一族圓滑動。匹配 — 本課程第一個真正的設計行為 — 就是
   選兩步棋，走到圓心。
3. **完美匹配是一個你親手蓋的諧振，帳單用頻寬付。** 今天我們的兩個設計在
   2.4 GHz 都是**精確**的 — 裁判會印出 |Γ| ≈ 10⁻¹⁶ — 而作業的全部戲劇性在於
   它們在 400 MHz 之外的表現。第 6 講把這件事變成定理（Bode–Fano）；今天你先
   **親眼看**。

先擋掉有人已經在打字的反駁：「這張圖不是過時了嗎？軟體都會算。」剛好相反。
軟體是**畫在**這張圖上 — 圖是座標系，不是計算器。到第 11 講你要在同一個圓盤上
讀放大器的穩定圓、雜訊圓、增益圓，然後決定你的設計點住哪裡；被軟體淘汰的是
不會讀圖的工程師。規格書、VNA 螢幕、以及你這輩子在白板前的每一次匹配討論，
都發生在這裡。

### 1.2 雙線性映射 — 推導兩次（0:08–0:20）

**第一層 — 代進去看（快版）。** 從第二講出發，取歸一化 z = Z/Z₀：

> Γ = (z − 1)/(z + 1)   ⇔   z = (1 + Γ)/(1 − Γ)

地標逐一驗證，出聲、上黑板：

- 短路，z = 0 → Γ = −1（左端點；全部反射，倒著回來）
- 開路，z → ∞ → Γ = +1（右端點；全部反射，正著回來）
- 匹配，z = 1 → Γ = 0（圓心 — 今天整堂課的靶心）
- 純電抗 z = jx → |Γ| = |jx−1|/|jx+1| = 1（圓周：只儲存，不吸收）
- 我們的天線，z_L = 0.72 − j0.42 → Γ = 0.285∠−110.0°（盤內，左下）

被動意味著 R ≥ 0，意味著 |Γ| ≤ 1：第 3 小時對這個映射丟四千個隨機被動阻抗，
回來的最大 |Γ| 是 0.999963。圓盤守得住。

**第二層 — 為什麼圓映到圓（第一性版本，用來解釋第一層）。** 這個映射是雙線性
轉換（bilinear / Möbius transformation），而雙線性轉換可分解為平移、縮放，加上
**一次反演** w → 1/w。平移與縮放顯然保圓；唯一有戲的是反演。把圓寫成
α(u² + v²) + βu + γv + δ = 0 — 在 u + jv → 1/(u + jv) 之下，α 和 δ 對調，方程
維持同一**形式**。直線是 α = 0 的圓 — 通過無窮遠的圓。於是阻抗平面的格線 —
R = 常數的垂直線、X = 常數的水平線 — 落成兩族圓：

> 等 r 圓：圓心 (r/(1+r), 0)，半徑 1/(1+r) — 全部在 Γ = 1 相切
> 等 x 弧：圓心 (1, 1/x)，半徑 1/|x| — 也全部在 Γ = 1 相切

那個相切點 Γ = 1 是開路 — 無窮遠的像，遠端半平面的所有格線都擠到那裡。對著
這件事盯六十秒，這張圖就不再是曼陀羅，而是方格紙。

先擋掉必問題：「整個無限大的半平面怎麼裝得進去？」因為 Γ 是**波的比值**，被動
負載頂多全反射（|Γ| = 1）。阻抗無界；反射有界。這張圖才是誠實的貨幣 — 這也是
你的 VNA 量的是 Γ、再換算成 Z，而永遠不是反過來的原因（第 4 講把這件事講精確）。

### 1.3 讀圖 — 帶著走一遍（0:20–0:32）

投影片提示：手繪風的大圖；然後同一張圖上標出 z_L。

實物投影機時間（這將是你未來每一份規格書裡的樣子）。把課程天線 —
Z_L = 36 − j21 Ω，作業二的病人 — 分四個慢動作畫上去：

1. 歸一化：z_L = 0.72 − j0.42；
2. 找 r = 0.72 的圓（在印好的 0.5 與 1.0 圓之間）；
3. 找 x = −0.42 的弧（下半 — 電容性；電感性在上半）；
4. 交點就是那個點。一個點、兩個座標、零代數。

接著從圖上**讀出**第二講算過的東西：點到圓心的距離是 |Γ| = 0.285；紙圖下方的
徑向刻度直接換成 SWR = 1.80 與回波損耗（return loss）10.9 dB，不用計算機 —
這正是這張圖原本的工作，免費的反正切。翻譯關係再出聲說一次（到第 6 講必須是
反射動作）：|Γ| 0.285 ⇔ SWR 1.80 ⇔ RL 10.9 dB ⇔ 送達功率 91.9%。

畫出**駐波比圓（SWR circle）**：以原點為心、過 z_L。這個圓上的每個阻抗反射得
和我們的天線一樣兇；無損線能帶我們去的每一個點也都住在這個圓上 — 這就是下一節。
圓是預算；匹配是越獄。

戰場故事，90 秒：某 2.4 GHz 產品團隊**隔著 30 公分測試纜線**量他們的天線，然後
對量到的阻抗設計了一個漂亮的 L 型匹配。裝上去，更糟。沒有人算錯：纜線把那個點
沿駐波比圓轉了將近一整圈，於是他們匹配的是一個只存在於「那條不隨產品出貨的
纜線遠端」的阻抗。在圖上，這個錯誤一眼可見 — 圓對了，角度錯了。參考平面
（reference plane）的正式處理在第 4 講（去嵌入，de-embedding）；今天的教訓
比較便宜：*動任何一毫米之前，先知道你的點活在哪個平面。*

### 1.4 運動 — 線讓你旋轉，以及導納圖（0:32–0:46）

東西一動，這張圖就開始賺錢。從第二講：

> Γ_in(ℓ) = Γ_L e^(−j2βℓ)

大小不動；相位減 2βℓ。在圖上：**朝發射機（generator）走，沿駐波比圓繞圓心
順時針轉**，線每走一電氣度、圖上轉兩度 — 每半個波長一整圈。那個 2 倍與方向
是所有人都會錯一次的兩件事；方向現在就擋掉：往發射機走 Γ 的相位**減少**，
因為反射波要多走一段回程 — e^(−j2βℓ)，負號，順時針。烙在視網膜上。

黑板上的數字，第 3 小時驗證（`zin_line` — 第二講的正切轉換，如今有了幾何靈魂）：

- ℓ = λ/8：z 轉 90° → Z_in = 28.4 + j6.0 Ω
- ℓ = λ/4：180° — **穿過圓心的點反演** → Z_in = 51.8 + j30.2 Ω = Z₀²/Z_L。
  第二講的四分之一波長轉換器就是「對徑點」— 整個證明在這張圖上只有一句話。
- 駐波比圓每圈穿過實軸兩次：ℓ = 0.097λ 處 Z_in = 27.8 Ω = Z₀/SWR（電壓最小
  點），ℓ = 0.347λ 處 Z_in = 89.9 Ω = Z₀·SWR（電壓最大點）。第二講的駐波
  解剖學，收斂成兩個實軸交點。

**導納圖（admittance chart）。** 匹配的第二族棋步是**並聯**元件，而並聯元件
相加的是導納（admittance）：y = 1/z，而在 Γ 的語言裡，y 的點是 z 的點**對原點
的鏡射** — 因為取倒數就是轉 180°（又是 λ/4 的事實，這次與頻率無關）。所以同
一個圓盤伺候兩種貨幣：正常讀是阻抗，取對徑點就是導納（或像市售複合圖那樣把
旋轉過的格線疊上去）。我們的天線：y_L = 1.036 + j0.605 — 把符號紀律出聲說清楚，
因為兩種貨幣之間符號會翻面：電容性負載的電抗是**負**的、電納（susceptance）卻是
**正**的；在導納國度，+j 是電容性。這套「貨幣與符號」紀律正是第 3 小時蓄意 bug
要違反的東西，結果會讓你看得很開心。

串聯元件：沿**等 r 圓**滑動（r 凍結，x 在動）。並聯元件：沿**等 g 圓**滑動
（g 凍結，b 在動）。線：旋轉。三個動作 — 這就是完整的指令集。匹配是一支
兩條指令的程式。

### 1.5 本小時回顧（0:46–0:50）

三句話，然後休息：史密斯圖是全體被動阻抗的雙線性像，圓映到圓，圓周是電抗、
圓心是家；線讓你朝發射機順時針轉 2βℓ、每 λ/2 一圈，λ/4 是反演 — 這也是導納
住在對徑點的原因；串聯走 r 圓、並聯走 g 圓。第二小時就用這三個動作，把我們的

## 第二小時 — 原理 II：匹配，兩種做法（1:00–1:50）

### 2.1 為什麼要匹配，以及兩步原則（1:00–1:12）

匹配買到什麼？對數字誠實，因為數字比民間傳說有趣。我們的天線不匹配時已送達
91.9% 的入射功率 — 匹配只找回 0.37 dB。如果 0.37 dB 是全部，沒有人會費這個事。
真正買到的是：饋線上不再有駐波（SWR 1.80 → 1.00 — 作業二讓你看過駐波在 10 公尺
真實纜線上幹的事）；發射機看到的是 50 Ω 電阻性負載，而不是一個隨纜線長度每
公分都在漂移的東西（第 11 講：放大器的增益、雜訊、甚至穩定性都是「它看到什麼」
的函數）；下游元件拿到它們被特性化時的那個阻抗。匹配與其說是為了功率，不如說
是**讓系統可以組裝**。

設計之前先做一個誠實的區分，因為這個混淆每年都會浮出來：今天我們把負載匹配
**到線** — 逼 Γ = 0、消滅反射。這不自動等於對**訊號源**做最大功率傳輸的共軛
匹配；兩者在源本身是 50 Ω 電阻時重合，而這正是本課程到第 11 講重新打開這個
問題之前的預設。如果你聽過「最大功率要 Z_s*」— 沒錯，那是另一個問題，先停在
路邊，第 11 講再接。

**兩步原則。** 靶是圓心，y = 1 + j0（或 z = 1 + j0 — 同一點）。你**最後**用的
元件決定你前一步必須站上的軌道：最後一步是**並聯**元件，就只能改 b、沿等 g 圓
滑 — 所以前一步必須停在 **g = 1 圓**上。最後一步是串聯，走等 r 圓 — 軌道就是
**r = 1 圓**。本課程的每一種匹配拓撲 — 今天的 L 型與支節、第 6 講的多節 — 都是
從圓心沿合法軌道倒著蓋回來的路。當口號說：*最後一步選軌道；第一步走上軌道。*

### 2.2 L 型匹配 — 從圖的幾何得到閉式解（1:12–1:26）

投影片提示：兩種拓撲並排，加上區域規則。

兩個元件，一串聯一並聯；唯一的問題是順序，而圖直接回答。負載若在 **1 + jx 圓
之內**（r > 1 的地盤 — R_L > Z₀），靠負載的並聯元件搆得到 r = 1 軌道，所以
並聯在前（貼著負載）、串聯收尾。負載在**圓外**（R_L < Z₀ — 我們的天線，36 Ω）
則反過來：**串聯貼著負載**先走上 g = 1 軌道，並聯收尾。一個區域一種拓撲 —
另一種的平方根會變負，那是代數在說「這條軌道到不了」。作業的設計器必須自己
**發現**區域，不准假設；檢查器會餵它一個 120 + j90 Ω 的負載驗明正身。

**第一層 — 推導就是圖的幾何（快版，而且是真身）。** 在我們的區域：串聯元件 x
之後，站在 z = r_L + j(x_L + x)；要求落在 g = 1 圓上：Re{1/z} = 1……一行代數：

> r_L² + (x_L + x)² = r_L   （歸一化；這**就是** g = 1 圓）
> ⇒ x = ± √(r_L(1 − r_L)) − x_L，接著 b = ∓ √((1 − r_L)/r_L)

**第二層 — 同一件事不歸一化（Pozar 5.1 的樣子），** 作為作業的合約：

> X = ± √(R_L(Z₀ − R_L)) − X_L    B = ± √((Z₀ − R_L)/R_L) / Z₀

兩個正負號，兩個設計 — 都合法、都精確。把我們的天線當場算完，每個數字上黑板
（第 3 小時全部印出）：

- √(36 · 14) = 22.45 Ω。解一：X = +22.45 + 21 = **+43.45 Ω** — 電感，
  43.45/(2π·2.4 GHz) = **2.881 nH**；B = **+12.47 mS** — 電容，**0.827 pF**。
- 解二：X = −22.45 + 21 = **−1.45 Ω** — 一顆 45.7 pF 的串聯電容（基本上是
  帶文件的導線）；B = −12.47 mS — **5.32 nH** 並聯電感。
- 兩個中間點：y = 1 ∓ j0.624，**恰好**在 g = 1 軌道上 — 檢查器印出
  Re(y) = 1.000000000，九位數，因為代數就是幾何。

再一個數字，先於第 3 小時的量測預言頻寬：這個匹配的負載 Q 是
√(Z₀/R_L − 1) = **0.62** — 一個懶散、寬容的諧振，因為 36 Ω 離 50 不遠。
若是匹配 5 Ω，Q = 3，頻帶會給你看臉色。先按著，2.4 節用。

L 型匹配住在哪裡：自諧振還堪用的集總 L 與 C，大約撐到 2–6 GHz（看你對寄生
效應多誠實）— 所以你口袋裡的手機（sub-6 GHz）裡滿滿都是 L 型匹配，而樓上
10 GHz 的雷達工作台上沒有。再往上，銅的幾何**就是**元件 — 下一節。

### 2.3 單支節匹配 — 分布式的做法（1:26–1:40）

投影片提示：支節調諧器的拓撲；然後兩個解都畫在圖上。

完全不用元件：同一種 50 Ω 線取長度 **d**，接一個**並聯支節（shunt stub）** —
一段開路或短路收尾的線岔，長度 **ℓ**，輸入是純電納（圖的圓周，轉到你需要的
地方）。兩段銅長，任何 PCB 上免費印出來；這就是**那個**微波匹配。

用圖的語言做設計 — 還是同一支兩步程式：線長 d 是免費的旋轉（第一步），並聯
支節是電納對消（第二步）。因為最後一步是**並聯**，一切都發生在**導納**裡：
把負載的 y 沿駐波比圓順時針轉，直到穿過 **g = 1 圓** — 一定會穿過，每個駐波
比圓每半圈穿它兩次 — 讀出該處剩下的 b，把支節裁成加 −b。到達 y = 1。收工。
實物投影機上走一遍：y_L 在 1.036 + j0.605……旋轉……圓在 y = 1 + j0.595 穿過
g = 1，再在 y = 1 − j0.595 又穿過一次。兩個交點、兩個設計，和 L 型的 ± 一模
一樣。

解析版（Pozar 5.2 — 作業的合約；推導是第二講的代數加上耐心）：令 t = tan βd，

> t = [X_L ± √(R_L((Z₀−R_L)² + X_L²)/Z₀)] / (R_L − Z₀)
> 然後 d/λ = arctan(t)/2π（負了就加 λ/2），支節對消該平面的電納 B：
> 開路支節 ℓ = −arctan(B Z₀)/2π，短路支節 ℓ = arctan(1/(B Z₀))/2π，
> 必要時加 λ/2 收進 [0, λ/2)。

我們天線的兩個解，上黑板（第 3 小時逐一驗到 10⁻¹⁶）：

- **解二（就選這個）：d = 0.1993 λ = 24.9 mm，開路支節 ℓ = 0.0854 λ =
  10.7 mm。** 落在 y = 1 − j0.595，支節加 +j0.595。
- 解一：d = 0.4953 λ = 61.9 mm，開路支節 ℓ = 0.4146 λ = 51.8 mm。落在
  y = 1 + j0.595。注意 d 幾乎是**一整圈** — 總共 0.9 λ 的銅，對上解二的
  0.28 λ。兩個在 f₀ 都完美。它們不是同一個產品 — 作業讓你量出為什麼，
  「選短的」將從民間傳說變成一個數字。

PCB（微帶線）上為什麼偏好開路支節：短路要打通孔（via），而通孔是第 5 講的
寄生元件；在同軸與波導裡，乾淨的反而是短路。兩種閉式解都在作業工具箱的合約
裡；檢查器會呼叫一次 `kind="short"`，讓你誠實。

這個設計賴以運轉的紀律 — 畫底線，第 3 小時會攻擊它：**並聯元件說的是導納，
所以旋轉必須停在導納圖的 g = 1 圓上。** 停在**阻抗**讀作 1 + jx 的地方 — 一個
看起來再自然不過的動作，r = 1 圓長得就像一條軌道 — 你就停在了正確點的對徑點
上。兩個平面相距 λ/4；代數甚至會遞給你一個貌似合理的支節長度。一切看起來都
沒事，直到裁判開始量。第 3 小時，cell 3.7。

### 2.4 四分之一波長重逢、禁區，以及帳單（1:40–1:48）

**λ/4，從高處再看一次。** 第二講的轉換器只匹配**實**負載 — 現在你一眼就看得出
為什麼：Z₀' = √(Z₀ R) 需要實的 R，也就是圖上實軸上的點。但實軸對任何人都只有
兩步之遙：每個駐波比圓每圈穿它兩次（我們的天線：0.097 λ 處 27.8 Ω、0.347 λ 處
89.9 Ω — 1.4 節的數字）。所以「λ/4 不能匹配複數負載」是帶注腳的民間傳說：
*先旋轉、再轉換* — 線加 λ/4 節也是一支兩步程式。作業二已經在沒有幾何的情況下
蓋過它；現在幾何是你的了。

**禁區（forbidden regions）。** 每種拓撲只搆得到圓盤的一部分，而圖不用代數就
告訴你是哪部分：串聯開頭的 L 型只能沿負載的等 r 圓離開 — 如果那個圓永遠碰不到
g = 1（恰好發生在 R_L > Z₀ 時），這個拓撲對這個負載就是死的，這就是 2.2 的區域
規則從另一側看過來。同一論證殺掉 R_L < Z₀ 時的並聯開頭，也畫出任何固定拓撲
調諧器的勢力範圍。等第 11 講遞給你一顆最佳雜訊源阻抗躲在圓盤犄角的電晶體，
你就是用這一招挑出真正到得了那裡的網路。

**帳單。** 今天兩個設計都只在一個頻率精確 — 因為兩個都是諧振：能量在只在調諧
頻率互相抵消的 +jX 與 −jB 之間來回晃。Q 數的就是晃的量。L 型把能量存在兩顆小
元件裡，Q = 0.62；支節設計把能量存在線長裡 — 而線的電氣角 2πd·f/f₀ 的漂移
**正比於 d**，所以解一那 0.91 λ 的銅退繞得比解二的 0.28 λ 快三倍。第 3 小時
量測之前，先把預言寫上黑板：2.0–2.8 GHz 的帶內最差回波損耗排名應該是 L 型、
然後支節二、然後支節一 — 而且支節一在帶緣會真的**比裸天線還糟**。一個在 f₀
完美、在 f₀ ± 400 MHz 是負債的匹配：這句話就是隨口說出的 Bode–Fano 判準
（第 6 講）— 匹配深度 × 頻寬是負載自身 Q 訂好的預算，每個網路只是選擇怎麼花。

戰場故事，60 秒：某 IoT 設計把天線匹配得美極了 — 28 dB 回波損耗，正中第 7
頻道 — 然後在第 1 與第 13 頻道的法規傳導測試掛掉。最後出貨的「解法」是一個
中心點**更差**的匹配（14 dB），但整個頻帶守住 12 dB：金樣品是一個諧振，產品
是一段頻寬。作業裡你會親手做一次這個交易，帶著數字。

### 2.5 本小時回顧（1:48–1:50）

兩步原則：最後一步選軌道（並聯 → g = 1，串聯 → r = 1），第一步走上軌道；
L 型是閉式解的圖上幾何，我們的天線是 2.88 nH + 0.83 pF，附區域規則；支節匹配
是導納國度的旋轉加對消，24.9 mm + 10.7 mm 的裸銅，兩個解不是同一個產品；
而每個精確匹配都是諧振，帳單用頻寬付。第 3 小時把這一切在 scikit-rf 裡蓋出來，
然後故意犯下第二小時那樁死罪。

**休息（1:50–2:00）。**

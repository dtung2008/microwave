## 第一小時 — 原理 I：單元、行波與反射（0:00–0:50）

### 1.1 第一講開出的支票（0:00–0:08）

投影片提示：上週的 λ 表，2.4 GHz 那一列打光 — 那條越過 λ/10 線的 3 公分走線。

開場先收上週的債。第一講結尾放了話：過了約 λ/10，克希荷夫不再是真理，**這一講**
才是。今天兌現。作業的主角把利害關係說得具體：10 公尺同軸纜線（coax）餵一支
2.4 GHz 天線。在那條纜線裡，2.4 GHz 的 λ = 83 mm — 這條饋線長達 **120 個波長**。
把它叫「一條導線」，在唯一要緊的單位上錯了四個數量級。

今天的三個主張 — 寫上黑板，留到下課：

1. **傳輸線（transmission line）是無窮小電路的梯子，而整座梯子由兩個數字概括。**
   四個每公尺量（R′、L′、G′、C′）孕育出特性阻抗（characteristic impedance）Z₀
   與傳播常數（propagation constant）γ = α + jβ。今天其餘的一切，都是這兩個數字
   的後果。
2. **傳輸線強制執行一個比值；拒絕這個比值的負載會造成反射。** Z₀ 不是電阻 —
   它是行波**必須**攜帶的 V/I 比。持不同意見的負載會把一部分波送回來：Γ，反射
   係數（reflection coefficient），這個產業裡被量測得最多的量。
3. **一段線會變換阻抗 — 而這是功能，不是缺陷。** Z_in 透過一個正切函數依賴
   ℓ；在 λ/4 處，線把阻抗**反轉**，這是你擁有的第一件匹配工具。今天的結尾：
   一條饋線把天線謊報了 19 dB，以及 λ/4 的修法 — 實測 |Γ| ≈ 10⁻¹⁶。

先擋掉教室裡數位設計師正在想的話：「我們管這叫訊號完整性（signal integrity）」—
沒錯。同一套物理、不同方言 — 你的「振鈴（ringing）」和「匯流排上的反射」就是
今天的 |Γ| 加上一個時脈；第 3 小時會用我們的公式把你課本裡的彈跳圖（bounce
diagram）親手做出來。今天結束時，兩種方言應該合流。

### 1.2 RLGC 單元與電報員方程式 — 推導兩次（0:08–0:20）

投影片提示：梯形電路 — 串聯 R′dz 與 L′dz、並聯 G′dz 與 C′dz，週而復始。

一對導線為什麼會**變成**這座梯子？先講物理，再做代數。任何兩條平行導體都帶著：
電流周圍的磁通 → 每公尺串聯電感 L′；導體之間的電荷儲存 → 每公尺並聯電容 C′；
導體的有限電導率 → 每公尺串聯電阻 R′；不完美的介質 → 並聯漏電導 G′。低頻時整條
纜線是一團集總元件，克希荷夫還活著。過了 λ/10，電壓與電流**沿線逐點不同**，所以
必須在一片無窮小切片 dz 上寫電路定律，讓微積分把切片黏起來。

**第一層 — 極限過程（第一性原理版）。** 對一片切片寫 KVL：
V(z+dz) − V(z) = −(R′ + jωL′)·dz·I(z)。對並聯支路寫 KCL：
I(z+dz) − I(z) = −(G′ + jωC′)·dz·V(z+dz)。除以 dz、令 dz → 0（二階小量死掉 —
說出口，會有人問）：

> dV/dz = −(R′ + jωL′) I    dI/dz = −(G′ + jωC′) V

**電報員方程式（telegrapher's equations）** — 得名於 1850 年代那批發現海底電纜
把摩斯電碼糊成一團、恰恰需要這套理論的工程師。兩條耦合的一階方程式：電壓因串聯
阻抗被吃掉而變化，電流因並聯導納漏走而變化。

**第二層 — 波動方程式（快版後果）。** 對第一式微分、代入第二式：

> d²V/dz² = γ² V,  γ = √((R′ + jωL′)(G′ + jωC′)) = α + jβ

解是 e^(∓γz)：兩道波，各奔一方，每公尺被 α（奈培/公尺）衰減、被 β（弧度/公尺）
轉相位。任何均勻雙導體線上關於傳播的一切，都在 γ 裡面。而每道行波的 V/I 比值，
從任一條電報員方程式讀出：

> Z₀ = √((R′ + jωL′)/(G′ + jωC′))

先擋掉必問題：「真實纜線又不是離散元件的梯子 — 這是模型還是真理？」對任何支持
TEM（transverse electromagnetic，橫向電磁）波的線 — 同軸、雙線，以及下一講的
微帶線（microstrip）的良好近似 — 在 dz → 0 極限下它是嚴格的；RLGC 值可以從截面
幾何算出來（第 5 講對微帶線就這麼做）。梯子不是場論的近似；它是場論，投影到
電路語言上。

### 1.3 Z₀ 與 γ — 兩個數字，配上數字（0:20–0:34）

介紹課程的纜線，因為今天每條公式都要落在它身上：一條 RG-58 級的同軸線，用它在
2.4 GHz 的每公尺單元描述 — R′ = 10 Ω/m、L′ = 250 nH/m、G′ = 0.45 mS/m、
C′ = 100 pF/m。（R′ 與 G′ 凍結在 2.4 GHz 的值；真實纜線的 R′ 隨集膚效應
（skin effect）以 √f 成長 — 第 5 講的細則。這是建模選擇，說出口。）

先看無損骨架，因為數字乾淨：

> Z₀ = √(L′/C′) = √(250 nH / 100 pF) = √2500 = **50 Ω**（50 就住在這裡！）
> v_p = 1/√(L′C′) = **2×10⁸ m/s = 0.667c**  β = ω/v_p  λ = v_p/f = **83.33 mm**

帶上損耗，第 3 小時印出誠實版：Z₀ = 50.0001 − j0.0589 Ω（虛部是損耗的指紋 —
這裡很小），γ = 0.1112 + j75.40 每公尺。低損耗近似值得上黑板推一次，因為它回答
**dB/m 從哪裡來**：

> α ≈ R′/2Z₀ + G′Z₀/2 = 0.100 + 0.011 = 0.111 Np/m

兩種損耗機制，被 Z₀ 往相反方向加權 — 導體損耗除以 Z₀（阻抗高，同樣功率下電流
小），這件事九十秒後就有用。換算奈培：1 Np = 20/ln10 = 8.686 dB，所以
**0.966 dB/m**，作業那條 10 公尺饋線單程吃掉 **9.66 dB**。第一講的 dB 文法，
現在有了物理出處。

**Z₀ 究竟是什麼** — 講仔細，這是本講最容易被誤解的物件。Z₀ 是「一道行波」攜帶
的 V/I 比。它不是三用電表量得到的電阻：在直流下，電表看到的是 R′ℓ 加上遠端接的
東西，50 Ω 根本不出場。Z₀ 不耗散任何功率 — 它是**線強制執行的比值**，波的電壓
與電流之間的匯率。一顆 50 Ω 電阻與一條 50 Ω 線只在一件事上有共識：拿那顆電阻端
接那條線，抵達的波發現自己的比值已被滿足，於是無一反射。這句話就是 1.4 節。

先擋掉「為什麼是 50 Ω？」— 年年必問：對空氣介質同軸線，功率承受力在 30 Ω 附近
最佳、損耗在 77 Ω 附近最低；50 是委員會形狀的折衷（75 Ω 活在廣播電視界，因為
沒人往電視饋線灌千瓦，損耗說了算）。沒有什麼神聖的 — 只是被凍結的歷史，而你
現在得去匹配它。

也先擋掉相對論焦慮：「0.667c — 電子跑那麼快？」不 — 電子漂移速度是 mm/s 級；
**能量**在導體之間的場裡走，0.667c = 1/√ε_r，聚乙烯的 ε_r ≈ 2.25。導體是軌道；
貨物是場。（這也是為什麼下一講「沿線移動」的操作是相位操作，不是粒子搬運。）

### 1.4 反射 — Γ，與反射功率圖像（0:34–0:46）

場景：一道波抵達線的末端，遇見 Z_L。波帶著 V/I = Z₀；負載要求 V/I = Z_L。兩者
必須在同一對端子上同時成立 — 矛盾，除非 Z_L = Z₀。物理用它唯一的辦法化解：出現
第二道、反向的波，其振幅比 Γ 恰好讓**總量**滿足負載。寫下邊界條件 — 總電壓除以
總電流等於 Z_L：

> (V⁺ + V⁻)/(V⁺/Z₀ − V⁻/Z₀) = Z_L  ⇒  **Γ = V⁻/V⁺ = (Z_L − Z₀)/(Z_L + Z₀)**

電流那行的負號是學生跌倒的地方：反向波的電流往回流，所以**相減**。地標數字上
黑板，各配一句物理：

- 短路，Z_L = 0：Γ = −1 — 全部回來，電壓翻面（短路把 V 釘在 0）；
- 開路，Z_L → ∞：Γ = +1 — 全部回來，正面朝上（開路把 I 釘在 0）；
- 匹配，Z_L = Z₀：Γ = 0 — 比值被滿足，無一返回；
- 純電抗，Z_L = jX：|Γ| = 1 — 只儲能、不耗散，所以功率終究得全數回家。電容器
  是一面帶相移的鏡子。

接著是課程的病人，往後三講都會遇到的數字：一支在 2.4 GHz 量得 **Z_L = 36 −
j21 Ω** 的天線。出聲算：

> Γ = (−14 − j21)/(86 − j21) = **0.285∠−110.0°**

功率：反射波帶走 |Γ|² = 8.1% 的入射功率；負載留下 1 − |Γ|² = **91.9%**。同一個
數字的三種方言，必須練成反射動作（第 3 小時四個全印）：

> |Γ| = 0.285 ⇔ **駐波比**（standing wave ratio, SWR）= (1+|Γ|)/(1−|Γ|) = 1.80
> ⇔ **回波損耗**（return loss, RL）= −20 log₁₀|Γ| = 10.90 dB
> ⇔ **失配損耗**（mismatch loss）= −10 log₁₀(1−|Γ|²) = 0.37 dB

回波損耗是**大就是好**的數字（反射被壓得遠）；失配損耗是**小就是好**的數字
（缺的少）。正負號慣例會殺人：規格書上的「S11 = −10.9 dB」和「RL = 10.9 dB」
是同一件事 — 現在說清楚，第 4 講就少一場混亂。

反射掉的功率**去了哪裡**？先擋掉：沿線回到產生器。若產生器匹配（50 Ω 訊號源 —
本課程在另行聲明前的標準假設），源電阻吸收它：變熱。若產生器**不**匹配，波再
反射一次 — 又一次 — 這個多次彈跳的故事就是第 3 小時的彈跳圖；跑到穩態，**恰好**
就是駐波公式的出處。一套物理，兩種視角。

下課前補一筆符號帳，因為你的紙上現在住著兩個 gamma：**γ = α + jβ 是傳播常數；
Γ 是反射係數。** 同一個希臘字母，純屬歷史的不幸。作業程式碼用名字拒絕歧義：
前者叫 `gamma_per_m`，後者叫 `refl`。紙上也採同樣的衛生習慣 — 必要時加下標。

### 1.5 本小時回顧（0:46–0:50）

三句話，然後休息：傳輸線是 RLGC 梯子的 dz → 0 極限，電報員方程式把它壓縮成 γ 與
Z₀ — 我們的纜線：50 Ω、0.667c、0.97 dB/m；Z₀ 是被強制執行的比值、不是電阻，持
異議的負載反射 Γ = (Z_L−Z₀)/(Z_L+Z₀) — 我們的天線退回 8.1%；四種方言（|Γ|、
SWR、RL、失配損耗）是同一個數字穿四套西裝。第二小時：兩道對開的波對它們之間
那段線做了什麼 — 以及一段纜線變成電路元件的那一刻。

## 第二小時 — 原理 II：駐波、轉換器與謊言（1:00–1:50）

### 2.1 駐波解剖 — 與曲柄圖（1:00–1:14）

投影片提示：包絡線圖 — 第 3 小時會把這張圖動起來。

現在線上住著兩道波：前進的 V⁺e^(−jβz)、反向的 ΓV⁺e^(+jβz)（先無損，圖像乾淨；
損耗 2.3 節回來）。距**負載** ℓ 處的總電壓（RF 慣例 — 從事發現場往回量）：

> V(ℓ) = V⁺e^(jβℓ)(1 + Γe^(−2jβℓ))

括號的模就是**駐波包絡線**。兩道波同相處：|V|max = |V⁺|(1+|Γ|)。反相處：
|V|min = |V⁺|(1−|Γ|)。包絡線**裡面**的波在跑；包絡線本身站著不動 — 第 3 小時
在凍結的包絡線裡畫七張時間快照，「駐波」這名字自己解釋自己。極值之比就是第一
小時的 SWR — 對我們的天線實測：包絡線 max/min = 1.2851/0.7149 = **1.7976**，
而由 |Γ| 算的 SWR 說 1.7976。同一個數，兩條路 — 不用函式庫的裁判原則。

這也是 SWR 這個詞活下來的原因：第一件 RF 儀器是開槽線（slotted line）— 一根
沿纜線切槽滑動的探針，讀 |V(ℓ)|。1940 年你量不到 Γ；量得到的是包絡線的最大、
最小與最小值位置 — 那就是 |Γ| 和它的相位，換了衣服。（它在操作上也還有意義：
|V|max 是讓接頭打火的東西，(1+|Γ|)× 的電流是讓末級電晶體發燙的東西 — SWR 是
Γ 的「應力」方言。）

**曲柄圖（crank diagram）** — 下週長成史密斯圖（Smith chart）的那張畫。畫複數
1 + Γe^(−2jβℓ)：一支單位相量，加一支長度 |Γ|、角度隨 ℓ 增加而**減少**的小相量 —
一支繞著 1 的端點順時針掃的曲柄。包絡線就是曲柄的總長：臂指向 +1 時最大、背向
時最小。曲柄轉滿一圈 = 2βℓ 前進 2π = **ℓ 前進 λ/2**：整個駐波圖樣每半個波長
重複一次。兩個後果，現在說、下週收割：(1) 無損線能對一個阻抗做的一切，都是 Γ
的**旋轉**；(2) 圖樣的週期是 λ/2、不是 λ — 那個讓每個人恰好跌倒一次的因子 2。

最小值在哪裡？曲柄背向 1 的條件是 angle(Γ) − 2βℓ = ±π。對我們的天線（角度
−109.97°）：第一個最小值在 ℓ/λ = (180 − 109.97)/720 = **0.0973** — 第 3 小時
取樣的包絡線讀出 0.0976λ（8.13 mm；第四位數是圖的取樣格距，不是物理）。記住
這個數；它馬上要派上用場。

### 2.2 Z_in(ℓ) — 正切變換，與 λ/4 的加冕（1:14–1:32）

主菜。站在距負載 ℓ 處問：後面那段線加負載，端出什麼阻抗？總 V 除以總 I：

> Z_in = Z₀ (1 + Γe^(−2jβℓ))/(1 − Γe^(−2jβℓ))

代入 Γ、輾平（黑板上一行代數 — 讓他們看著 Z₀ 一路對消）：

> **Z_in = Z₀ (Z_L + jZ₀ tan βℓ)/(Z₀ + jZ_L tan βℓ)**

正切變換。先讀它的性格再代數字：tan 週期是 π，所以 βℓ 前進 π — 每 **λ/2** —
Z_in 就重複，正是曲柄的週期，理當如此。而 tan 每個週期都經過 0 與 ∞，所以從
負載往回走半個波長之內，Z_in 遍歷整個動物園 — 容性、感性、小電阻、大電阻。
**一段纜線就是一台阻抗轉換器，不管你有沒有下訂單。** 在 2.4 GHz 把跳線改長
3 公分，你就重新設計了輸入網路。

特殊情況，各是一件工具：

- **ℓ = λ/2：Z_in = Z_L。** 線複誦負載。半波跳線在電氣上隱形 — **只在它恰好是
  半波的那一個頻率**（下面的戰場故事把這條註腳變成職涯教訓）。
- **ℓ = λ/4：tan → ∞，Z_in = Z₀²/Z_L。** 四分之一波長**反轉器**。大變小、容性
  變感性 — 以及最值錢的情況：**實數** R 變成另一個實數。要把實數負載 R 匹配到
  系統 Z₀，用 Z_T = √(Z₀R) 的線做那段四分之一波長：Z_in = Z_T²/R = Z₀，分毫
  不差。兩行代數，微波工程裡被蓋起來次數最多的結構之一 — 四分之一波長轉換器
  （quarter-wave transformer）。
- **短路支節（stub）：Z_in = jZ₀ tan βℓ** — 想要什麼電抗就有什麼電抗，用一段
  短路線。開路支節：−jZ₀ cot βℓ。這些會變成第 3 講的匹配元件；今天先知道
  型錄存在。

λ/4 故事的數字，因為作業就蓋這個：我們的天線是複數，而 λ/4 轉換器只匹配**實數**
阻抗 — 複數 Z_L 開根號得到複數 Z_T，世上沒有那種纜線。解法：**先走回一個純實數
平面。** Z_in 哪裡是純實數？正是曲柄穿過實軸的地方 — 包絡線的最小與最大值處，
每半波長兩次、交替出現：

> 在電壓最小值：Z_in = Z₀/SWR（我們：50/1.7976 = **27.8 Ω**）
> 在電壓最大值：Z_in = Z₀·SWR（我們：**89.9 Ω**）

於是：先鋪一段普通 50 Ω 線當間隔段（spacer）到第一個最小值 — 0.0973λ =
**8.11 mm** — 再接四分之一波長（20.83 mm）的 Z_T = √(50 × 27.8) = **37.29 Ω**。
在 f₀ 匹配**依構造精確**：作業的檢查器印出 |Γ(f₀)| ≈ 7×10⁻¹⁷ — 機器精度，因為
代數是精確的，裁判只是在確認算術。（免費的作業提示：間隔段要用**理想**線的 β
設計，不是有損纜線的 γ — 兩者在第六位數分家，而 10⁻¹⁰ 的判準看得見第六位數。）

先擋掉必問題：「只在一個頻率成立，λ/4 有什麼好加冕的？」因為「一個頻率」是
漫畫版 — 作業量出誠實版：這個修法把 10 dB 回波損耗撐過 **2.33 GHz 的頻寬**
（f₀ 的 97%），20 dB 撐過 577 MHz（24%）。窄頻是一個數字，不是一句罵人的話 —
而且第 6 講整整花一小時把它變寬。

### 2.3 損耗 — 與說謊的饋線（1:32–1:40）

把 α 放回來。每公尺把波的振幅乘上 e^(−αℓ)；功率乘上 e^(−2αℓ)。我們的 10 公尺
饋線：單程 9.66 dB。接著是這份作業得名的陷阱。你帶著向量網路分析儀（vector
network analyzer, VNA — 第 4 講參觀它）站在 10 公尺纜線的發射機端量回波損耗，
想了解天線。你量到的反射走了**三趟衰減**：去程（−9.66 dB）、彈回（其中
−10.90 dB 被反射）、回程（−9.66 dB）：

> RL_in ≈ RL_天線 + 2 ×（線損）= 10.90 + 19.33 ≈ 30.2 dB

第 3 小時實測 **30.09 dB**（那 0.1 dB 的縫來自纜線微複數的 Z₀ — 經驗式終究是
經驗式）。把謊言唸出聲：天線是**平庸的** — SWR 1.8 — 儀器卻說**優秀** —
30 dB！纜線把反射洗白了。每一 dB 的纜線把負載美化兩 dB；夠長的有損纜線能讓
**任何**負載 — 連開路都算 — 看起來像匹配。每個外場工程師都學過一次的推論：
回波損耗必須在你在乎的平面量，或者把纜線修正掉 — 「從機房量起來天線好得很」
是業餘無線電史上最貴的一句話。

功率帳本收掉本小時的物理（作業模組 2 把它算到精確）：發射機端入射 1 W，
99.3 mW 抵達並留在天線，0.95 mW 逃回來，**899.7 mW 拿去加熱纜線**。送達功率
比入射低 10.03 dB = 9.66（線損）+ 0.37（失配）— 兩種稅在 dB 相加，因為在瓦特
相乘。而替模組 2 當裁判的不變量：把損耗關掉，|Γ|² + 送達比例 = 1，準到
1×10⁻¹⁶ — 能量守恆，物理替你的程式碼背書，不需要任何函式庫。

### 2.4 時域 — 彈跳圖（1:40–1:48）

拿走正弦波；送一個步階。這是數位工程師的主場，也是開場承諾的方言合流。1 V
步階，從 25 Ω 訊號源進入 10 公尺 50 Ω 線，端接 150 Ω：

- t = 0：步階出發。線**強制執行它的比值** — 訊號源看到 50 Ω（它還不可能知道
  負載 — 因果律！），所以出發電壓是分壓 50/(25+50) = **0.667 V**。
- 50 奈秒後（10 公尺，2×10⁸ m/s）波前撞上負載：Γ_L = +1/2。負載電壓跳到
  0.667×(1+½) = **1.00 V**。
- 反射的 0.333 V 往回跑；在源端 Γ_s = (25−50)/75 = −1/3；再反射；每個來回乘上
  Γ_LΓ_s = −1/6。
- 負載的階梯：1.000 → 0.833 → 0.861 → 0.857 → …，幾何收斂到直流分壓
  150/175 = **0.857 V**，公比 −1/6。

第一個波前**超過終值 16.7%**。在示波器上這叫振鈴（ringing），被歸咎於幽靈；
它的真名是 |Γ|，週期是來回時間 2ℓ/v_p。兩條寓意：(1)「電氣上長」有時域定義 —
當波前的上升時間短於來回時間，線就是長的，這是 λ/10 的數位孿生；(2) 把階梯跑到
t → ∞，你恰好收回 2.1 節的相量答案 — 頻域是時域的穩態帳本，不是另一個宇宙。

戰場故事，90 秒 — 半波長跳線。一個雙頻段站台：低頻段在 f₀，第二頻段在 1.5f₀。
技師把一條受損的 50 Ω 跳線換成同長度的 75 Ω 視訊級纜線 — 而那個長度恰好是 f₀
的 λ/2。在 f₀ 上台架驗證：什麼都沒變。當然沒變 — 半波線複誦它的負載，**與線
自身的 Z₀ 無關**；跳線的 75 Ω 恰恰在那個頻率隱形，所以那次驗證什麼也沒證明。
在另一個頻段 1.5f₀，同一條跳線是 **3λ/4 — 奇數個四分之一波長** — 一台貨真價實
的 75 Ω 反轉器：50 Ω 系統變成 75²/50 = 112.5 Ω，SWR 2.25，回波損耗 8.3 dB，
高頻段的餘裕悄悄蒸發。沒有人量錯；量測只是恰好取在正切函數躲起來的那一個頻率。
寓意 — 同時也是第 3 小時的蓄意 bug：**正切有週期 — 一條線在某頻率的行為，
只替那個頻率背書。**

### 2.5 本小時回顧（1:48–1:50）

駐波是兩道對開的波在干涉 — 包絡線 max/min 之比是 SWR，曲柄圖是史密斯圖的胚胎，
圖樣每 λ/2 重複；Z_in 是正切變換 — λ/2 複誦、λ/4 反轉，「間隔段 + λ/4」在 f₀
把我們的天線精確匹配；損耗讓饋線用兩倍衰減說謊，而功率帳本（1 W 進、99.3 mW
送達 — 纜線吃掉 900）是可查帳的物理；線上的步階幾何地彈跳，振鈴是 |Γ| 在講
時域方言。第 3 小時用十二行 NumPy 把這一切蓋出來、用 scikit-rf 當裁判，然後
設計一台錯得很有魅力的轉換器。

**休息（1:50–2:00）。**

## 第三小時 — 工具：線引擎、裁判，與一個誘人的 bug（2:00–2:50）

### 3.1 環境驗證（2:00–2:05）

跑 cell 3.1。預期：python 3.12.x、numpy 1.26.4、scipy 1.13.x、matplotlib
3.10.x、scikit-rf 1.13.0 — 第一講的環境，無新增。課前 `setup_check.py` 沒過的

### 3.2 線引擎 — 整講塞進十二行（2:05–2:14）

Cell 3.2：`propagation()` 四行 — 組出 R′+jωL′ 與 G′+jωC′，開兩個平方根；
`z_in()` 再三行 — 用 **tanh** 形式，因為損耗是一等公民（也因為 `np.tan` 在
λ/4 極點爆炸，而 `np.tanh` 聳聳肩就過了 — 作業 README 疑難排解第一條）。跑在
纜線上，把第一小時從螢幕讀出來：Z₀ = 50.0001 − j0.0589 Ω — **線強制執行的
比值，加上損耗的微小虛部指紋**；α = 0.9663 dB/m；v_p = 2×10⁸ = 0.667c；
λ = 83.33 mm；**10 公尺饋線 = 120 個波長**。然後是天線：|Γ| = 0.2851、角度
−110.0°，SWR 1.798，RL 10.90 dB，失配損耗 0.368 dB — 天線把**抵達它**的功率
留下 92%。黑板上的每個數字，現在都是輸出。

### 3.3 裁判 — skrf 解同一個單元（2:14–2:22）

Cell 3.3，課程裁判原則的第二講戲服。scikit-rf 的 `DistributedCircuit` 拿同樣
四個 RLGC 數字，用它自己的程式路徑算 γ 與 Z₀：一致到 **0.0** — 完全相同，兩邊
都實作同一個閉式。更有趣的：10 公尺饋線的 Z_in 走兩條獨立的路 — 我們的 tanh
引擎，對上 skrf 的 γ/Z₀ 走**反射旋轉**恆等式（Γ_L 乘上 e^(−2γℓ) 傳播，全程
沒有 tanh）：2.0–2.8 GHz 全帶最大相對誤差 **5.4×10⁻¹⁶**。兩種推導、一個答案、
機器精度 — 作業檢查器對**你的**引擎印出這一行時，判準是 10⁻⁶，正確的引擎會
超標十個數量級。

收尾預告作業的頭條，一行講完：天線端的回波損耗 10.90 dB；隔著 10 公尺纜線量，
**30.09 dB**。指著它：**那個數字是謊言，作業模組 2 負責解剖它。**

### 3.4 駐波，動起來（2:22–2:30）

Cell 3.4：先凍結包絡線 |1 + Γe^(−2jβℓ)|，再在裡面畫七張真實電壓的時間快照。
波在動；包絡線不動 — 這就是「駐」。實測：max/min = 1.2851/0.7149，比值
**1.7976** — 由 |Γ| 的 SWR 公式說 1.7976。兩條路、同一個數、零函式庫。第一個
最小值在**距負載 0.0976λ**（8.13 mm）— 第二小時把 λ/4 轉換器停在那裡的純實數
平面，也是作業 Q1 要你在計算之前**預測**的位置。存下 `standing_wave.png`，
作業要並排用。

### 3.5 彈跳圖（2:30–2:38）

Cell 3.5：第二小時的步階，寫成八行 while 迴圈。看著輸出對上黑板：單程 50 ns、
出發 0.6667 V、Γ_s = −1/3、Γ_L = +1/2；負載階梯 1.0000 → 0.8333 → 0.8611 →
0.8565 → … → 0.8571 V，直流分壓；第一個波前**過衝 +16.7%**。趁畫圖時說出口：
在示波器上這叫振鈴；它的真名是 |Γ|。存下 `bounce.png`。數位背景的同學：這
**就是**你們訊號完整性課本裡的格子圖（lattice diagram），而你剛用電報員第一性
原理八行寫完它。

### 3.6 蓄意 bug — 「也能用」的 3λ/4 轉換器（2:38–2:44）

Cell 3.6，今天埋好的背叛。正切週期是 π — 所以 λ/4 會反轉，3λ/4 也會。兩個都
設計出來，先無損：間隔段 8.106 mm 走到 27.815 Ω 平面，Z_T = 37.293 Ω，裁判印出
λ/4 的 |Γ(f₀)| = 7×10⁻¹⁷、3λ/4 的 3×10⁻¹⁷。**兩個都完美。** 菜鳥工程師的結論：
「3λ/4 是同一個元件，而且我的比較好做。」現在把纜線自己的 α 交給轉換器，重量：
λ/4 給 RL 55.8 dB，3λ/4 給 51.97 dB — 仍然漂亮，損耗幾乎沒碰凹那個零點。所以
真的「也能用」？掃頻。20 dB 回波損耗頻寬：**λ/4：576.8 MHz。3λ/4：275.6 MHz。**
f₀ 上同樣的成績、**一半**的頻寬、三倍的銅、三倍的損耗。正切的週期不是免費
午餐：每多半個波長的線就多一份儲能，儲能讓頻率響應變陡 — 和戰場故事裡那條跳線
變成陷阱，是同一套物理。（第 3 講給「儲能 ⇒ 窄頻」這個直覺一張可以住的圖；
第 6 講把它變成定理。）

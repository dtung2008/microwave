## 第一小時 — 原理 I：電壓失效之時，波接手（0:00–0:50）

### 1.1 為什麼這一講是全課程的樞紐（0:00–0:08）

投影片提示：第一講的課程地圖，L4 方塊點亮，後面每個方塊都補上一行「……以 S 參數
描述」。

開場先講主張：這一週，課程要永久換一種語言。從第 5 講起，我們設計的每一個東西 —
微帶線、Wilkinson 分配器、濾波器、電晶體、天線埠 — 都用同一種方式**表示**：每個
頻率一個散射參數（scattering parameters, S-parameters）矩陣。規格表是 S 參數，
模擬器輸出是 S 參數，第 11 講你會從 Mini-Circuits 下載的 `.s2p` 檔也是 S 參數。
這一週把「讀、轉換、串接、以及 — 最重要的 — 質疑」練起來，後面的課程就是下坡路。

今天的三個主張 — 寫在黑板上，留到下課：

1. **在微波頻率，電壓與電流不再是好座標。** 不是錯 — 是**歧義**。第 2 講的行進波
   振幅才是真實儀器量得到的東西，而 S 矩陣就是它們的轉移函數。
2. **表示法可以互換；代數不行。** S、Z、ABCD 描述同一個硬體、可自由轉換 — 但每種
   表示法各有一個它讓其變得平凡的運算，用錯一種去串接，會得到氣定神閒的胡說。
   今天的結尾，就是同一個串接算兩遍，其中一遍不符物理。
3. **物理替每一個 S 矩陣當裁判。** 互易性（reciprocity，S = Sᵀ）、無損性
   （SᴴS = I）、被動性（passivity，奇異值不得超過 1）是任何誠實檔案都必須通過的
   單一數字檢驗。這一週你把它們做出來；第 7、11 講原封不動地重用。作業把它們
   對準三個檔案，其中至少一個在說謊。

先擋掉電路學背景同學的問題：「電路學教過二埠的 Z 參數、h 參數 — 為什麼要新形式？」
誠實回答：Z 在紙上毫無問題，問題出在操作面：要**量** Z₁₁，你得把第 2 埠開路，而
10 GHz 的世界沒有開路這種東西 — 一個裸露的接頭是電容也是天線，而許多電晶體一看到
開路就開始振盪。S 參數是把二埠語言圍繞著微波唯一做得好的操作重建：一切都端接
50 Ω，然後量波。同一個網路，換成量得到的座標。

### 1.2 電壓為什麼失去意義（0:08–0:18）

板書。回想第 2 講的端接傳輸線：V(z) = V⁺(e^{−jβz} + Γe^{+jβz})。現在問一個
無辜的問題：*這個元件輸入端「的」電壓是多少？* 沿駐波走一個波長：|V| 在
|V⁺|(1+|Γ|) 與 |V⁺|(1−|Γ|) 之間擺盪 — SWR 為 3 時，量到的答案隨探棒位置差三倍。
10 GHz 的 PCB 上，「探棒放哪」每移動幾公釐答案就變。電壓仍然存在；它只是不再是
**埠的屬性**，而變成了**位置的屬性**。

第二擊，操作面的一擊：古典矩陣的定義依賴你做不出來的邊界條件。Z 參數要開路
（I = 0），Y 參數要短路（V = 0）。在微波，「開路」會輻射、看起來像電容；「短路」
是一個帶電感的貫孔；而一個主動元件在諧振頻率被要求推開路，它的回答是振盪。
戰場故事，60 秒：學生實驗檯，一顆 6 GHz 電晶體用一截懸空 SMA 接頭當「開路標準」
做特性量測 — 曲線漂亮又平滑，但沒有一條屬於電晶體；那截懸空接頭是一段四分之一
波長殘段（stub），把預期的開路變成近似短路，待測元件整趟掃頻都離振盪只差兩歐姆。

那麼線上什麼東西是處處良定義、唯一的？兩個行進波。第 2 講已把 V、I 拆成 V⁺ 與
V⁻；V⁻/V⁺ 就是 Γ，整個第 3 講都住在它上面。今天我們把它們好好正規化，讓它們
當座標。

### 1.3 波振幅 a 與 b — 推導兩次（0:18–0:30）

**第一層 — 快版（定義）。** 在參考阻抗 Z₀（實數，全課程 50 Ω）的埠上：

> a = (V + Z₀I) / (2√Z₀)  b = (V − Z₀I) / (2√Z₀)

a 是入射（向內）波振幅，b 是外行波。反解：V = √Z₀(a + b)、I = (a − b)/√Z₀。
在匹配的線上 b = 0 且 V/I = Z₀ — 波圖像與電路圖像在該一致的地方完全一致。

**第二層 — 第一性（√Z₀ 從哪來）。** 我們**想要**平方就是功率的變數，讓散射係數
比較的是能量、不是伏特。用 RMS 相量算流入埠的功率：P = Re(V I*) = |a|² − |b|²。
就是它：|a|² 是入射功率（瓦），|b|² 是外行功率，差值是網路留下的。分母的 √Z₀
不是裝飾 — 它正是把電壓記帳換算成能量記帳的因子。（若用峰值相量，兩項各帶 ½；
慣例在每個比值中消去。細節見 Pozar 第 4 章 [R1]。）

往回接，說出口：在一埠上，b/a = (Z_L − Z₀)/(Z_L + Z₀) = Γ — 第 2 講的反射係數
（reflection coefficient），以散射參數的身分重新登場。你上週學的史密斯圖就是
b/a 的複數平面。沒有新東西，只是升了官。

先擋掉符號方向的問題：「入射是指射進哪一端？」每個埠都有自己的 a 指向網路**內**、
b 指向**外**。因此二埠每個頻率有四個數字，矩陣就是下一節。

### 1.4 S 矩陣 — 向量網路分析儀量的東西（0:30–0:40）

定義，框起來：

> b₁ = S₁₁a₁ + S₁₂a₂  b₂ = S₂₁a₁ + S₂₂a₂  亦即 **b = S a**
> S₁₁ = b₁/a₁，條件 a₂ = 0 — 而 a₂ = 0 的意思是**第 2 埠端接 Z₀**，
> 不是開路。要讓一個波歸零，用的是匹配負載。

在學生誤解生根之前先講明：一般而言 S₁₁ **不是**「元件的輸入反射」— 它是
**第 2 埠匹配時**的輸入反射。第 2 埠接上任何別的東西，輸入反射就變成
Γ_in = S₁₁ + S₁₂S₂₁Γ_L/(1 − S₂₂Γ_L) — 第二小時推導。把 S₁₁ 讀成「就是匹配」
是業界最常見的規格表誤讀。

詮釋表，帶著感情唸：S₁₁ — 第 1 埠的匹配（第 3 講整講的主題，現在是一個矩陣
元素）。S₂₁ — 傳輸，這東西的增益或損耗。S₁₂ — 反向傳輸：小的時候叫隔離，
重要的時候叫回授（第 11 講會看到放大器的不穩定性就住在 S₁₂ 裡）。S₂₂ — 輸出
匹配。

向量網路分析儀（vector network analyzer, VNA），一張投影片，除魅：一個掃頻源，
每個埠一個**定向耦合器**（directional coupler）— 一種能把進去的波和出來的波
實體分開的元件（第 7 講會做它）；兩個相量一相除，S₁₁ 就量出來了 — 沒有開路、
沒有短路，全程 50 Ω 端接。校正（一句話，誠實版）：VNA 量到的是**它自己**接頭處
的波；校正標準（短路/開路/負載/直通）把參考平面搬到你的平面 — 第二小時回到
參考平面，因為那是不變量幫不了你的一件事。

### 1.5 三個從此屬於你的二埠（0:40–0:48）

黑板上算，數字第 3 小時會印出來：

- **匹配 ×½ 衰減器（6.02 dB pad）：** S₁₁ = S₂₂ = 0、S₁₂ = S₂₁ = ½。功率進 1、
  出 ¼、反射 0 — 所以 |S₁₁|² + |S₂₁|² = 0.25，缺的 ¾ 是**耗散**掉的。記住這個
  數字；二十分鐘後它替么正性殘差做校準。
- **50 Ω 世界裡的 75 Ω 四分之一波長線：** 無損，但在 f₀ 印出 |S₁₁| = 0.3846、
  |S₂₁| = 0.9231 = −0.695 dB。驗算：0.3846² + 0.9231² = 1.0000。什麼都沒被耗散 —
  缺的功率**往回走了**。失配損耗不是耗散，|S₂₁| < 1 不代表發熱。
- **理想 1:2 變壓器：** ABCD = [[½, 0], [0, 2]]，在 50 Ω 下 S₁₁ = −0.6、
  S₂₁ = +0.8。同樣 0.36 + 0.64 = 1。注意**沒有**發生的事：變壓器把電壓加倍，
  S₂₁ 卻是 0.8 < 1 — 因為 S 比較的是功率，被動元件沒有功率可加。把這念頭留著；
  它是作業的 Q1，而業界每週都有人答錯。

### 1.6 本小時回顧（0:48–0:50）

三句話，然後休息：線上的電壓是位置的函數，所以埠改說波的語言 — a 進、b 出、
平方是瓦。S 矩陣是 b = S a，每個「歸零」都靠匹配負載執行，這正是 VNA 量得出它
的原因。無損網路的 |S₂₁| 照樣可以遠小於 1 — 反射不是耗散 — 而 |S₂₁| 能不能
超過 1，今晚你要給出一輩子帶著走的答案。第二小時：其他矩陣、串接代數，以及
替每個檔案當裁判的三個不變量。

## 第二小時 — 原理 II：矩陣動物園、串接與不變量（1:00–1:50）

### 2.1 Z、Y、ABCD — 每種表示法的主場（1:00–1:12）

同一個二埠，四種語言。板書表格，講精簡：

- **Z（阻抗矩陣）：** V = Z I。**串聯**堆疊時的主場（Z 相加）。開路定義 — 難量、
  好推導。
- **Y（導納矩陣）：** I = Y V。**並聯**的主場（Y 相加）。處處是 Z 的對偶。
- **ABCD（鏈矩陣）：** (V₁, I₁) = [A B; C D](V₂, I₂)，其中 I₂ 定義成**流出**
  第 2 埠，正是為了讓鏈條接得起來。**串接**的主場：整條鏈的 ABCD 是按順序的
  矩陣乘積。第 2 講的線段代入就是 [cos βℓ, jZ_c sin βℓ; j sin βℓ/Z_c, cos βℓ]；
  串聯阻抗是 [1, Z; 0, 1]；並聯導納是 [1, 0; Y, 1]。三個印章，就能蓋出本課程
  所有的梯形網路 — 作業裡埋的濾波器正是這種堆疊。
- **S（散射矩陣）：** b = S a。**量測**的主場，也是微波語意的主場；唯一一個儀器
  直接交給你的表示法。

轉換式，陳述、不硬磨（投影片兩個都有；作業要你親手實作，scikit-rf 裁判到
1e-10 — 本週實測 1.6e-12）：

> Z = Z₀(I − S)⁻¹(I + S)、S = (Z − Z₀I)(Z + Z₀I)⁻¹ — 矩陣形式，任意埠數。
> S ↔ ABCD：帶著 2S₂₁ 分母的二埠公式 — 在投影片上、在 starter 的 docstring 裡、
> 在 Pozar 表 4.2 [R1]。把它們**一次**抄對，正是該交給 AI 打字、再拿裁判驗證的
> 那種工作。

先擋掉必問題：「憑什麼 ABCD 可以乘，S 不行？」因為 ABCD 的輸出變數 (V₂, I₂)
就是下一級的輸入變數 — 這個表示法**被設計成**連接方程恰為恆等式。S 的變數是
按方向分類的波，不是按級分類 — 這正是下一節。

### 2.2 串接 — 看起來對、其實錯的代數（1:12–1:22）

畫兩個方塊串成鏈，波都標上。第一級在其第 2 埠的外行波 b₂ **就是**第二級的
入射波 a₁'。很好。但第一級的 S 矩陣還需要知道自己的 a₂ — 那是第二級的 b₁' —
兩個網路**雙向**互餵，合成響應是兩者之間無窮次彈跳的級數和（第 2 講的彈跳圖，
矩陣版）。把 S₁ 乘上 S₂ 回答的是另一個不符物理的問題：它把一邊的 b 接到另一邊
的 b — 輸出接輸出。

兩條正路，講明白：

1. **走 ABCD**（或 T／波串接矩陣）：轉換、按鏈序相乘、轉回來。這就是作業的
   `cascade`，skrf 的 `**` 運算子是它的裁判 — 六段失配段落實測一致到 1.0e-15。
2. **把彈跳級數加總：** 兩級時 S₂₁,tot = S₂₁'S₂₁/(1 − S₂₂S₁₁') — 那個 1/(1−x)
   就是級間反射的幾何級數。答案相同，而且它**顯示**了為什麼匹配的介面讓串接
   變簡單：S₂₂S₁₁' → 0，彈跳全滅。

現在就給數字，讓第 3 小時的示範落地兩次：兩個 ×½ pad 做天真的 S@S，得到
S₂₁ = 0 — 兩個衰減器串起來「什麼都不傳」，因為乘積把埠接反了。而 L 節 + 線段
那組，天真乘積印出看似合理的 −7.44 dB，真值是 −0.35 dB — **看似合理**才是
關鍵詞；本小時的第三個不變量就是抓它的工具。

### 2.3 不變量 — 互易、無損、被動（1:22–1:38）

主菜。物理對幾大類網路各許下一個承諾，每個承諾是一行線性代數，每行變成一個
函數，課程往後十二週都在用。

**互易性：S = Sᵀ。** 出自 Lorentz 互易定理：任何由線性、等向材料組成的網路 —
金屬、介質、帶不帶損耗都行 — 兩個方向傳輸完全相同：S₂₁ = S₁₂，永遠成立，不管
版圖看起來多不對稱。什麼會打破它：磁化的鐵氧體（隔離器、環行器）、電漿，以及
**主動元件** — 電晶體的本職就是 S₂₁ ≫ S₁₂。所以互易性檢查同時是主動性偵測器。
殘差：全頻帶 max |S − Sᵀ|；純轉置，沒有共軛 — 現在就講，因為把兩種轉置搞混是
作業的經典 bug。

**無損性：SᴴS = I — 推導兩次。** 快版：功率進 = |a|² 各埠加總，出 = |b|²；無損
表示對**每一種**激勵 ‖b‖² = ‖a‖²；「對所有 a 都有 ‖Sa‖² = ‖a‖²」就是么正
（unitary）的定義。第一性版，因為「對每一種激勵」正是學生會滑過去的重點：
‖a‖² − ‖Sa‖² = aᴴ(I − SᴴS)a 是個二次形式；若對所有 a 為零，這個 Hermitian
矩陣 I − SᴴS 就逐項為零。逐行讀出：|S₁₁|² + |S₂₁|² = 1 — 我們的 λ/4 線
（0.3846² + 0.9231² = 1.0000）與變壓器（0.36 + 0.64）當場在黑板通過。把它
變成儀器：**么正性殘差 = 各頻率 ‖SᴴS − I‖（Frobenius 範數）的最大值**。pad 得
3/(2√2) = 1.06066 — 現場算：SᴴS = ¼I，殘差矩陣是 −¾I，範數 ¾√2。無損線得
1e-16。一個數字，「無損」就不再是行銷用語。

**被動性：奇異值不得超過 1。** 較弱的主張，較寬的網：被動網路可以耗散，但不可
**發射**。吸收功率 = ‖a‖² − ‖Sa‖² ≥ 0 對每個 a 成立 ⇔ I − SᴴS ⪰ 0（半正定）
⇔ S 的每個奇異值 σ ≤ 1。是奇異值，不是特徵值 — S 不是 Hermitian，非正規矩陣
的特徵值可以安分地待在單位圓內，網路卻在對外泵功率。殘差：各頻率
max(σ_max² − 1, 0) 的最大值。誠實的被動檔案是零；正值意味著主動硬體或壞資料 —
沒有第三種。

現在把作業的 Q1 丟給全班，逼大家表態：*被動網路能不能在某個頻率出現
|S₂₁| > 1 — 某種諧振、某種巧妙的失配？* 收完票，指著剛寫下的代數：σ_max ≤ 1
壓住矩陣的每一個元素，所以**不能** — 實數參考阻抗下不能、諧振也不能、永遠不能。
「λ/4 線能把電壓加倍」是真物理，但那是**電壓**增益；a、b 裡的 √Z₀ 早已把帳本
換算成能量，被動元件沒有能量可加。真正能超過 1 的：電壓轉移函數，以及參考到
複數 Z₀ 的 pseudo-wave S 參數 — 兩者都不會出現在 50 Ω 的檔案裡。今晚三個埋好
的檔案中有一個印出 |S₂₁| = +8 dB；投「諧振可以」的那一半班級，會把一顆放大器
無罪釋放。

容忍度，誠實的尾聲：實測資料帶雜訊，殘差永遠不是零。作業埋的「VNA」每個元素
加約 1e-4 的雜訊，把殘差地板抬到 1e-3 附近；課程容忍度設在地板上方約 5 倍，
而且**理由**就寫在常數旁邊 — 因為一個沒人能辯護的容忍度，遲早有人悄悄放寬。

### 2.4 參考平面、訊號流程圖，以及帶著疑心讀規格表（1:38–1:48）

**參考平面。** S 參數定義**在**平面上。把平面往外移一段長度 ℓ 的線，每個波就
乘上 e^{−jβℓ}：S′ = diag(e^{−jβℓ₁}, e^{−jβℓ₂})·S·diag(e^{−jβℓ₁}, e^{−jβℓ₂})。
去嵌入（de-embedding）就是選 ℓ 把夾具剝掉。兩個推論，一個安慰、一個不安慰：
不知道平面在哪之前，相位沒有意義；而平移矩陣是么正的 — 所以**不變量看不見
平面錯誤**。一個檔案可以通過互易、么正、被動三關，相位卻參考在錯的接頭上。
這套組合抓的是騙子，不是糊塗的記帳員；知道你在獵哪一種敵人。

**訊號流程圖，Mason 精簡版。** 節點 a₁、b₁、a₂、b₂；分支是 S 的元素；第 2 埠
的負載是一條從 b₂ 折回 a₂ 的分支 Γ_L。一個迴圈：S₂₂Γ_L。單迴圈法則（本課程
需要的全部 Mason）：路徑增益除以 (1 − 迴圈)：

> Γ_in = S₁₁ + S₁₂S₂₁Γ_L / (1 − S₂₂Γ_L)

當場做極限檢查：Γ_L = 0 得 S₁₁（匹配端接的定義，找回來了）；S₁₂ = 0 得 S₁₁
（沒有回授路徑，輸出端隱形）。第 11 講把電晶體放進方塊，用同一張圖推出它需要
的每一條增益公式 — 這十分鐘是投資。

**讀規格表的疑心，養成習慣。** 課綱預告的誤解：「S₂₁ 就是增益，永遠是。」
只在匹配端接下成立。夾在失配的級與級之間，換能增益（transducer gain）G_T 牽涉
S₁₁、S₂₂ 和兩個 Γ — 流程圖剛剛展示了機制（那些 1/(1−x) 分母），第 11 講把差別
量化。第二個疑心，今晚作業一句話講完：一份寫著「無損」的規格表是在做一個
**可檢驗**的宣稱 — 0.1 dB 的暗損耗在 60 dB 的圖軸上隱形，在 ‖SᴴS − I‖ 裡
刺眼。檔案負責宣稱；殘差負責作證。

### 2.5 本小時回顧（1:48–1:50)

四種語言，一個網路：Z 串聯相加、Y 並聯相加、ABCD 串接相乘、S 是儀器說的話。
S 矩陣不能相乘 — 串接走 ABCD 或把彈跳級數加總，記住 −7.44 對 −0.35 dB。三個
不變量，三句話：S = Sᵀ，否則有主動或鐵氧體；SᴴS = I，否則有耗散；σ_max ≤ 1，
否則檔案在發射它沒被給過的功率 — 而被動網路不會在 50 Ω 檔案裡印出 |S₂₁| > 1。
第 3 小時把這一切變成會跑的程式碼、弄壞一個串接，再交給你三個嫌疑犯。

**休息（1:50–2:00）。**

### 3.7 蓄意 bug — 用矩陣乘法串接 S（2:37–2:43）

Cell 3.7，第二小時預告過。先來卡通版車禍：兩個 ×½ pad，`S @ S`，乘積說
S₂₁ = 0 — 兩個衰減器串起來「什麼都不傳」，因為乘積把輸出接到了輸出。全班大笑；
沒有人會把這個出貨。然後是危險版：L 節 + 75 Ω 線。天真版：−7.44 dB。正確版：
−0.35 dB。天真的數字**看似合理** — 它能安然通過設計審查。現在對它跑
`is_reciprocal`：**False**，|S₁₂ − S₂₁| = 1.651 — 兩個互易的被動零件串出一個
自稱非互易的網路，銅做的硬體不可能這樣。不變量把**代數**定了罪。再加上誠實的
註腳，投影片和程式碼裡都有：兩個無損 S 矩陣的天真乘積仍然是么正的（么正矩陣
的乘積還是么正），所以光靠么正性檢查會**漏掉**這個 bug — 你需要整套組合，
這正是作業要你建整套組合的原因。

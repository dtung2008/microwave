## 第一小時 — 原理 I：從線圈到銅箔 — Richards 與 Kuroda（0:00–0:50）

### 1.1 為什麼上週的濾波器買不到（0:00–0:08）

投影片提示：hw8 的帶通梯形電路，換上 2.4 GHz 的元件值重畫一次。

用算術開場，不用哲學。把作業 8 那台你已經擁有的合成機器對準 2.4 GHz 而不是
60 MHz：N=3 切比雪夫（Chebyshev）、0.5 dB、10% 頻寬。第一個串聯支路算出來是
**52.93 nH 串聯 0.0831 pF**。把這兩個數字翻譯成 2.4 GHz 的現實：53 nH 的線圈
要繞好幾圈、好幾毫米的導線，匝間電容讓它在 2.4 GHz *以下*就自諧振——過了自
諧振點，「電感」其實是電容。而 0.083 pF 比焊墊本身的寄生電容還小。插入損耗
*方法*在微波下活得很好；元件目錄死了。

在 2.4 GHz 無限供應、單價為零的東西是**印刷傳輸線**——第五講教過你把它切成
大約 20 到 120 Ω 之間的任何 Z₀。這一講就是一場翻譯：同一組 g 值，用銅箔實現。
今天的三個主張，寫在板上：

1. **一個正切函數就是整套理論。** Richards 轉換（Richards' transformation）
   Ω = tan(βl) 把等長傳輸線網路變成頻率軸扭曲後的集總濾波器——*精確地*，不是
   近似。今天的支節（stub）濾波器落在切比雪夫閉式解上，誤差 3×10⁻¹⁴ dB。
2. **Kuroda 恆等式（Kuroda identities）是恆等式，不是近似。** 它把你做不出來
   的支節換成做得出來的，checker 量到的等價誤差是 7×10⁻¹⁶——機器精度，而且在
   每一個頻率上。
3. **分佈式濾波器是週期性的。** tan 會重複，所以你的濾波器會重複。每個等長線
   （commensurate lines）濾波器都有第二次人生——**再入通帶（reentrant
   passband）**——這週你要在掃頻之前先預測它落在哪裡。忽略主張 3，就是濾波器
   「通過」實驗桌測試、到了現場卻失效的標準劇本。

### 1.2 Richards 轉換 — 推導兩次（0:08–0:20）

**第一層——快版：代入就看見。** 第二講給過支節的輸入阻抗：特性阻抗 Z、電氣長度
θ = βl 的短路支節呈現 Z_in = jZ·tan θ；開路支節呈現 Z_in = −jZ·cot θ。現在盯著
集總目錄看：電感是 Z_L = jωL，電容是 Y_C = jωC。定義 **Richards 頻率**

> Ω = tan θ = tan(βl)

支節*就是*把 ω 換成 Ω 的集總元件：阻抗 Z = L 的串聯短路支節，是電抗 ΩL 的電感；
阻抗 Z = 1/C 的並聯開路支節，是電納 ΩC 的電容。任何 LC 梯形網路都逐元件映射成
支節網路——同樣的拓撲、同樣的 g 值、*在 Ω 上*同樣的轉移函數。

**第二層——原理版，用來解釋快版。** 為什麼映射的是整條*響應*，不只是單一頻率上
的元件阻抗？因為等長網路定理：若網路中每段線的電氣長度 θ 都**相同**（等長、
commensurate），則整個網路的每個 S 參數都是單一變數 t = j·tan θ 的有理函數。
（板上速寫論證：每段線的 ABCD 是 cos θ·[[1, jZ tanθ],[j tanθ/Z, 1]]——tan θ 的
多項式——級聯與端接保持有理性。）所以等長分佈網路擁有*恰好*是集總網路在變數 Ω
上的數學。合成理論整批搬家；唯一的代價是頻率軸：Ω 是 ω 的*扭曲*版本，而且是
週期性地扭曲。這個代價有名字——2.3 節——而且永遠躲不掉。

**校準選擇。** 原型的帶緣在 Ω = 1，所以選共同長度讓 tan θ 在截止頻率等於 1：
**θ(f_c) = 45°，即每個元件在 f_c 是 λ/8。** 映射表（第三小時會印出來）：
Ω(0) = 0——DC 還是 DC；Ω(f_c) = 1——帶緣精確落點；Ω(2f_c) = ∞——有限的實頻率
對應*無限大*的原型頻率，3 GHz 設計在 6 GHz 有一個衰減極點；Ω(3f_c) = −1——帶緣
*再次*出現；Ω(4f_c) = 0——「又是 DC」，濾波器忘光了一切。

先擋掉尖銳學生會問的問題：*「2f_c 到 4f_c 之間 tan 是負的——負頻率在我的濾波器
裡幹嘛？」* 答：這類全極點響應的衰減只依賴 |Ω|（切比雪夫多項式非偶即奇），
所以 2f_c 到 4f_c 之間的響應是「從無限大一路退回 DC」的鏡像。第二個通帶就是
沿著這面鏡子走回來的。

### 1.3 Kuroda 恆等式 — 把做不出來的變成做得出來的（0:20–0:32）

Richards 把 N=3 梯形交給佈局工程師：**串聯短路支節、並聯開路支節、串聯短路
支節。** 佈局工程師把它退回來。兩個理由，都是物理的：

- **微帶線做不出串聯支節。** 串聯元件要打斷訊號導體；串聯*支節*還要讓這個斷口
  往旁邊跑、然後短路到地——而地平面在下方連續不斷。畫不出來，就是畫不出來。
- 就算做得出來的並聯支節也有問題：Richards 把三個元件全放在**同一個節點**。
  三根支節從一個接點長出來，彼此耦合，把接點變成一坨沒人建模的東西。

請出**單位元件（unit element, UE）**：同樣等長 θ 的一段傳輸線，阻抗任選。它的
ABCD 是 cos θ·[[1, jZ tan θ],[j tan θ/Z, 1]]。兩件事實：第一，阻抗等於埠阻抗的
UE 加在源端或負載端，對 |S21| *什麼都不改*——匹配的線只加相位。第二——這是
Kuroda 的發現——UE 讓支節**穿過它、順便改變物種**。

**推導（原理版，板書——六行）。** 把 UE(Z₁) 乘上串聯短路支節 Z₂（t 記 tan θ）：

> UE·SS = cos θ · [[1, jt(Z₁+Z₂)], [jt/Z₁, 1 − t²Z₂/Z₁]]

把並聯開路支節 Ẑ₂ 乘上 UE(Ẑ₁)：

> Sh·UE = cos θ · [[1, jtẐ₁], [jt(1/Ẑ₁ + 1/Ẑ₂), 1 − t²Ẑ₁/Ẑ₂]]

逐項比對：Ẑ₁ = Z₁ + Z₂，Ẑ₂ = Z₁(Z₁+Z₂)/Z₂——再驗 (2,1) 項有沒有收攏：
1/(Z₁+Z₂) + Z₂/(Z₁(Z₁+Z₂)) = 1/Z₁。有。加框：

> **UE(Z₁) + 串聯短路支節(Z₂) = 並聯開路支節(Z₁(Z₁+Z₂)/Z₂) + UE(Z₁+Z₂)**
> 記 n² = 1 + Z₂/Z₁：兩個新阻抗都是舊阻抗乘上 n²。

**快版，當作慢版的合理性檢查：** 讓 θ → 0。左邊是一小段線（≈ 沒東西）加一個小
串聯電感 Z₂·θ；右邊是一個小並聯電容 θ/Ẑ₂ 加一小段線。L 換成 C？在 DC 兩邊都
消失——而在任何低頻，兩個網路的差只在 θ 的二階，恰如矩陣恆等式展開後的要求。
恆等式*在所有 θ 精確成立*；低 θ 極限只是讓人願意相信。

誠實地交代整個家族：Kuroda 恆等式共**四條**。不需要變壓器的兩條，把串聯短路
支節隔著 UE 換成並聯開路支節（上面推的那條）以及反向（同一套代數倒著跑）。
另外兩條互換開路↔短路的物種，代價是一個**理想 n²:1 變壓器**——為完整起見陳述
（Pozar 表 8.7）；微波實務幾乎只用前兩條，因為理想變壓器也是買不到的元件。

戰場故事，45 秒：有學生不做 Kuroda，直接把串聯支節「近似」成訊號線上一道細
彎折縫隙就下線。縫隙是串聯電容，不是串聯短路支節——元件根本不對——回來的板子
是一個沒人訂購的耦合器。Kuroda 不是官僚程序；它是濾波器與抽象藝術的分界線。

### 1.4 支節低通，一路算到銅箔數字（0:32–0:45）

板書——作業的模組 1，現場做一遍。規格：N=3 切比雪夫、0.5 dB 漣波、f_c = 3 GHz、
50 Ω。hw8 引擎給 g = [1.5963, 1.0967, 1.5963, 1]。

1. **原型，串聯 L 開頭：** L = 1.5963、C = 1.0967、L = 1.5963。
2. **Richards：** 串聯短路支節 Z = 1.5963 | 並聯開路支節 Z = 1/1.0967 = 0.9118
   | 串聯短路支節 Z = 1.5963。（正規化；全部在 3 GHz 是 λ/8。）
3. **兩端各加 UE(1)** ——免費，它們與埠匹配。
4. **每端做一次 Kuroda**（Z₁ = 1、Z₂ = 1.5963、n² = 2.5963）：串聯支節變成
   (1+g₁)/g₁ = 1.6265 的並聯支節，躲在 1+g₁ = 2.5963 的 UE 後面。負載端對稱。
5. **乘 50 Ω：** 並聯開路 **81.32 Ω** | 線 **129.81 Ω** | 並聯開路 **45.59 Ω**
   | 線 **129.81 Ω** | 並聯開路 **81.32 Ω** ——五個元件，全部在 3 GHz 是 λ/8
   （理想線 12.49 mm），全部做得出來，而且支節之間隔了一整段線。這個佈局上的
   好處不是白來的——UE *就是*那段間隔。

在第三小時量測之前，先講清楚「構造上精確」是什麼意思：這個網路在每個頻率的
|S21| 等於切比雪夫閉式解在 Ω = tan(45°·f/f_c) 的值。在 f_c：恰好 −0.5000 dB——
等漣波帶緣，最後一位數都對，因為從頭到尾沒有任何近似。趁數字還在板上，順手
檢查阻抗的現實性：45.6 到 129.8 Ω——舒適地落在微帶線 20–120 Ω 的窗口裡
（129.8 Ω 那段有點勉強；第五講的合成說它在我們的板上是 0.15 mm 的細線——細,
但合法）。Richards + Kuroda 交出一個*做得出來*的濾波器,不靠運氣：UE 被支節
阻抗吸收,正是把所有數值拖向窗口中央的那隻手。

## 第二小時 — 原理 II：階梯阻抗、耦合線,與兩條誠實條款（1:00–1:50）

### 2.1 階梯阻抗低通 — 快而寬的役馬（1:00–1:10）

主菜之前,先看便宜貨。一小段*高阻抗*線（βl ≪ 1）的 ABCD ≈ [[1, jZ_h·βl],
[j·βl/Z_h, 1]]:串聯項獨大——它是**串聯電感** ωL = Z_h·βl。對偶地,一小段低阻抗
線是**並聯電容** ωC = βl/Z_l。於是低通梯形變成一節肥一節瘦的香腸:

> βlᵢ = gᵢ·R₀/Z_h（電感） βlᵢ = gᵢ·Z_l/R₀（電容）,在 ω_c。

3 GHz、巴特沃斯（Butterworth）N=3、Z_h = 120 Ω、Z_l = 20 Ω 算出來:電氣長度
**23.9° / 45.8° / 23.9°**。看著中間那個數字,把小聲話說出來:45.8° 一點都不
「短」。近似已經在吃力,第三小時量帳單:實現出來的 3-dB 點落在 **3.049 GHz**
（偏高 1.6%）,阻帶在 6 GHz 只到 **13.1 dB**（真巴特沃斯給 18.1）,整個阻帶
在 **−14.9 dB** 附近觸底,到 **11.7 GHz** 響應回到 0 dB。設計指引,誠實版:
階梯阻抗是規格軟、板面空間硬的時候用的濾波器——偏壓線清理、真濾波器前面的
諧波打壓——而它的 Z_h 被你板廠的最小線寬封頂,那才是真正決定阻帶的東西。
規格有硬裙帶的,繼續往下走。

### 2.2 耦合線帶通 — 第七講的投資到期（1:10–1:28）

投影片提示:兩條平行微帶線,下面放第七講的四張模態場圖。

微波帶通的役馬是一排**平行耦合 λ/4 節**。取兩條耦合線,從線 1 的一端饋入,從
線 2 的遠端取出,另外兩端開路。第七講給過你對付任何對稱四埠的工具:分解成
**偶模**（even mode,阻抗 Z0e,兩線同相驅動）與**奇模**（odd mode,Z0o,反相）。
對這種接法跑完分解,得到二埠阻抗矩陣——寫下來,不推導（推導是第七講等級的
作業代數）:

> Z₁₁ = Z₂₂ = −j·(Z0e + Z0o)/2 · cot θ
> Z₁₂ = Z₂₁ = −j·(Z0e − Z0o)/2 · 1/sin θ

代入 θ = 90°——四分之一波長:Z₁₁ = 0、Z₁₂ = −j(Z0e−Z0o)/2。對角線為零、只剩
交叉耦合的二埠是一個**阻抗反轉器（impedance inverter）**:K = (Z0e − Z0o)/2。
*耦合強度就是阻抗劈裂。* 其餘全是第八講:帶通濾波器就是用反轉器耦合的諧振器,
g 值告訴你每個反轉器要多強。分數頻寬 Δ:

> Z₀J₁ = √(πΔ/2g₀g₁) — 端節帶根號
> Z₀Jₖ = (πΔ/2)/√(g₍ₖ₋₁₎gₖ), k = 2..N — 內部節不帶
> Z₀J₍N₊₁₎ = √(πΔ/2gNg₍N₊₁₎)

然後每節的偶奇對,由 K = (Z0e−Z0o)/2 反解,並記得每節還內嵌了諧振器的一部分:

> Z0e = Z₀(1 + JZ₀ + (JZ₀)²) Z0o = Z₀(1 − JZ₀ + (JZ₀)²)

在誤解成形之前先擋掉:*「為什麼端節的 J 帶根號?」* 因為端反轉器把諧振器耦合到
**端接**（g₀ = 1）,不是另一個諧振器——與 hw6 的外部 Q 和級間耦合不同源,是同
一件事的另一張臉。

**板上實作,N=3、0.5 dB、Δ = 10%、f₀ = 2.4 GHz**（作業的核心,這裡全速做一次）:
J·Z₀ = 0.3137、0.1187、0.1187、0.3137——然後是全班該抄下來的表:

| 節 | Z0e (Ω) | Z0o (Ω) | K (Ω) |
|---|---|---|---|
| 1, 4 | 70.60 | 39.24 | 15.68 |
| 2, 3 | 56.64 | 44.77 | 5.94 |

（這正是 Pozar 例題 8.8 的數字——同一個電氣設計,他放在 2 GHz——所以教科書本人
就能當你作業模組 2 的裁判。）每節在 2.4 GHz 是 λ/4。端節耦合強——偶奇劈裂大,
物理上是*縫隙小*;內部節耦合弱——劈裂小,縫隙寬。

**從阻抗到毫米。** 工具箱用逆 Hammerstad 加 Akhtarzad 單線等效（耦合對的每個
模,行為像半模阻抗的單條微帶線;二維求根解回線寬與縫隙）收尾。在我們的 RO4350B
板上:端節 **w = 0.93 mm、s = 0.087 mm**,內部節 **w = 1.15 mm、s = 0.46 mm**,
長度 **19.0 / 18.9 mm**。在 s = 87 µm 上停一拍:端節縫隙已經在標準 PCB 蝕刻的
邊緣——*是規格的頻寬決定了那道縫。* Δ 越寬,耦合要越緊,s 要越小;到某個 Δ,板廠
說不。這是任何合成公式都不會印出來的頻寬上限。

對設計程序本身的誠實條款,因為作業會量它:J 反轉器圖像是**窄頻的**——在 f₀
精確,對 (f−f₀)/f₀ 只到一階。實現出來的 0.5-dB 頻寬量到 **9.83%**,設計值 10%;
漣波在遠端帶緣漏到 0.57 dB。不是 bug:泰勒展開,做泰勒展開該做的事。hw8 的集總
轉換是精確代換,帶緣命中到機器精度;這個是誠實的工程近似,Q4 要你找出它進場的
位置。

### 2.3 再入 — 週期性的帳單到期（1:28–1:38）

投影片提示:Richards 圓——θ 繞圈,通帶扇形上色,頻率軸把圓展開成一串重複的通帶。

第 1–2 節的一切都是用 cot θ、csc θ、tan θ 蓋的——全部以 π 為週期。而 TEM 線的
θ 對頻率*線性*。結論,以定律的口吻說:**每個等長分佈濾波器的響應對頻率是週期
的。** 複本落在哪:

- **支節低通**（λ/8 在 f_c）:通帶 0 → f_c;衰減極點在 2f_c(每根支節 λ/4:開路
  支節變成對地短路);然後鏡像裙帶,接著 **3f_c 到 5f_c 又是一整個通帶**——
  3 GHz 的設計,9 到 15 GHz 大門敞開。
- **耦合線帶通**（λ/4 在 f₀）:通帶在 f₀;傳輸零點在 2f₀(θ = 180°,半波節退耦);
  **通帶在 3f₀ 再現**——θ = 270° = 90° + 180°,cot/csc 分不出差別。2.4 GHz 的
  設計:**7.2 GHz,大門敞開,|S21| = 0 dB。** 然後 5f₀ = 12 GHz,永遠繼續。

設計後果,每句都值得全班抄:你的阻帶規格只在通帶與第一個再入之間可執行——
「40 dB 極限抑制」不是等長濾波器承諾得起的東西。若有強干擾源坐在 3f₀ 附近,
這個拓撲*在架構層*就出局,輪不到最佳化。系統層的解是誠實的級聯:再加一個低通
（它自己的再入也要查)去擦帶通的第二次人生。

先擋:*「集總濾波器也這樣嗎?」* 不——ω 在直線上跑向無限大,不繞圈;hw8 的梯形
單調滾降到永遠。再入是你用線圈換銅箔時買進的、貨真價實的新故障模式。第三小時
的蓄意 bug 和作業 Q1 都住在這裡。

### 2.4 理想與 EM 的鴻溝 — 場解器知道的事（1:38–1:48）

到目前為止的掃頻假設理想 TEM 線:耦合對的兩個模同速、接點是幾何點、開路就是
開路。微帶線一條都不簽:

- **偶模與奇模速度不同。** 奇模的場多住在縫隙上方的空氣裡(ε_eff 較低,較快);
  偶模的多住在基板裡。2f₀ 的傳輸零點要求兩個模*一起*到達半波;它們不一起,
  零點劈成兩個,能量從劈縫之間漏過去:平行耦合微帶濾波器惡名昭彰的 **2f₀ 附近
  寄生通帶（spurious passband）**。
- **色散:** ε_eff 隨頻率上升(第五講),用準靜態值切的長度在 f₀ 電氣上偏長——
  整條響應往低頻滑。
- **不連續性:** 開路端有邊緣場(支節比畫的更長)、接點儲能、階梯散射。

戰場故事,本課程長明燈那一盞:一片下線的耦合線濾波器回來**低了 4%**——每節長度
都用 DC 的 ε_eff 切,不是 f₀ 的。理想掃頻不可能抓到;理想掃頻*就是那個 bug*。
解藥是物理更多的模型:場解器,或板子本身。

**案例研究。** openEMS(免費 FDTD 場解器)只由授課者執行——你後處理它輸出的
Touchstone,永遠不安裝。誠實框,課堂上大聲說:*本週課程機器上真正的輸出檔還不
存在*,所以實驗室生成一個**大聲標示的佔位檔(placeholder)**:理想模型加上有文件
記載的 ±3% 偶奇 ε_eff 劈裂與 +2% 色散,重掃一次。它不是場解——它是理想模型加上
面點名的那兩個機制,所以鴻溝的*形狀*誠實,數字是替身。它給的數(第三小時 3.6 格,
每張圖都蓋來源章):中心滑動 **2.4000 → 2.3740 GHz(−1.1%)**,2.4 GHz 的 |S21|
掉到 **−0.29 dB**,理想模型在 2f₀ 的 −77 dB 變成 **−0.3 dB**——寄生通帶,原尺
寸。真正的輸出檔落進 `lab/` 那天,同一格程式讀它,數字自動更新;管線本身就是
教材。

### 2.5 本小時回顧（1:48–1:50）

階梯阻抗:快、寬,對截止與裙帶都不誠實——還被板廠最細的線封頂。耦合線:偶奇
劈裂*就是*耦合;g → J → (Z0e, Z0o) → 毫米,端節帶根號、縫隙最緊。所有分佈式
的東西掛兩條誠實條款:響應會重複(7.2 GHz 大門敞開,而且你會在掃頻前預測到),
理想模型差一個模速劈裂加一個色散位移,只有更多物理能標價。第三小時讓每個數字
都印出來。

### 3.1 環境驗證（2:00–2:03）

跑 3.1 格。預期:python 3.12.x、numpy 1.26.4、scipy 1.13.x、matplotlib 3.10.x、

### 3.2 Richards 映射表（2:03–2:08）

3.2 格:一張表,f → θ → Ω。每列印出來就指著念:3 GHz 映到 Ω = 1(帶緣,我們的
λ/8 選擇);6 GHz 印出 Ω ≈ 3.5×10¹⁵——數值上的無限大,衰減極點;9 GHz 映到
**−1**,又一個帶緣;12 GHz 映到零——「濾波器以為自己在 DC」。這一格的結尾就是
本講的論旨:*tan 是週期的,所以每個等長濾波器都重複。永遠。*

### 3.3 支節低通,現場蓋起來（2:08–2:16）

3.3 格:g 遞迴(hw8 引擎的緊湊版)、Richards、然後 Kuroda 印成前後對照:做不出來
的串聯形式一行,全並聯形式下一行——81.32 / 129.81 / 45.59 / 129.81 / 81.32 Ω。
掃它。三個量出來的事實,大聲念:|S21|(3 GHz) = **−0.500000 dB**——等漣波帶緣,
精確;整條掃頻落在「切比雪夫過映射」閉式解上,誤差 **2.8×10⁻¹⁴ dB**;Kuroda 後
的網路與串聯支節網路一致到 **7.8×10⁻¹⁶**——*恆等式,不是近似*(這個數字就是作業
Q3)。存下的圖顯示 6 GHz 的極點,以及——刻意把軸開寬——9 GHz 回來的通帶。

### 3.4 階梯阻抗,標價（2:16–2:24）

3.4 格:三行設計(23.9° / 45.8° / 23.9°),先用理想線掃:3-dB 點 **3.049 GHz**,
6 GHz 阻帶差 5 dB。然後銅箔步驟:RO4350B 上的逆 Hammerstad 線寬——120 Ω 是
**0.178 mm**(注意板廠最小線寬)、20 Ω 是 **4.04 mm**——實體長度 4.29 / 7.27 /
4.29 mm,再用 skrf `MLine` 物理(有限厚度、色散)重掃同一片銅:3-dB 點又動了,
到 **3.112 GHz**。寓意,講一次:理想線設計已經是原型的近似;銅箔又是理想線設計
的近似;*你回報的每個數字,都註明它出自哪一層模型。*

### 3.5 耦合線帶通,從頭到尾（2:24–2:33）

3.5 格:整條鏈用交談速度過一遍——g → J·Z₀(0.3137 / 0.1187,「端節帶根號」)→
Z0e/Z0o 表(70.60/39.24、56.64/44.77——「Pozar 自家的例題 8.8,在我們的頻率」)→
理想掃頻:IL(f₀) = 0.0000 dB、0.5-dB 頻帶 2.282–2.518 GHz = **9.83%** 對設計的
10(「窄頻映射的手續費——模組 2 精確,反轉器*圖像*不精確」)→ Akhtarzad 尺寸,
每節 w/s/ℓ,特別點名 87 µm 的端縫。這一格是作業模組 2 和 3 壓縮成一個畫面;
在掃頻函數裡 θ = 90°-在-f₀ 那一行放慢,因為那一行就是模組 3。

### 3.6 案例研究 — 理想遇上「現實」（2:33–2:40）

3.6 格,第五講的先例升級版:這一格載入 `openems_coupled_bpf.s2p` 位置上的任何
Touchstone,不管它是授課者的場解還是佔位檔,後處理完全相同。今天它用大寫印出

2.4 GHz 上 −0.29 dB、2f₀ 寄生通帶 −0.3 dB(理想模型承諾過 −77)。兩句布道詞:
*真正的輸出檔存在的那天,同一段程式直接讀它——先蓋管線,後等資料;每個替身都

### 3.7 蓄意 bug — 在 2f₀ 宣布勝利（2:40–2:44）

3.7 格,第二小時預告的 bug。系統規格:3.2 GHz 以上 ≥ 40 dB。把完工的濾波器掃
0.1 → 4.8 GHz——看起來完全合理的選擇,中心頻率的兩倍,集總濾波器工程師會停的
地方。3.2 GHz 以上最差抑制:**52.8 dB,而且隨頻率越來越深。** 出貨。然後重掃到
10 GHz:3.2 GHz 以上最差抑制 **0.0 dB,在 7.20 GHz**——第二個通帶,大門敞開,
就在 bug 掃頻邊界外 2.4 GHz 的地方。雙面板圖投影,停十秒鐘。能活過這門課的
規則:**等長濾波器是週期的——永遠掃過 3f₀,並且知道 5f₀ 在哪。**

### 作業簡報（2:44–2:48）

- **預測先行。** Q1(濾波器在哪裡回來,為什麼)和 Q2(2f₀ 的零點碰到微帶線活不
